# 가화만사성 아이콘 문법 (A2)

기준: DESIGN-SYSTEM-PLAN §0(사용자 관점), §3 A2. 색은 토큰 v3(갈색 #744821, 종이 #F6F3EE, 보조 #85592F, 선 #A67C5A, 완료 초록 #166534, 위험 #B91C1C).
겉보기(렌더링)는 에이전트 자체 확인만 했고 리드 확인 전이다(미확인).

## 1. 문법
| 항목 | 규칙 | 이유 |

## 2. 크기와 판독 확인
- 크기: **24**(자녀 탭·목록), **32**(어르신 버튼 안 아이콘 최소), **48**(안내·빈 상태·큰 표식). 탭 아이콘 26은 24~32 사이 값으로 24 격자를 그대로 확대한다.
- 확인 방법: (1) 24·32·48에서 선과 선 사이 틈이 살아 있는가(굵기 3.5에서 틈 0.5 이상), (2) 눈을 가늘게 뜨거나 흐리게(블러) 해도 실루엣이 구분되는가, (3) 시트에서 이름을 가리고 알아맞히기, (4) 글자 150% 확대 레이아웃에서 글자 옆에 붙었을 때 균형.
- 굵은 변형은 선만 굵어지는 것이 아니라 막히는 아이콘(경고·사진·복사·달력·설정)은 `bold/`에서 안쪽 디테일을 줄인 별도 도면이다.

## 3. 상태와 색
- **기본**: #744821(종이 위 7.05:1). 보조 줄 #85592F(5.47:1).
- **눌림**: 짙은 #4D2E12 + 둥근 바탕판 #EADFCF + 굵은 3.5(9.3:1). 색만이 아니라 판과 굵기가 함께 바뀐다.
- **비활성**: #A67C5A(3.36:1). 비활성은 대비 의무 대상이 아니지만 색 말고도 버튼 글자를 바꾼다("지금은 누를 수 없어요" 등 이유 문구).
- 완료 = 초록 #166534 + **체크 모양** + 글자. 위험 = 빨강 #B91C1C + **삼각형·휴지통 모양** + 글자. 주황(누르는 곳)과 초록(끝난 것)을 반대로 쓰지 않는다. 색만으로 의미를 전달하지 않는다.
- 선택된 탭·현재 상태는 굵은 3.5 + 글자 굵게.

## 4. 의미 분류와 사용 규칙
- a 아이콘만: 의미가 거의 보편이고 글자가 곁에 이미 있거나 없어도 기능이 사라지지 않는 것.
- b 아이콘+글자 필수: 알아볼 수는 있지만 60~80대는 "무슨 일이 일어나는지" 확신이 없는 것.
- c 글자만: 아이콘이 오히려 혼란을 주는 것(로그아웃).
- **규칙안 R1**: 어르신 화면은 모든 버튼이 b(아이콘+글자)이거나 글자만이다. 아이콘 단독 버튼은 닫기(X)·뒤로 두 개뿐이고 눈에 보이는 크기 32, 터치 영역 64.
- **R2**: 어르신 화면에서 아이콘은 글자 **왼쪽**에 붙는다(읽는 방향). 글자가 먼저 읽히고 아이콘은 보조다.
- **R3**: 같은 일에는 같은 아이콘과 같은 글자. 아이콘만 바꾸거나 글자만 바꾸지 않는다.
- **R4**: 위험한 행동(삭제)은 아이콘만으로 누르게 하지 않는다. 글자+2단계 확인.
- **R5**: 어르신 화면에서 쓰지 않는 아이콘(표의 "사용 안 함")은 자녀 화면 전용이다.
- **R6**: 아이콘은 오류에 쓰지 않는다(걱정 해님+부드러운 문구). 경고 삼각형은 되돌릴 수 없는 삭제 경고에만.

### 분류 근거
- **스피커 (b 아이콘+글자)**: 스피커 모양은 라디오·TV·전화로 익숙하지만, 60~80대는 "눌러서 읽어 준다"로 바로 연결하지 못할 수 있다. 라벨 "읽어 주세요" 필수.
- **스피커 재생 중 (b 아이콘+글자)**: 파동 개수(1→2)와 글자("멈추기" 또는 "읽는 중")로 상태를 구분한다. 색만 바뀌지 않는다. 소리를 못 듣는 상황도 있어 글자 필수.
- **멈춤 (b 아이콘+글자)**: 네모 정지 기호는 리모컨·녹음기 세대에게 익숙하지만 앱에서는 처음일 수 있다. "멈추기" 글자 필수.
- **체크(완료) (a 아이콘만)**: 체크는 설문·서류에서 익숙하다. 항상 글자(예: "다 했어요", "연결됐어요") 옆 보조 표시로만 쓰이므로 단독으로 의미를 떠안지 않는다. 완료 초록과 함께 쓰되 모양이 의미를 갖는다.
- **뒤로 (b 아이콘+글자)**: 왼쪽 화살표는 대부분 알지만 "뒤로가 이 앱에서 기록을 지우나?" 같은 불안이 있다. 어르신 화면은 "이전" 글자와 함께, 자녀 화면은 단독 가능(분류 b로 보수 적용).
- **화살표(다음) (b 아이콘+글자)**: 오른쪽 화살표는 직관적이지만 "다음"이 정확히 무엇인지는 글자가 말해야 한다. 버튼 글자 옆 보조.
- **꺾쇠(더 보기) (a 아이콘만)**: 목록 줄 오른쪽 끝에 붙는 순수 보조 표식이다. 줄 전체가 글자를 가지고 있고, 어르신 화면에는 쓰지 않는다. 없어져도 기능이 사라지지 않는다.
- **홈 (b 아이콘+글자)**: 집 모양은 알아보기 쉽다. 그러나 "홈"이라는 영어 라벨 자체가 장벽이라 한글 "처음" 또는 "오늘"과 함께 쓴다(라이터 확정 필요).
- **리포트 (b 아이콘+글자)**: 막대그래프는 자녀(30~50대)에게는 익숙하고 어르신은 쓰지 않는다. "리포트"도 외래어라 자녀 화면에서도 라벨 필수.
- **응원(하트) (b 아이콘+글자)**: 하트는 "좋아요/사랑"으로 보편적이지만 "응원 문구를 고른다"는 행동은 글자가 필요하다. 어르신 화면에서는 "응원이 왔어요" 글자와 함께.
- **설정 (b 아이콘+글자)**: 톱니는 스마트폰 사용 경험이 있으면 알지만 60~80대에게는 "기계 부품"으로 읽힐 수 있다. 자녀 화면에서도 "설정" 글자 필수, 어르신 화면에는 쓰지 않는다.
- **알림 (b 아이콘+글자)**: 종 모양은 알림의 표준이다. 하지만 "알림 허용"이 무슨 뜻인지는 글자가 풀어 준다("전화처럼 울려요").
- **알림 끔 (b 아이콘+글자)**: 사선은 "안 된다"로 읽히지만 비난처럼 느껴질 수 있다. 문구는 "알림이 꺼져 있어요"처럼 사실만 쓰고, 사선+글자로 상태를 표시한다.
- **잠금 (b 아이콘+글자)**: 자물쇠는 대부분 알지만 어르신 화면에서 "내가 틀려서 잠겼다"로 읽히면 안 된다. 문구로 "잠시 쉬어요, 10분 뒤에 다시"를 말해야 한다. "곧 유료"는 글자 배지로 처리(아이콘 쓰지 않음).
- **닫기 (a 아이콘만)**: X는 시트·창 오른쪽 위에서 거의 모두가 알아본다. 단 어르신 화면에서는 작고 모서리에 있어 누르기 어렵다 → 터치 영역 64 확보, 가능하면 큰 "닫기" 글자 버튼으로 대체.
- **공유(카톡 전달) (b 아이콘+글자)**: "상자에서 화살표가 올라가는" 공유 기호는 스마트폰 사용자에게 익숙하지만 처음 보는 사람은 의미를 모른다. 자녀 화면 한정, "카톡으로 보내기" 글자 필수. 카카오 로고는 우리 것이 아니므로 쓰지 않는다.
- **복사 (b 아이콘+글자)**: 겹친 사각형은 컴퓨터 사용 경험 있는 사람에게만 익숙하다. 자녀 화면 한정이며 "번호 복사" 글자 필수.
- **새로고침(다시 하기) (b 아이콘+글자)**: 원형 화살표는 어르신에게 "돌고 돈다/로딩"으로 읽히기도 한다. 버튼 글자는 "다시 해 볼게요"처럼 동사 하나로 쓰고, 아이콘은 보조.
- **경고·위험 (b 아이콘+글자)**: 삼각형+느낌표는 거의 보편이지만 어르신이 "내가 큰 잘못을 했나"로 느낄 수 있다. 오류에는 쓰지 않고(걱정 해님+부드러운 문구), 정말 되돌릴 수 없는 삭제 경고(C8)에만 쓴다. 위험 빨강+삼각형+글자.
- **사진 (b 아이콘+글자)**: 네모+산+해 모양은 갤러리 앱의 표준이다. 이 앱은 사진이 핵심이라 어르신에게 반복해서 학습된다. 첫 노출에서는 "사진" 글자 필수. 해가 해님과 어울리도록 둥근 점으로 그렸다.
- **연필(따라 쓰기) (b 아이콘+글자)**: 연필은 "쓴다"로 어르신이 가장 잘 아는 도구 중 하나다. 다만 "수정"으로도 읽혀, 코스 카드에서는 "한글 쓰기" 글자 필수.
- **지우개 (b 아이콘+글자)**: 지우개는 연필과 짝으로 인식되지만 기울어진 블록 그림만으론 약하다. "지우고 다시" 글자 필수. 기록 삭제(휴지통)와 혼동하지 않도록 모양을 크게 구분했다.
- **휴지통(삭제) (b 아이콘+글자)**: 휴지통은 알아보기 쉽지만 어르신에게 삭제는 두려운 행동이다. 휴지통 단독으로 누르게 하지 않고 "내 기록 지우기" 글자+2단계 확인. 아이콘만으로 위험한 행동을 하게 만들지 않는다.
- **정보 (b 아이콘+글자)**: "i"는 영어 정보(information)에서 온 기호로 60~80대에게는 낯설다. 어르신 화면에서는 쓰지 말고 글자 안내로만 한다. 자녀 화면은 보조.
- **로그아웃 (c 글자만)**: 문 밖으로 나가는 화살표는 직관적이지 않고 "로그아웃" 자체가 외래어다. 설정 줄의 글자("이 폰에서 나가기" 등 라이터 확정)만으로 충분하다. 그려 두었으나 사용 비권장.
- **사람 (b 아이콘+글자)**: 머리+어깨는 "계정/사람"으로 보편적이다. 누구인지는 이름 글자가 말한다. 어르신 화면 사용 안 함.
- **가족 (b 아이콘+글자)**: 두 사람 그림이 "가족"인지 "친구/팀"인지는 모호하다. "가족" 글자 필수(C1 제목 등).
- **별 (b 아이콘+글자)**: 별은 "즐겨찾기/평점/칭찬"으로 쓰여 의미가 겹친다. 연속일은 해님 도장이 기본이므로 이 별은 자녀 화면 보조 한정. 사용자 결정 필요(도장 해님으로 통일할지).
- **달력 (b 아이콘+글자)**: 달력은 어르신에게도 친숙하다(벽걸이 달력). 그러나 날짜 숫자와 글자("7일 남았어요")가 정보 본체다. 아이콘은 보조.
- **시계 (b 아이콘+글자)**: 시계는 가장 익숙한 기호다. "10분 뒤" 숫자+글자가 필수이며, 아이콘만 있으면 "시각"인지 "남은 시간"인지 모호하다.
- **와이파이 끊김 (b 아이콘+글자)**: 와이파이 부채꼴은 스마트폰 상단바에서 보지만 60~80대는 "와이파이"라는 말을 모를 수 있다. "인터넷이 연결되지 않았어요" 글자 필수. 어르신 탓이 아닌 문구로.
- **휴대폰 (b 아이콘+글자)**: 폰 모양은 직관적이다. 어르신 화면에서는 "이 폰", "새 폰" 글자와 함께 써야 어느 폰을 말하는지 명확하다.
- **말풍선 (b 아이콘+글자)**: 말풍선은 "대화/메시지"로 알려져 있다. 자녀 화면 한정, "대화 주제" 글자와 함께.
- **더하기 (b 아이콘+글자)**: +는 숫자 계산에서 알지만 "무엇을 더하나"는 글자가 말해야 한다. 어르신 화면 사용 안 함, 자녀 화면 "번호 만들기" 글자 옆.
- **불러오는 중 (a 아이콘만)**: 돌아가는 고리는 "기다리는 중"으로 널리 쓰이나, 어르신은 "멈춘 것 아닌가" 불안해한다. 반드시 글자("확인하고 있어요")와 함께, 움직임 줄이기 설정에서는 정지 상태로 대체.
