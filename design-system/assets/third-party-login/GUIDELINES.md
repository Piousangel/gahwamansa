# 카카오·구글 로그인 버튼 공식 규정 정리 (2026-11-17 확인)

출처: developers.kakao.com/docs/ko/kakaologin/design-guide · developers.google.com/identity/branding-guidelines
(우리 해석이 아니라 원문 규정. 해석이 필요한 곳은 "우리 적용"으로 따로 적음)

## 카카오
| 항목 | 규정 |
|---|---|
| 컨테이너 색 | #FEE500만 (다른 색 금지) |
| 심볼 | #000000, 형태·비율·색 변경 금지, 생략 금지, 카카오 CI·기능 아이콘으로 대체 금지 |
| 레이블 | #000000 85%, 완성형 "카카오 로그인" / 축약형 "로그인", OS 기본 서체 |
| radius | 12px |
| 가로 확장 | 심볼·레이블 영역 유지, 확장 구간 좌우 동일, 레이블 자간·크기 변경 금지. 심볼은 좌측 정렬 또는 레이블과 가운데 정렬 |
| 전체 확대 | 심볼:레이블 비율 유지, 레이블 세로 ≤ 컨테이너 세로의 1/3 |
| 작게 | 비율 억지 조정 금지 → 축약형 "로그인" |
| 금지 | 타사 버튼이 상대적으로 강조되도록 색을 임의 지정 |
| 크기·여백 수치 | 문서에 없음. 공식 PNG/PSD(리소스 다운로드)의 비율을 기준으로 함 |

## 구글
| 항목 | 규정 |
|---|---|
| G 로고 | 표준 컬러, 크기·색 변경 금지, 흑백 금지, 직접 그리기·구버전 금지. 흰/어두운/중립 배경 위에서만 |
| 테마 | Light: 면 #FFFFFF·테두리 #747775 1px(안쪽)·글자 #1F1F1F / Dark: #131314·#8E918F·#E3E3E3 / Neutral: #F2F2F2·테두리 없음·#1F1F1F |
| 글꼴 | Google Sans Medium 14/20 (현지화 허용) |
| 패딩(Android) | 로고 왼쪽 12, 로고 오른쪽 10, 글자 오른쪽 12 |
| 문구 | "Sign in/Sign up/Continue with Google" 현지화 허용·권장 → "Google로 계속하기". "Google" 한 단어만 쓰기 금지 |
| 크기 | 확대 가능하나 종횡비 유지(로고 늘림 금지). 최소 높이 수치 없음 |
| 모양 | 직사각형·알약·정사각(아이콘만) |
| 아이콘만 | G 단독 버튼 가능하나 버튼 경계 + 동작을 알리는 표시 필요 |
| 다른 로그인과 함께 | **다른 타사 로그인만큼 눈에 띄어야 함, 대략 같은 크기·비슷한 시각적 무게.** 순서 규정 없음 |

## 우리 적용 (자녀 로그인 화면)
- 카카오와 구글 버튼은 **같은 높이·같은 폭**(구글 규정: 동등한 크기·무게). 카카오를 '주 버튼'으로 키우지 않는다. 순서만 카카오 → 구글
- 높이 56dp(앱 터치 규칙) 이상, 같은 값. 카카오 레이블 높이 ≤ 56/3
- 카카오: 완성형 "카카오 로그인", radius 12, 심볼 왼쪽 정렬(공식 SVG 심볼 path 그대로)
- 구글: Light 테마, "Google로 계속하기", 공식 G(google-g-light-square.svg에서 G만), 패딩 12/10/12. Google Sans 라이선스 미확보 → OS 기본 서체로 현지화 문구(글꼴은 규정상 권장, 대체는 리스크 낮음으로 판단 — 출시 전 재확인)
- 버튼 모서리: 카카오 12, 구글도 12로 맞춰 동등하게(구글은 모양 자유)
- "이메일로 받기"는 보조 글자 링크(타사 버튼 아님)
