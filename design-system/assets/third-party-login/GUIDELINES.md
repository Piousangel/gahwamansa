## 우리 적용 (자녀 로그인 화면)
- 카카오와 구글 버튼은 **같은 높이·같은 폭**(구글 규정: 동등한 크기·무게). 카카오를 '주 버튼'으로 키우지 않는다. 순서만 카카오 → 구글
- 높이 56dp(앱 터치 규칙) 이상, 같은 값. 카카오 레이블 높이 ≤ 56/3
- 카카오: 완성형 "카카오 로그인", radius 12, 심볼 왼쪽 정렬(공식 SVG 심볼 path 그대로)
- 구글: Light 테마, "Google로 계속하기", 공식 G(google-g-light-square.svg에서 G만), 패딩 12/10/12. Google Sans 라이선스 미확보 → OS 기본 서체로 현지화 문구(글꼴은 규정상 권장, 대체는 리스크 낮음으로 판단 — 출시 전 재확인)
- 버튼 모서리: 카카오 12, 구글도 12로 맞춰 동등하게(구글은 모양 자유)
- "이메일로 받기"는 보조 글자 링크(타사 버튼 아님)

### 우리 적용(자녀 로그인 화면, iPhone만)
- **Platform 분기**: `Platform.OS === 'ios'`일 때만 그린다. Android·웹에는 없고, 그때 화면은 지금(버튼 둘)과 같다.
- 순서 카카오 → 구글 → Apple. **같은 높이·같은 폭·같은 반경·같은 글자 크기·같은 무게**(grid 같은 행). 검정 면이 가장 강하므로 마지막이어도 숨지 않는다. 눈에 띔 규정은 크기·무게로 지키고 순서에 기대지 않는다.
- 로그인 중: 세 버튼 모두 같은 비활성. Apple 시트가 떠 있는 동안에도 색을 바꾸지 않는다.
- 취소: Apple 시트에서 닫으면 알림 없이 기본으로(카카오·구글과 같은 규칙, DECISIONS의 취소 규칙).
- 글자 150%: 같은 구조. 하단 고정이 45%를 넘으면 안에서 스크롤(약관·연령 줄이 먼저 가려진다).
- **320×640 · 글자 200%**: 하단 고정을 없애고 제목 → 세 버튼 → 약관 → 연령 → 이메일을 한 스크롤로. 로고·보조 문장은 숨긴다. 버튼 문구는 어절 단위 줄바꿈 허용('Apple로 / 로그인'), 세 버튼은 같은 높이. 계산: 상단 52 + 이전 바 64 + 제목 2줄 108 + 간격 16 + 세 버튼 3×114 + 간격 24 ≈ 606 ≤ 640. 세 버튼이 스크롤 없이 첫 화면.
- 읽기 순서: 제목 → 카카오 → 구글 → Apple → 약관 → 연령 → 이메일. 읽기 이름은 보이는 문구 그대로('Apple로 로그인').
- 시안: docs/design/v3/screens/child/C0_login_ios.dc.html
- 앱 쪽: `SocialButton`은 지금 kakao/google만 안다. apple 종류 추가 + Apple 공식 자산(또는 `AppleAuthenticationButton`)로 그리되 위 크기·반경을 맞춘다(구현은 B2).
