# 결정 기록 (2026-11-25부터)

결정 하나 = 이 폴더의 파일 하나. 2026-11-25 이전 결정은 루트 [`DECISIONS.md`](../../DECISIONS.md)(그대로 보존, 더 붙여 쓰지 않음).

## 왜 파일 하나씩인가
모든 PR이 `DECISIONS.md` 끝에 붙여 쓰면, 한 PR이 병합될 때마다 다른 열린 PR이 전부 충돌한다(11-25 하루 6회+). 새 파일만 더하면 서로 다른 PR이 같은 줄을 건드리지 않아 충돌이 없다.

## 쓰는 법
1. 파일 이름: `YYYY-MM-DD-<slug>.md` (slug는 영문 소문자·숫자·`-`, 예: `2026-11-25-decisions-per-file.md`).
2. 머리 세 줄은 꼭(CI `decisions` 가 검사):

```markdown
# <결정 제목 한 줄>

- 날짜: 2026-11-25
- 관련 PR: #267 (PR을 열기 전이면 '이 PR', 없으면 '없음')
```

3. 본문은 예전과 같이: 맥락 / 선택 / 버린 안·이유 / 약점·다시 볼 조건. 한 결정을 고치거나 뒤집을 때는 원래 파일을 고치지 말고 새 파일을 만들고 "대체: <옛 파일>"을 적는다.

## 색인·최근 결정 보기
- 이 폴더 목록 자체가 날짜순 색인이다(GitHub 폴더 화면은 이름순).
- 표 색인: `scripts/decisions-index.sh` (화면 출력) / `--write` (이 폴더 `INDEX.md`, 커밋하지 않음 — 커밋하면 색인이 다시 충돌 지점이 된다).
- 최근 N개 본문: `scripts/decisions-index.sh --recent 3`. 같은 날짜끼리는 slug 알파벳 역순이라 정확한 시간 순서가 아니다.
