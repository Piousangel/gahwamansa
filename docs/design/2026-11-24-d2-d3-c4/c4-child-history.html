C-4 · 자녀 '지난 날' — 고르신 쪽이 더 눈에 띄게

오너 의견: 날짜별로 'A와 B 중 무엇을 골랐는지'가 더 눈에 띄게. 자녀 화면에는 사진·낱말이 나오지 않는다(동의 미리 보기 '사진과 자판으로 쓴 글자는 보이지 않아요', O-1). 안 고른 쪽 '흐리게'는 불투명도가 아니라 면 없음 + 보조 글자색(inkSubChild 5.96:1) + 400 굵기로 만든다 — 자녀 글자 4.5:1을 지킨다. 안 고른 쪽 글자의 확대 상한은 팻말 글자와 같은 1.5 — sub 상한 2.0을 쓰면 200%에서 안 고른 쪽(32)이 팻말(30)보다 커져 위계가 뒤집힌다. 빈 날(19일처럼 안 한 날)은 카드가 없다(11-18 U6). 질문·답은 seed 20~24일차.

안 1 · 두 칸 나란히 (권장)

'A vs B 중 무엇'이 보이나가장 잘 보임 — 두 칸이 나란히, 자리 고정고른 쪽은 잘 보이지만 'vs' 구도는 약함(다른 쪽이 작은 줄)
안 고른 쪽 흐리게면 없음 + 옅은 선 + 보조 글자(5.96:1)보조 글자 한 줄(5.96:1)
200%위아래로 쌓여 카드가 김(첫 화면 약 1.5날)카드가 짧음(첫 화면 약 2날)
긴 선택지(14자)100%에서 칸 폭 약 140 → 두 줄로 꺾임(말줄임 없음)한 줄에 들어감
노랑 개수둘 다 날짜 카드마다 팻말 1개 → 한 화면에 노랑 여러 개. R-22 '화면당 sign 1개' 렌더 검사와 충돌, R-22가 '지난 날'에 row 크기를 따로 둔 것과는 맞음 → 오너 확인 필요(아래 README 질문 3)
