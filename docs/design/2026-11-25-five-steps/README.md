### 2. ② 떠올려 보기
- 권장: BackLink → '떠올려 보기 · 2 / 5'(200%는 '2 / 5') → **사진 80 + AI 고지**(사진 이름은 ①에서 봤으므로 뺌) → 질문 → 「정답은 없어요」 → 낱말 카드 3장(세로, 최소 높이 64, 26/700) → Dock [이걸로 할게요] + 「오늘은 넘어갈게요」.
- 카드 1탭 = 테두리 5 + 면 + ✓ '골랐어요'(P5와 같음), 확정은 Dock(2탭 안전장치). 200%는 '골랐어요'를 낱말 아래 줄로(옆에 두면 '누/룽/지'로 한 글자씩 꺾임 — 1차 캡처에서 확인).
- **200%에서 「오늘은 넘어갈게요」는 카드 아래 본문으로**(P6 200%와 같은 규칙). Dock에 두면 두 줄로 꺾여 Dock이 화면 40%를 넘는다(R-12).
- 14자 보기도 카드 틀은 깨지지 않는다(320 200%에서 3줄). 실제 보기는 기획 새 규칙상 2~4음절.

### 3. ⑤ 이야기 건네기
- 권장: ②와 **같은 선택 카드**(흰 면·line 1.5·반경 6), 문장 22/400 먹, 노랑·아이콘 없음. 셋째 문장 아래 보조 줄 '구수한 숭늉 · 달콤한 식혜'. 사진 없음.
- 쓰지 않는 모양: 말풍선(메신저·답장 기대), 보내기 화살표·봉투('응원 보내기'와 겹침, 안부 앱), 하트·별(칭찬). 시안 파일에 나란히 그려 둠.
- **기획과 다른 점**: 「가족에게 건넸어요」를 ⑤ 화면의 한 줄로 두지 않고 **P7 본문 첫 줄**로 옮겼다(저절로 넘어가는 순간을 하나 더 만들지 않기 위해). 문구는 그대로.
- '골랐어요' 표시는 문장 카드에서는 늘 아래 줄(문장을 좁히지 않게).

### 4. '오늘은 여기까지 할게요'
- 권장: **B1 — 100%는 Dock 주 버튼 아래 밑줄 글자 버튼**(②~⑤의 '오늘은 넘어갈게요'와 같은 자리·모양 → '그만하는 길'은 늘 한 곳), **200%는 단계 행 바로 아래 본문**. ③을 마친 뒤부터만 보인다.
- 확인 대화상자 없음('정말 그만두시겠어요?'는 재촉으로 읽힘). P7을 닫고 돌아온 홈에서 ④·⑤ 행을 누르면 할 수 있게 열어 두기를 제안 — **구현 레인 확인 필요**(넘어감 기록 뒤 다시 기록).
- 그 뒤 P7: ⑤에서 건넨 날만 본문 첫 줄 「가족에게 건넸어요」. 여기까지로 마친 날은 그 줄이 없을 뿐 똑같다(몇 단계 했는지 말하지 않음). P7 바탕(팻말 hero)은 R-22 글을 따른 스케치이고 이 시안의 결정은 본문 줄뿐이다.
- '여기까지'로 마친 뒤 코스 홈은 다 마친 화면(C)과 똑같다(④·⑤ 넘어감도 '했어요', 기획 3.3).

### 5. 오늘 한 장
- **발견**: 5단계에서는 ④ 낱말 = ②에서 고른 낱말이라, 기획대로 '먼저 떠올리신 것: 누룽지'와 '오늘 낱말: 누룽지'를 다 두면 같은 낱말이 두 번 나온다.
- 권장: ②를 한 날은 **'먼저 떠올리신 것' 한 줄만**(오늘 낱말 줄 대신), ②를 넘긴 날은 지금처럼 '오늘 낱말 · {사진 낱말}'. 맨 아래 '건넨 말' + 문장(bodyLg 먹, 노랑 없음). 넘긴 단계의 줄은 없다.

### 6. 자녀 날짜 카드
- 지난 날(C5): 두 칸 팻말(카드당 1개, D-4 예외 그대로) 아래 옅은 구분선 + ② 「사진 보고 누룽지를 떠올리셨어요」(먹 16). 넘긴 날은 줄도 구분선도 없다(23일 카드 = 지금 카드와 똑같다).
- **권장: 목록에서는 ⑤를 뺀다 → ⑤ 건넨 말은 앨범 카드와 날짜 상세에만**(기획 6절 대안 채택). 320×640 200%에서 ②⑤ 카드 하나가 687px로 한 화면(495)보다 길다. ⑤를 빼면 465px.
- ⑤ 표시: 이름표 「엄마께서 건넨 말」(보조 회색) + 다음 줄 '문장'(먹 18). 기획은 한 줄이지만 200%에서 이름표와 문장이 섞여 꺾인다. 읽기는 기획 문장 그대로.
- 앨범(C4): 팻말 hero → '오늘' → ②·⑤ 두 줄 → '이야기 꺼내기'. 200%는 응원 버튼 본문(N-10 지금 규칙).

## 디자인 리스크
1. **5행 높이**: 100% 360×640에서도 코스 홈이 한 화면에 들지 않는다. ③ 뒤에는 '지금 할 차례' 행이 첫 화면 끝에 걸린다 → 열릴 때 지금 행으로 스크롤(구현 제안), 다 마친 화면은 도장 1개(C-나)로 158px 줄인다.
2. **200% 스크롤 길이**: 코스 홈 3.1~3.8화면, 오늘 한 장 3.4화면(320). 다섯 행이 모두 이름·상태 두 줄로 꺾이는 것이 원인이라 도장 안을 바꿔도 200%는 거의 줄지 않는다(1565 → 1500).
3. **② 100% 첫 화면**: 보기 3장 중 1장만 보인다. 질문·사진·Dock(주 버튼 + 넘어가기)가 먼저 자리를 차지한다. 줄이려면 「정답은 없어요」를 빼거나(42px) 100%에서도 넘어가기를 본문으로 보내는(60px) 안이 있는데, 둘을 다 해도 셋째 카드는 걸친다. 70대 관찰 테스트(U-4)에서 스크롤을 찾는지 확인 필요.
4. **⑤ 문장 줄 수**: 「누룽지, 오늘 그게 먼저 떠올랐어요」가 360·320 200%에서 3줄(기획 목표 '두 줄 이하' 못 미침). 320 200%에서 주 버튼 [이걸로 건넬게요]도 두 줄로 꺾여 Dock이 171px.
5. **자녀 카드 길이**: 지난 날 목록 ②⑤ 카드가 320 200%에서 한 화면보다 김 → 목록에서는 ⑤를 빼는 권장안. 앨범 카드도 200%에서 1.7~2화면.
6. 어르신 검증 0회. 브라우저 렌더 기준이며 안드로이드 줄바꿈은 구현 뒤 다시 잰다. 412폭·150%는 그리지 않았다.
