- 끝나면 네 그룹의 manifest를 `project/_manifest/<그룹명>.json`에 쓴다: `[{"file":"parent/p1_connect/P1_default.dc.html","id":"P1","state":"default","title":"P1 코드 입력 · 기본","interactive":true}, ...]`.

- **아이콘·해님·그래픽은 직접 그리지 않는다.** 전문 에셋 디자이너가 만든다. 모든 그림 자리는 눈에 띄는 점선 라벨 박스(`[해님: 기본]`, `[아이콘: 스피커]`, `[사진 자리]`)로 표시한다. 앱 `AssetPlaceholder`와 같은 규칙. 이모지 금지.
