# 디자인 v2 리뷰 준비 (2026-11-17)

캔버스: https://claude.ai/artifact/PCwUtgqZFkjBH63A2Jab3Y (본인만 열람 가능, 렌더링은 아직 아무도 확인하지 못함). 보관본: `docs/design/v2/`(`.dc.html`은 캔버스 전용 형식이라 단독 렌더링은 불가).
상태: 디자인 단계 완료(빌드 1 필수 화면 **116개**), 리뷰 단계 시작. 개발 반영은 **승인 전까지 하지 않는다**.

## 1. 완료 점검(리드가 직접 확인한 것)
- 필수 ID 19개(P0~P6, P9, P10, S1, S2, C0~C5, C8, C9) 모두 시안 있음, 총 116개(A 35 + B 30 + C 51), manifest와 파일 일치, 이름 중복·구조 이상·금지 표현·직접 그린 해님 SVG 없음.
- SCREENS.md 상태 키워드(오류 7종, 잠금, busy, 확대 150%, 삭제 범위 3종 등) 포함 확인.
- **확인하지 못한 것**: 실제 렌더링(폰트, 줄바꿈, 글자 확대 150%의 잘림), 문구의 라이터 확정, 앱과의 세부 동작 일치.

## 2. 인벤토리 보완: 놓친 화면 (리드 발견)
- **P14 연결이 끊긴 폰**: 가족 삭제나 폰 교체 재연결 뒤 이전 폰은 프로필을 잃는다. 현재 앱은 이를 일반 오류("인터넷이 끊겼어요")로 처리해 어르신이 막힌다. **시안 추가 요청 필요 + 앱 오류 처리 구현 필요**(서버는 `parent_required`/`no_profile`을 이미 돌려줌). SCREENS.md에 추가함.
