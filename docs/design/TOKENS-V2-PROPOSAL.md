상태: **제안**. 사용자가 방향(로바 기준)에 동의했고, 값·폰트·버튼 형태 승인 전이다. 매핑 파일: `docs/design/tokens-v2.json`.

## 3. 새로 생기는 위험 (반드시 읽기)
1. **주 버튼(갈색)과 위험(빨강)의 명도 대비가 1.21로 거의 같다.** 색만으로는 구분되지 않는다(색각 이상 포함). 삭제 화면은 색 외에 **모양(위험은 외곽선, 주 버튼은 채움), 굵은 경고 박스, 문구**로 구분한다. 시안의 삭제 화면은 이미 이 구조지만 QA가 확인해야 한다.
2. **해님 노랑·주황 포인트가 줄어든다.** 행동 색이 주황에서 갈색으로 바뀌어 전체가 차분해진다. 활기가 줄어 "따뜻하다"로 읽히는지는 사용자와 어르신 관찰로 판단해야 한다(시안으로 대비 확인 가능).
3. **연한 면 위 보조 글씨 대비가 4.68~5.02로 여유가 작다.** 보조 글씨 크기를 줄이지 않는다(20px 이상 유지).
4. 갈색 한 가지로 글씨와 버튼을 모두 처리하면 **위계가 약해질 수 있다.** 제목은 더 진한 갈색 `#4E2F14`(배경 10.90)를 쓰는 선택지를 열어 둔다(제안, 미적용).

## 4. 버튼과 형태 (로바 형태 반영, 수치는 우리 기준 유지)
- 알약형 반경 36 유지(이미 동일). 그림자는 단단한 하단 그림자(`0 4px 0`) 대신 **로바식 부드러운 그림자**(`0 4px 12px rgba(116,72,33,0.18)`)를 제안한다.
- 눌림(pressed) 상태: 배경이 `#744821` → `#5A3716`로 바뀐다(로바의 "터치 시 색 변화" 반영).
- 비활성: 면 `#ECE8E3`, 글자 `#6B5C4A`(로바의 회색 버튼 느낌).
- 물결 구분선: 앨범 스티치 장식으로 쓸 후보다. **그림이므로 에셋 디자이너 몫**이고 개발용으로는 라벨 박스로 둔다.

## 5. 폰트 (결정 대기)
| 용도 | 현재 | 로바 후보 | 비고 |
|---|---|---|---|
| 제목·버튼 | Jua | 이사만루 Medium | 라이선스 미확인, 앱은 웹폰트(CDN)가 아니라 **폰트 파일 번들** 필요 |
| 본문 | Noto Sans KR | 인피니티산스 Regular | 라이선스 미확인 |
| 날짜·사진 설명 손글씨 | Nanum Pen Script | 유지 | 로바 가이드에 없음 |
- 이사만루 Light는 가늘어서 어르신 본문에는 쓰지 않는다(큰 제목 장식용만 후보).
- **사용자가 눈누 페이지에서 상업 이용 라이선스를 확인해 주기 전까지 시안은 기존 폰트를 유지한다.**

## 6. 적용 순서 (승인 후)
1. 이 제안서와 전/후 비교 캔버스에서 사용자가 값 승인.
2. `tokens-v2.json`의 색 매핑으로 시안 116개를 일괄 치환하고 디자이너가 검수, 캔버스 재게시.
3. 앱은 시안 승인 뒤 `app/src/ui/tokens.ts`를 갱신하고(개발 반영 단계), 폰트는 라이선스 확인 후 번들.
