# UX 감사: 부모와 자식 디자인 v2 시안 116개 (2026-11-17)

감사 기준: DESIGN-SYSTEM-PLAN §0 질문 5개·§1 글자 규칙, copy.ko.json, writer.md, policy.md, SPEC.md. 대상: `docs/design/v2/` parent 45 + child 51 + common 7 + 그 외 포함 116장(Main.dc.html 제외). 방법: 116개 전부에서 문구·글자 크기를 추출해 전수 점검, 대표 화면 15장은 레이아웃 코드(높이·overflow)를 직접 읽음. **렌더링은 하지 못했다.** 줄바꿈·높이는 "추정"(한글 1em·공백 0.3em으로 계산)이고, 코드에서 직접 확인한 것만 "확인"이라 썼다.
가정: 어르신 화면 폭 390, 콘텐츠 폭 342. 자녀 화면 콘텐츠 폭 350. 시안의 `[해님]`·`[아이콘]` 자리표시와 `[문구 확정 필요]` 라벨은 출시 전에 사라진다고 본다.

## ① 요약

### 출시 차단 Top 10
1. **첫 실행에 "어르신/자녀" 고르는 화면이 없다.** REVIEW D10은 선택을 P0에 두기로 했는데 P0는 2장뿐이고 선택이 없다. C0에서는 "어르신이세요? 번호 입력하기"를 지우기로 해 놓고 시안에는 4장 모두 남아 있다. 새로 설치한 70대는 P0_restore_failed에서 "다시 연결해 주세요 / 저장된 연결을 찾지 못했어요"를 읽는다. 처음 쓰는데 고장 난 것처럼 읽힌다.
2. **응원 도착 화면이 없다(P8).** 자녀 화면은 "엄마 폰에 응원이 도착했어요"(C4_cheer_sent)라고 약속하지만, 어르신 화면 116장 어디에도 응원이 표시되지 않는다. 자녀는 보냈다고 믿고, 어르신은 받은 적이 없다.
3. **한글 줄바꿈 방지가 0건이다(확인).** `keep-all`·`word-break`가 116장 모두에 없다. 수작업 `<br>`도 150%에서는 소용없다. "번호를"이 "번 / 호를"로, "괜찮아요"가 "괜찮아 / 요"로 끊길 수 있다(추정, §②-1 표).
4. **글자 150%에서 스크롤이 없는 화면이 많다.** P4·P5·P6·P9는 높이 844 고정에 스크롤 영역이 없다(확인). C0~C4, C8, C9는 `overflow-y:hidden`이라 넘치면 잘린다(확인). 확대한 어르신이 가장 많이 쓰는 사진·질문·한글 단계에서 버튼이 화면 밖으로 나간다(추정).
5. **동의 화면(P2)이 자녀에게 보이는 것을 다 말하지 않는다.** 자녀 홈은 "참여 여부·단계별 완료·연속일"을 어르신이 거부해도 보여 준다(C4_declined). 그런데 P2는 "고른 답"만 말하고, 거부 안내(P2_declined)도 "답이 저장되지 않아요"라고만 한다. 어르신은 자기가 하루에 뭘 했는지까지 자녀가 본다는 걸 모른 채 앱을 쓴다. 감시처럼 느껴지는 지점이고 policy.md의 "범위·철회" 요건과도 어긋난다.
6. **지우기가 위험한 자리에 있고 설명이 부족하다.** P3 메인의 "내 기록 지우기"(20px 밑줄 링크)가 64~72px 큰 버튼 바로 아래 12px 간격에 붙어 있다. 오른 엄지로 "이어서 하기" 대신 누르기 쉽다(추정). P9는 "데이터 지우기"라는 영어식 제목에 "지금까지 고른 답과 기록이 지워져요"뿐이다. 자녀에게서 사라지는지, 연결이 끊기는지, 도장이 없어지는지 말하지 않는다. P10 "내 기록이 지워졌어요" 다음 안내도 없다.
7. **삭제 버튼 위계가 어르신과 자녀에서 반대다.** P9는 "그만둘래요"가 큰 주 버튼(REVIEW D5 채택)이다. C8_child_1·C8_family는 빨간 "삭제하기"·"네, 삭제할게요"가 주 버튼이고 "그만둘래요"는 흰 외곽 버튼(확인). C8_preview_failed는 그만둘래요가 16px 링크로 가장 약하다. 같은 앱에서 반대로 학습하게 한다.
8. **코드 5회 실패 구간이 막다른 길이다.** P1_locked는 "남은 시간 4:32"(분:초)를 보여 준다. D4가 채택한 "N분 뒤" 올림 방식과 모순이고, 쳐다보는 동안 줄어드는 시간이 어르신에게 재촉이 된다. 실패 4회까지 경고가 없고, 오류 화면(invalid·used·expired)에는 "번호가 없어요" 도움 경로가 없다. 잠금의 "알겠어요"가 어디로 가는지도 시안에 없다.
9. **연결 수명 주기 화면이 비어 있다.** 호칭 설정(엄마/아빠) 화면이 없는데 시안은 "엄마"를 고정하고, 같은 화면에서 "어르신"과 섞어 쓴다(C4_declined 제목은 "엄마의 앨범", 안내는 "어르신이…"). 재연결 진입점이 없다(C5에는 로그아웃·계정 삭제뿐, C7 없음). 어르신 폰 앱 설치 안내가 없다. P14(끊긴 폰)·P11(새 폰)도 없다.
10. **어르신에게 나가는 문구에 오류가 남아 있다.** P6 `"나무" 이라고 읽어요`(조사 오류, 따옴표·공백도 어색). P1 not_parent_device는 어르신에게 "어르신 폰에서 써 주세요"라고 한다. 자녀가 어르신 폰에 직접 설치해 자녀 계정으로 열었다면 그 폰의 사용자는 어르신이므로 "나는 지금 어르신 폰인데?" 하고 막힌다. writer.md 7번 "아직" 금지를 어르신 화면이 어긴다(P3_no_content "오늘 사진이 아직 없어요", P4 "사진이 아직 안 보여요").

### 가장 큰 구조 문제 3개
- **A. 사람이 거쳐 가는 "연결의 일생"이 화면으로 설계되지 않았다.** 처음 시작(역할 선택)·응원 받기·폰 바꾸기·연결 끊김·호칭·설정이 모두 빠져 있고, 있는 화면(P1~P6, C0~C5)은 "잘 되는 하루"만 그린다. 사용자는 막힐 때마다 시안 밖으로 떨어진다.
- **B. 어르신 홈(P3)이 한 화면 한 일을 어긴다.** 날짜, 해님 말풍선, 연속일, 도장 7칸, 코스 카드 3개, 큰 버튼 2개, 읽어 주세요, 삭제 링크가 한 화면에 있다. F4 결함(카드 3 + 버튼 2 + 링크)이 그대로이고 "지금 할 일 하나"로 바뀐 흔적이 시안에 없다.
- **C. 어르신이 아는 것과 자녀가 보는 것이 같지 않다.** 어르신은 "답"만 공개된다고 믿고, 자녀는 단계별 완료·연속일·"아직이에요"까지 본다. 자녀의 "아직이에요"는 독촉 전화로 이어질 수 있고, 그러면 어르신은 감시당한다고 느끼며 앱을 끈다. 서비스 목표(대화 늘리기)를 정면으로 해친다.

### 3. 버튼·문장·기호 규칙 위반
- **동사 하나가 아닌 버튼:** "네, 삭제할게요", "네, 지울게요", "그만둘래요", "하나를 골라 주세요"(안내문이 버튼 자리), "나중에 하고 홈으로"(동작 둘), "로그인 중이에요 · 잠시만요", "만들고 있어요 · 잠시만요", "보내는 중 · 잠시만요", "어르신께 보냈어요 · 연결 기다리기"(링크, 동작 둘), "번호 만들기를 그만두기". 상태 문구가 버튼 라벨 자리에 있어 "누를 수 있나?"가 흐려진다(C4 "보냈어요" 비활성 버튼 포함).
- **명사형/동사형 혼용:** "홈으로 가기"·"번호 복사"·"카톡으로 보내기"(명사형) vs "복사했어요"·"다시 하기". 어르신 쪽은 "다 봤어요"·"정했어요"·"다 썼어요"처럼 일관됨(좋음).
- **'·' 남용:** "1단계 · 사진 보기", "1 / 3", C8 "· 가족 연결 · 엄마 폰은 다시 연결해야 해요"(목록 점과 구분 점이 같은 줄에). PLAN §1과 TTS 읽기 기준에서 기호는 최소여야 한다. P4~P6 헤더 "1단계 · 사진 보기 + 1 / 3"은 같은 정보를 두 번 쓴다.
- **어르신 문장 20자 초과:** P1 "자녀분 앱에서 '번호 만들기'를 누르면 받을 수 있어요"(30자·따옴표), P4 "사진이 아직 안 보여요. 조금 뒤에 다시 와 주세요"(2문장), P2_declined 2문장 28px. 자녀 화면은 한 문장 40자 이내 규칙인데 C2_reconnect 안내가 48자 이상 + 두 문장.
- **'틀려도 괜찮아요' 위치:** P1 invalid의 "숫자를 다시 확인해 볼까요? 틀려도 괜찮아요"는 방금 틀렸다고 알린 직후 반복되어 오히려 틀렸다는 사실을 강조한다(낮음).
- **높임말:** 대체로 해요체 일관(좋음). C9 "삭제되었어요"와 C0 "계속하면 … 동의한 것으로 봐요"(약관 문장이라 이질)가 어색. 시안에 반말 없음.
- **숫자:** 6자리 번호를 writer.md는 "3자리씩 띄워(482 915)"라고 했는데 P1 입력 칸은 6칸 균등, C3_waiting은 `482916` 붙여 쓰기, C2는 44px 6칸 분리. 일치하지 않는다. P1_locked "4:32"는 시계처럼 읽힌다.

### 4. 글자 크기 (확인: 코드 추출)
- 자녀 화면 본문의 최소는 16px이고 11~13px도 쓰인 곳이 있다(요일·상태 글자 16px, C5 "곧 유료" 배지 16px). 50대 자녀도 안경을 벗고 보는 시간대(아침 출근길)가 있다. C4 안내("엄마가 고르면 여기에 보여요", "다른 문구 8개 보기")가 16px이라 설계 기준(본문 16 이상)의 하한이다.
- 어르신 화면에서 20px 이하는 보조 글(20px 밑줄 링크 "내 기록 지우기", P3 카드의 "했어요"·"지금 할 차례" 20px, 도장 요일 20px)이다. 카드 상태가 가장 필요한 정보인데 가장 작다.

### 5. 접근성 구조
- P5·P6·P9의 큰 버튼이 `<div role="button">`이다(확인). 시안 포맷이라 앱 구현과 다를 수 있으나 TalkBack 라벨·포커스 순서가 시안에 없다(미확인).
- 색만으로 구분하지 않는 규칙(S2_rules 6번)은 오류·완료·선택에서 지켜졌다(좋음). 단 P3 도장·코스 카드의 "완료/지금/대기" 구분은 20px 글자에 의존한다.
- 모든 상태 시안(예: P1_checking)에서 로딩이 `[아이콘: 로딩]` 자리표시뿐이라 움직임 감소(동작 줄이기) 대응은 S2_loading_skeleton만 명시한다.

## ④ 흐름별 막다른 길과 불안한 순간
**흐름 1 어르신 첫 연결: P0 → P1 → P2 → P3 → P4 → P5 → P6 → P7 → P3**
- P0에서 갈라지는 길이 없다(Top 1). P0 → P1 이동 근거가 "복원 실패"뿐이다.
- P1 입력 4회까지는 아무 경고가 없다가 5회째에 잠긴다. 잠긴 동안 어르신에게는 자녀에게 물어볼 안내도 없다.
- P1 성공 → P2 사이에 "연결됐어요"가 없다. 어르신은 번호를 쓰고 곧바로 낯선 동의 질문을 받는다.
- P2는 한 번 "싫어요"를 누르면 되돌릴 입구가 P3의 작은 카드 하나뿐이다. "싫어요"를 눌러야 앱을 쓸 수 있다고 오해하는 사용자가 있을 수 있다(추정).
- P3 → P4: 시안 링크가 존재하지 않는 `P4_photo.dc.html`을 가리킨다(확인, 링크 12개). 캔버스에서 눌러 보면 이동하지 않는다.
- P4~P6에는 나가는 길이 없다. 점심 먹으러 가야 하는 어르신이 중간에서 나오는 방법은 OS 뒤로 가기뿐이다. 나가면 진행이 저장되는지도 시안에 없다.
- P6 → P7은 화면이 없다. 코스를 마친 순간의 기쁨이 일반 화면 문구로 대신된다. 도장 소리·움직임 없이 사라진다.
**흐름 2 자녀 첫 사용: C0 → C1 → C2 → C3 → C4**
- C0 → C1 사이는 카카오 로그인 심사·동의항목(미확인). C1은 버튼 하나 더 눌러야 함.
- C2에서 "카톡으로 보내기" 후 어르신 폰에 앱이 없으면 아무 일도 안 일어난다(설치 안내 없음).
- C3 대기가 길어질 때(어르신이 며칠 뒤에 입력): 알림 없음, 자녀가 앱을 다시 열어야 상태가 보인다. 폴링은 REVIEW D14 제안뿐.
- C3 → C4_empty에서 같은 "번호 만들기" 버튼이 또 나와 새 번호를 만들게 된다(번호 5개 한도에 가까워짐).
**흐름 3 폰 교체 재연결: C7 → C2(재연결) → P1 → P3**
- C7이 없다. C2_reconnect에 이르는 길이 시안에 없다.
- 어르신 새 폰에서 P1 → P2를 다시 거치는지, "기록이 이어졌어요" 안내가 있는지 시안이 없다(P11).

## ⑤ 기획 제안 (결정은 사용자 몫)
1. **자녀에게 보이는 것의 한계를 어르신 화면에 그대로 쓴다.** "고른 답"과 "오늘 했는지"만 보인다면 P2에 그 둘을 쓰고, 단계별 칩("사진 완료/질문 진행 중/글씨 대기")은 빼는 쪽을 권한다. 감시 느낌은 단계 칩에서 가장 크다.
2. **자녀 홈의 "아직 안 했어요"를 없앤다.** writer.md 규칙대로 "오늘은 쉬셨어요"만. 독촉이 되는 순간 부모는 쓰지 않는다.
3. **어르신이 받는 응원 화면(P8)을 코스 시작 전 한 장으로.** "아들이 응원을 보냈어요" + 고마워요 한 번 누르기. 자녀가 "읽었어요"를 볼 수 있으면 대화가 시작된다. 지금 시안은 보내기만 있고 받기가 없다.
4. **P4의 회상 질문 2개를 어르신-자녀 대화로 잇는다.** 지금은 어르신이 답할 곳도, 자녀가 볼 곳도 없다. 질문 하나로 줄이고 "오늘 이 이야기를 전화로 해 보세요" 같은 안내를 자녀 화면에도 보인다.
5. **어르신의 손글씨를 선택 공유.** 자녀에게 가장 감동이 큰 장면은 "엄마가 쓴 '나무'"다. 지금 자녀 화면에는 글씨 완료 칩뿐이다. 동의 항목이 늘므로 정책 확인 필요.
6. **도장은 끊김 없이.** 연속일이 끊기면 상실감이 크다. 총 N일을 함께 보여 주면 "며칠 쉬었다 돌아온" 사용자를 덜 벌한다(P3_stamps_0의 권유 톤은 좋음).
7. **"곧 유료"가 핵심 가치에 붙지 않게.** 대화 주제 추천을 가리는 표시는 자녀에게 "곧 막힌다"는 압박이다. 무료 기간 동안 라벨 위치를 재검토(C6 시안은 범위 밖).
8. **설정 화면(C7)과 호칭.** 호칭, 재연결, 로그아웃, 삭제, 알림 시간이 한곳에 있어야 한다. 지금 C5 아래 링크 둘이 그 역할을 억지로 한다.
9. **지나친 기능:** C2_multiple의 번호 5개 관리는 자녀 대다수에게 복잡하다. 한 번에 하나만 보이게 하고 나머지는 접는다. C4 "다른 문구 8개 보기" 시트는 3개로 줄이거나 최근 사용을 먼저.
10. **빠진 기능:** 푸시 권한(P12, 빌드 2), 어르신 앱 설치 안내, 소리 자동 읽기 선택, 글자 크기 앱 안 설정(OS 확대에만 의존).
