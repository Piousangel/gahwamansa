# 화면 시안 v3 작업 지시서 (2026-11-17)

목적: 보드 결론(`docs/team/board/DECISION-MEMO.md`)과 사용자 결정에 맞춰 **빌드 1 구현 화면**만 새 디자인 시스템(안2 균형)으로 다시 그린다. v2 116장은 `docs/design/v2/`에 보존(수정 금지). 116장 전부를 옮기지 않는다: 아래 범위만.

## 반드시 따를 것
- 디자인 시스템: `design-system/tokens-v3.json`, `design-system/components/README.md`(컴포넌트 14종·표준 화면 틀·한국어 규칙), `design-system/assets/{icons,character,album}`. 개성은 **안2**: 스티치 구분선 2곳, 테이프 2곳(폴라로이드·"지금 할 차례" 라벨), 해님 도장 3종. 종이 결·모서리 꽂이·손글씨 메모 금지. 손글씨 폰트는 짧은 장식 문구에만, 날짜·연속일은 본문 글씨.
- 규격: 폰 390x844 아트보드, 어르신 본문 20 이상·주요 버튼 64 이상·화면당 주요 버튼 3개 이하·대비 4.5:1, 루트에 `word-break: keep-all`, 표준 화면 틀(상단 고정/스크롤 본문/하단 고정이 겹치지 않는 형제). 자리표시 라벨 박스 금지: 아이콘·해님·도장·테이프는 assets의 SVG를 인라인.
- 문구: `docs/team/board/r2/writer.md` 하단 확정 문구 표와 `docs/team/copy.ko.json` 우선. 없는 문구는 시안에 임시로 쓰고 화면 파일 상단 주석과 매니페스트에 "라이터 확정 필요"로 표시. 금지어: 아직·못 했·미완료·N일째·틀렸. "치매 예방/치료" 효과 표현 금지. 용어 "지우기" 통일. 자녀 화면에 "어르신" 금지(호칭 변수 `{호칭}`, 기본 "부모님", 조사 붙이지 않는 구조).
- 자녀 홈은 새 구조: "{호칭}의 최근 답 / 선택지(큰 글자) / 날짜 / {선택지} 이야기를 해 볼까요?". 칩·연속일·참여·완료 여부·"오늘 했는지" 없음. 빈 상태 "고른 답이 생기면 여기에 보여요", 동의 거부 "답을 나누지 않는 중이에요".
- 동의 거부 어르신도 앱은 계속 쓸 수 있다("괜찮아요. 앱은 그대로 써요"), 철회 시 저장된 답 삭제. 어르신 설정은 호칭 없음·지우기·동의 철회/다시 동의 3개.
- 토스 트랙은 토스 내비게이션 바(라이트 모드)가 상단을 차지한다. 상단 바를 자체로 그리는 화면에는 토스 바 영역(56px)을 비워 두는 변형을 1장씩 포함하지 말고, 매니페스트에 "토스에서는 상단 바 생략" 메모만 남긴다.
- 상태 누락 금지: 각 화면의 필수 상태(기본·로딩·오류·빈·150% 확대 대표 1~2장)는 `docs/design/SCREENS.md`의 화면별 상태 칸을 따르되 빌드 1 범위로 줄인다.
- 링크: 아트보드 간 `<a href>`는 실제 존재하는 파일만 가리킨다(v2의 `P4_photo.dc.html` 죽은 링크 재발 금지).

## 산출 규칙
- 각 화면 `.dc.html` 1파일(상태가 여럿이면 상태별 아트보드 또는 한 파일 안에 상태 변형 나란히), 담당 폴더에 `_manifest/<담당>.json`(화면 ID·파일·상태·사용한 컴포넌트·임시 문구·미확인) 과 `_notes/<담당>.md`(결정·한계·사용자 확인 필요) 기록.
- 렌더링을 직접 못 봤으면 못 봤다고 쓴다. 가로 넘침·잘림은 헤드리스 Chrome으로 폭 320/390에서 측정해 보고한다(스크립트 위치: 기존 디자이너가 쓴 `bumo-ds/gen/` 참고).
- 파일 소유: 자기 담당 폴더만 수정. `design-system/`, `docs/`, `app/`, `supabase/`, `toss/`는 읽기만. 커밋·게시 금지(리드가 함).
