## 시안 보정 (리드 결정 ①, 2026-11-17)
- P1 시안을 상단 "이전" 바 + 하단 고정 영역(이유 줄 / 주 "다음" / 링크 줄 "번호가 없어요"·"코스 보기")으로 보정했다. 번호 칸·키패드는 README §19(a) 규격(오목 입력칸, 판 위 볼록 키)으로 바꿨다. 위가 늘어난 만큼 제목을 28로, 키패드 판 안쪽을 8로 줄여 100%·폭 390에서 키 4줄이 스크롤 없이 들어간다(측정). 폭 320·100%에서는 마지막 키 줄 일부가 본문 스크롤 아래로 간다(남은 문제).
- 1차 판정 #7~#9는 §19 이전 규격으로 적은 것이라 정정했다(위 표).
