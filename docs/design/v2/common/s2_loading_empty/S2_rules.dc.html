[시안 메모] S2 로딩·빈 상태 규칙(해님 등장 제한) · 개발·에셋 전달용 규칙표
로딩 · 빈 상태 규칙
1
로딩 = 해님 없음
로딩 표시와 "잠시만요"만. 3초가 넘어도 재촉하는 말은 쓰지 않아요
2
빈 상태 = 해님 위로 한 줄
제목 1줄, 설명 1줄, 버튼 1개("다시 보기"). 큰 해님은 화면에 1개
3
오류 = 해님 걱정
앱이 주어인 문구, 버튼은 "다시 하기". 사용자를 탓하지 않아요
4
해님 금지 자리
사진 위, 쓰기 영역, 동의·삭제 화면, 버튼 안
5
버튼은 눌러도 안전
확인 중에는 "잠시만요"로 바꾸고 비활성
6
색만으로 구분 금지
오류 = 빨강 테두리 + 제목 글자, 완료 = 초록 + 체크, 선택 = 주황 + 체크
