- 큰 버튼: 어르신은 "눌렀나?"가 가장 불안하다 → 눌림은 즉시 색이 바뀌고, 비활성은 이유를 글자로 알림. 주 버튼은 한 화면에 1개.
- 위험 버튼: 갈색 주 버튼과 빨강의 명도가 거의 같다(1.21) → 채우지 않고 외곽선 + 경고 아이콘 + 문구. 안전한 선택이 위·채움.

- 도장 줄: 끊김을 말하지 않음(점선 칸만), 숫자는 서버 값.
- 대화상자: 어르신은 밖을 잘못 눌러 닫힘/선택되는 일이 잦다 → 밖을 눌러도 닫히지 않고 X 없음. 배너는 자동으로 사라지지 않음(읽는 속도가 느림).

- 표준 틀: 카드가 버튼 뒤에 숨는 건 어르신에게 "없는 것"이다 → 구조적으로 겹칠 수 없게 분리. 한 화면 한 일은 큰 버튼 1개로 구현.
