# 아이콘 작업 노트 (A2)

## 산출물
- SVG 35개 + 굵은 변형 35개: design-system/assets/icons/ , icons/bold/
- 시트 4개: icons_sheet_overview / states / grammar / usage (.dc.html)
- 문법·인벤토리·분류 전문: design-system/assets/icons/README.md

## 문법 근거 요약
24 격자, 중심선 4~20, 선 2.5·3.5, 둥근 끝, 외곽선형 통일(이유는 README §1). 3.5의 근거는 "틈이 막히기 직전"이라는 도형 계산이며 실제 어르신 시험 결과가 아니다.

## 분류 결과
a: 체크(완료), 꺾쇠(더 보기), 닫기, 불러오는 중 / c: 로그아웃 / 나머지 b. 어르신 화면에서 쓰지 않는 아이콘은 README 표 참고.

## 가정
1. 앱은 24px 격자 SVG를 react-native-svg로 쓸 수 있다고 가정(번들·호환은 앱 개발 검증).
2. 눌림·비활성 색은 토큰 확정(A5) 전 임시값(#4D2E12, #EADFCF, #A67C5A).
3. 와이파이·별·가족 등 자녀 전용 아이콘은 어르신 화면 규칙(R5)에 따라 쓰지 않는다.
4. 시트의 비율·글꼴은 기존 시안과 같은 구조를 따랐고 support.js는 이 폴더에 없다(리드 환경에서 연결).

## 미확인
- 리드 렌더링 확인 전. 에이전트가 headless Chrome으로 한 번 훑었으나 시각 판단은 장담하지 않는다.
- 굵은 3.5에서 틈이 막히는 곳: 경고(느낌표 두 점이 붙음), 사진(해 점 생략), 와이파이 끊김(사선과 호가 겹침), 가족(두 사람이 붙어 얼굴 두 개처럼 보임), 종 끔(사선), 설정.
- 가족·와이파이 끊김은 형태 자체가 약해 재작업 후보 1순위.
- 24px 실제 기기(저해상도) 판독, 150% 글자 확대 레이아웃 균형.
- 60~80대 실제 인식 시험은 하지 않았다. 분류 a/b/c는 디자이너 판단이다.
- 스피커 재생 중 파동 애니메이션과 움직임 줄이기 대응은 구현에서 정해야 함.
- 시트 .dc.html이 x-dc 런타임에서 열리는지(support.js 없이는 확인 불가).

## 사용자 결정 필요
1. 연속일은 해님 도장으로만 할지, 별 아이콘(자녀 화면 보조)을 둘지.
2. 로그아웃(c)과 정보(i)를 아예 쓰지 않고 글자로만 할지.
3. 하단 탭 라벨 "홈·리포트"는 외래어. "오늘·기록" 같은 한글로 바꿀지(라이터와 협의).
