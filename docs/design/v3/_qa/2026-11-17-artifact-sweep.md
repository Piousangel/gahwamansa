# 전 화면 렌더 점검 (2026-11-17, 디자인 리드)

방법: 헤드리스 Chromium(Playwright)으로 각 시트를 열고 모든 폰 아트보드를 폭 320×640 · 360×780 · 390×844 · 412×915 · 430×932로 바꿔 측정·스크린샷. 새 시트는 생성기가 모든 상태를 글자 100·150·200%로 따로 만들어(본문 2.0 상한, 28 이상·버튼 1.5 상한) 같은 5폭에서 쟀다.
자동 측정: 가로 넘침(아트보드 밖으로 나간 요소), 세로 잘림(스크롤 없는 상자에서 넘친 글), 글자 잘림, 하단 고정 영역 비율·주 버튼이 하단 영역 안에 보이는지.
눈으로 본 것: 새 시트 전부(5폭 중 320·360 또는 390·412 렌더)와 고친 기존 시트(아래 표 '본 렌더'). 스크린샷은 세션 작업 폴더에 있고 저장소에는 넣지 않았다(용량).
