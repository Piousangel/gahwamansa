# 자녀 화면 디자인 품질 관문 (2026-11-17)

대상: `docs/design/v3/screens/child/` 13파일, 아트보드 45장(C2_codes 3장은 빌드 1 제외지만 함께 점검).
방법: 헤드리스 Chrome. 아트보드를 기기 폭·높이로 바꿔(320x640, 360x780, 390x844, 412x915, 430x932) 글자 100·150·200%로 다시 생성해 측정하고 스크린샷을 찍었다. 측정 항목은 가로 넘침(왼쪽·오른쪽), 하단 고정 영역(버튼·탭) 잘림, 본문 높이 60px 미만, 시트 위쪽 잘림. 단어 쪼개짐·과부·위계는 스크린샷을 눈으로 봤다.
스크립트: 세션 scratchpad `childgen/qa.py`(생성기 `screens.py`·`lib.py`). 저장소에는 넣지 않았다.

## 결과 (최종 회차)
칸 값: 문제 수 / 본문이 스크롤되는 아트보드 수(45장 중). 스크롤은 실패가 아니라 "본문만 스크롤"이 맞게 동작한다는 뜻이다. 주 버튼은 모든 칸에서 화면 안에 있다.

|---|---|---|---|
| 320 x 640 | 0 / 25 | 0 / 40 | 0 / 43 |
| 360 x 780 | 0 / 5 | 0 / 26 | 0 / 33 |
| 390 x 844 | 0 / 1 | 0 / 16 | 0 / 28 |
| 412 x 915 | 0 / 0 | 0 / 11 | 0 / 26 |
| 430 x 932 | 0 / 0 | 0 / 4 | 0 / 23 |

## 눈으로 본 스크린샷
- 원본 크기 390 x 844(100%·대표 150%): 13파일 전부.
- 매트릭스 축소 시트(아트보드 45장씩, 칸마다 2장): **15칸 전부(30장)를 최종 회차 또는 바로 전 회차에서 눈으로 봤다.** 마지막 회차 수정(상단 바 제목 묶음·C5 답 줄바꿈)이 닿는 C5·상단 바는 150%x360에서 다시 확인했다.
- 하단 고정 영역 40% 이하는 측정 항목에 넣어 15칸 모두 통과(넘치면 영역 안에서 스크롤, 주 버튼은 맨 위라 항상 보임).

## 남은 한계(눈으로 본 어색함, 그대로 둠)
- 200%에서 "되돌릴 수 없어요"가 "되돌릴 / 수 없어요"로 나뉠 수 있다(C8). 묶으면 폭 320에서 넘치므로 200%에서만 풀었다.
- C2 번호 카드의 "7일 동안 쓸 수 있어요"는 200%·412 이상에서 시계 아이콘 옆 두 줄("쓸 수 / 있어요")이 된다. 읽는 데 지장은 없다.
- 320x640 200%는 본문이 짧게 보이고 대부분 스크롤된다(43/45장). 주 버튼은 모든 칸에서 보인다.
- 확대 규칙(본문 2.0, 큰 제목·버튼·번호 칸·탭·바·시트 머리·토스트 1.5)은 앱 커밋 00154d3과 같은 값으로 확정.
- NBSP 묶음은 앱(RN)에서 문구 데이터로 처리해야 한다. 폰트는 Google Fonts(Jua·Noto Sans KR)로 렌더했다. 실제 폰 확인은 앱 단계 QA 게이트에서 한다.
- C2_codes(빌드 1 제외)는 150%·200%에서 번호가 두 줄로 나뉜다. 빌드 1 밖이라 고치지 않았다.
