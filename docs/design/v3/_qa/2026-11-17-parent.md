# 어르신 화면 품질 관문 · 2026-11-17 (3차 수정)

범위: docs/design/v3/screens/parent/ 12개 파일(P0~P10, P13), 아트보드 전부.
방법: 헤드리스 Chrome으로 측정. 각 파일의 모든 보드를 확대 배율(100·150·200%)로 강제 생성한 뒤 폭 320·360·390·412·430에서 쟀다(12파일 × 3배율 × 5폭 = 180회, 실패 0회).
- 넘침: 보드 밖으로 나간 요소(장식 SVG 안쪽 경로 제외)
- 잘림: 버튼·키 글자가 버튼 밖으로 나감(scroll > client)
- 쪼개짐: 한 단어가 두 줄에 걸침(단어별 Range 측정)
- 과부: 마지막 줄이 1글자
- 하단: 하단 고정 영역이 화면 높이의 40% 초과, 또는 주 버튼이 화면 밖
- 본문 세로 스크롤은 150·200%에서 설계상 허용한다(본문만 스크롤하고 아래쪽은 페이드로 이어짐을 알림). 주 버튼은 모든 조합에서 화면 안에 있다.

눈으로 본 것: 12개 파일의 폭 390 시트 전체(아트보드 86장, 100·150·200% 보드 포함)를 렌더해 행별로 직접 봤다. 고친 뒤에도 다시 찍어 전부 다시 봤다. 폭 320·360·412·430은 측정만 했고 스크린샷으로 보지 않았다.

## 남은 문제
1. P3 3/3 말풍선 "오늘 코스는 여기까지예요. 내일 또 만나요"가 150·200%, 폭 320·360에서 "여기까지예요."가 두 줄로 쪼개짐. 해님·말풍선은 회의 결정 대기라 이번에 손대지 않음(말풍선 폭 또는 문구 길이로 해결 필요).
2. 가정: 24px 이상 큰 글자(제목·버튼)는 200%에서 1.5배까지만 커지는 것으로 그렸다(안드로이드 14 비선형 글자 확대 방식). 본문 20~22px는 그대로 2배. iOS·토스 웹뷰의 실제 배율은 실기기에서 확인 필요(QA 게이트).
3. 200%에서 P4 회상 질문, P5 선택 카드, P2 동의 셋째 줄은 첫 화면에 안 보이고 본문을 스크롤해야 보인다(페이드로 단서만 줌). 어르신이 스크롤을 알아차리는지 미확인.
4. 확인 상자 보드(P9 2단계, P13 2장)는 뒤 화면 버튼까지 세면 주요 버튼 4개(실제 누를 수 있는 것은 2개).
5. 폭 320·360·412·430은 측정만 했고 눈으로는 390만 봤다.
