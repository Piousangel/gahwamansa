# W1·W2 구현 예정 기능 시안 완비 점검 (L5, 2026-11-18)

- 기준: main f876ed6 copy.ko.json(push.*·tts.*·bgm.*·app_info.*).
- 판정 표기
  - ✓있음: 시안에 이미 있음
  - ✓보완: 이번에 보드를 추가함
  - 메모: 화면이 아니라 규칙이라 노트에만 적음
- QA: 생성 시트 전부 5폭 × 100·150·200%. 원본 보드를 끼운 PX 시트(PX_read_aloud·PX_music)는 원본이 고정 크기라 100%만 측정하고, 확대는 원본 P5·P3 시트의 150·200% 보드로 갈음한다.

## AU-04 알림 권한·채널
| 상태 | 판정 | 위치 |
|---|---|---|
| 어르신 앱 안 안내 → 시스템 창, '괜찮아요' | ✓있음 | N1_push 보드 1·2 (push.permission.*, '안 받으셔도 앱은 그대로 써요' 포함) |
| 자녀 C3 '알림 켜기' → 시스템 창, 거절 뒤 '설정 열기' | ✓있음 | N1_push 보드 3·4 |
| **설정 채널 행(어르신 2개)** '오늘의 사진'·'응원' 각 토글 | ✓보완 | P13_more 기본 보드: '알림' 한 행을 채널 두 행으로 바꿈(push.channel.daily·cheer + _desc) |
| 휴대폰 알림 전체 꺼짐 | ✓있음 | P13_more '알림이 휴대폰 설정에서 꺼짐'(push.system_off, 휴대폰 설정 열기) |
| **채널 하나만 휴대폰에서 꺼짐** | ✓보완 | P13_more '응원 채널만 휴대폰에서 꺼짐': 그 행 보조 글 '휴대폰 설정에서 꺼져 있어요' + '설정 열기'(그 채널 설정으로 바로) |
| **자녀 채널 '가족 연결'** 행·꺼짐 | ✓보완 | C7_settings_v2: '알림' 구역 + '가족 연결' 토글(push.channel.family), 꺼짐 보드 '설정 열기'(push.system_off.open_child). 예전 노트 '알림 행 숨김'은 폐기 |
| 알림 모양(잠금 화면·문구) | ✓있음 | N2_push_copy(daily·cheer), N3_connected(family 연결·다시 연결) |

- **메모: 채널 배정**
  - 어르신: daily·cheer.
  - 자녀: family(연결·다시 연결·연결 풀림).
- **메모: 앱 토글과 휴대폰 채널 설정이 다를 때**
  - 휴대폰에서 꺼진 채널은 앱 토글을 보여 주지 않고 '설정 열기'를 보여 준다.
  - 앱 토글은 서버 수신 설정(시간 08~21시 규칙 포함)이다.

## AP-03 읽어 주기
| 상태 | 판정 | 위치 |
|---|---|---|
| 버튼 위치(읽을 글 바로 아래 가운데)·기본·읽는 중(멈추기)·다 읽음 | ✓있음 | PX_read_aloud 규칙·P5·P8, P4 원본, P6 낱말 카드 안(P6_keyboard) |
| **한국어 음성 없음** | ✓보완 | PX_read_aloud '한국어 음성 없음': 버튼 아래 안내 상자(tts.no_korean.title·body) + '휴대폰 설정 열기'(TTS 설정) |
| **휴대폰 소리 0** | ✓보완 | '휴대폰 소리 0': 버튼 아래 한 줄(tts.muted), 스피커 아이콘 |
| **읽기 실패** | ✓보완 | '읽기 실패': 한 줄(tts.failed) |
| 화면 읽기 켜짐이면 버튼 숨김 | 메모 ✓있음 | 시트 노트·talkback R16 |

- 공통 규칙
  - 위 세 경우 모두 **누른 뒤에만** 보이고 polite 1회로 읽는다.
  - 버튼은 기본 상태로 돌아간다.
  - 화면을 떠나면 사라진다.
  - 자동으로 읽지 않는다.

## AP-04 배경 음악
| 상태 | 판정 | 위치 |
|---|---|---|
| P3 '음악 켜기'(꺼짐)·'음악 끄기'(나오는 중, 아이콘 speakerOn)·200% 줄바꿈 | ✓있음 | PX_music 보드 1~3 |
| P7 첫 완료 권유 시트(출처 줄 bgm.offer_source) | ✓있음(11-18 WR-04) | PX_music 보드 4 |
| 미리 듣기(켜 둘게요·끌게요) | ✓있음 | PX_music 보드 5 |
| 설정 토글 | ✓있음 | PX_music 보드 6·P13_more |

- **메모: 시스템 사유로 멈출 때**(무음·진동·이어폰 뽑힘·백그라운드·TalkBack)
  - P3 버튼은 **사용자 설정을 따른다**. 켜 둠이면 '음악 끄기' 그대로다.
  - 조건이 풀리면 2초 페이드로 다시 나온다.
  - 따로 알리지 않는다.
- '재생 중' 표시는 버튼 글자와 아이콘만으로 한다. 움직이는 막대 같은 것은 두지 않는다.

## AP-06 P13 v2 앱 정보 링크
| 상태 | 판정 | 위치 |
|---|---|---|
| 앱 정보 8항목(부모님) | ✓있음(11-18) | P13_more '앱 정보' |
| **이용약관·개인정보 처리방침 화면** | ✓보완 | '앱 정보 → 이용약관(앱 안 웹 화면)': 상단 '‹ 앱 정보' + 제목, 시행일·주소 한 줄, 웹 본문(앱 글자 배율 따름). 외부 브라우저로 내보내지 않음(어르신이 앱으로 못 돌아오는 문제) |
| **오픈소스 라이선스 화면** | ✓보완 | '앱 정보 → 오픈소스 라이선스': 안내 한 줄 + 라이브러리 행(이름·라이선스), 누르면 전문 |
| **인터넷 없을 때 링크** | ✓보완 | '앱 정보 · 인터넷 없음에서 링크 누름': 화면을 열지 않고 토스트 '인터넷이 연결되면 볼 수 있어요'(app_info.link_offline, 와이파이 끊김 아이콘) |

- **새 문구**: OSS 안내 '이 앱을 만드는 데 쓴 공개 소프트웨어예요'(라이터 확인).
- **이후**: OFL 서체를 번들하면 OSS 목록에 서체 3종을 넣는다(w2-design DZ-08).
