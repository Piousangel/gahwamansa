## DZ-07 런처 아이콘·스플래시 → 파일 판정 통과, 실기기 2건 남음(QA-10)
- **방법**
  - main의 `res/mipmap-xxxhdpi/ic_launcher_{foreground,background,monochrome}.png`와 `drawable-xxxhdpi/splash_icon.png`를 PNG 디코더로 쟀다.
  - 원형·squircle·둥근 사각 마스크로 48·64·96dp와 테마 아이콘을 렌더했다(`_qa/img/dz07-launcher-splash.png`).

| 항목 | 측정 | 기준 | 판정 |
|---|---|---|---|
| 적응형 전경 안전 영역 | 내용 최대 반지름 33.3dp(108dp 캔버스), 내용 49×57dp | 안전 원 66dp(반지름 33) | 통과(가장자리 그림자 0.3dp는 마스크 72dp 안이라 잘리지 않음) |
| 48dp 인지 | 원·squircle·사각 모두 살구 인장 '家'와 뒤 사진이 구분됨 | 사용자 할아버지 확인(11-17)과 같은 판 | 통과(렌더). 저가 기기 실물은 QA-10 |
| Android 13 테마 아이콘 | monochrome 레이어 있음, '家'·사진 윤곽 읽힘 | 단색 레이어 필수 | 통과 |
| Android 12+ 스플래시 | 288dp 캔버스(1152px@4x), 내용 최대 반지름 90dp, 내용 137×153dp | 아이콘 배경 없음 → 지름 192dp 원(반지름 96) 안 | 통과(6dp 여유) |
| 스플래시 → JS 대기 크기 튐 | 네이티브는 3D 상세판을 288 캔버스 기준으로, JS는 같은 생성기 배치(place 164, 2dp 위)로 그린다 | 같은 판·같은 배치 | 파일상 일치. **OEM이 아이콘을 다른 크기로 그리는지는 실기기에서만 보인다** → QA-10에서 두 장면 연속 캡처로 확인 |
| Android 11 이하 compat | — | compat 라이브러리가 아이콘을 작게 그림 | **실기기 확인(QA-10)** |

- **결론**: 아이콘·스플래시 파일은 바꾸지 않는다. QA-10 캡처 두 가지(12+ 스플래시 → JS 전환 연속 캡처, 11 이하 1대)가 나오면 이 표의 마지막 두 줄을 닫는다.

## DZ-08 워드마크 서체 라이선스 → 확정(OFL만)
| 서체 | 라이선스(원문 확인) | 원문 |
|---|---|---|
| Jua(제목) | SIL OFL 1.1, © 2018 The Jua Project Authors | https://github.com/google/fonts/blob/main/ofl/jua/OFL.txt |
| Noto Sans KR(본문·워드마크) | SIL OFL 1.1, © 2014-2021 Adobe(예약 이름 'Source') | https://github.com/google/fonts/blob/main/ofl/notosanskr/OFL.txt |
| Nanum Pen Script(손글씨) | SIL OFL 1.1, © 2010 NHN Corporation | https://github.com/google/fonts/blob/main/ofl/nanumpenscript/OFL.txt |

- **워드마크 '가화만사성'**
  - 서체는 Noto Sans KR 900이다(시안 FS_final과 같음).
  - 앱 안: 시스템 글꼴을 굵게 쓴다. 지금 코드 그대로이고 번들이 없다. Android 기본 한글 글꼴이 Noto Sans CJK라 모양이 같은 계열이다.
  - 스토어·마케팅 이미지: Noto Sans KR Black을 아웃라인한 SVG를 쓴다. 서체로 만든 그림은 OFL 제약 대상이 아니다.
- **배제**: 눈누 계열(이사만루·인피니티산스)은 쓰지 않는다. OFL만 쓴다는 원칙 때문이다.
- **번들 시 할 일**: 나중에 앱이 Jua 등을 번들하면 OFL.txt 전문을 오픈소스 고지(P13 앱 정보·AP-06)에 넣는다. 서체를 수정하면 예약 이름을 쓰지 않는다.
- **기록**: `design-system/tokens-v3.json` `fontCandidate.license`·`status`.

## DZ-09 카카오·구글 공식 로고 → 확인 통과(시안 쪽 표기만 정정)
- **카카오**
  - 앱 `ui/assets/kakaoSymbol.tsx`의 path는 공식 리소스 `login-complete-ko.svg`의 말풍선 path와 같다.
  - 색 #000000이다. viewBox는 자르기만 하고 늘리지 않았다.
  - 버튼: #FEE500, 반경 12, 레이블 "카카오 로그인" #000 85%, 레이블 ≤ 높이 1/3(20 ≤ 60/3).
  - 판정: 규정 통과.
- **구글**
  - 앱 `google-g.png`(24·48·72px)는 공식 `google-g-light-square.svg`(signin-assets.zip, 2026-11-17 내려받음)를 렌더한 것이다. 2025 그라디언트 G로, 지금 공식판이다.
  - 버튼: Light 테마(흰 면·#747775 1px·#1F1F1F), 패딩 12/10/12, "Google로 계속하기", 카카오와 같은 높이·폭.
  - 판정: 규정 통과.
- **시안 정정**
  - 시안 C0_login의 G는 위치 표시용 구판 4색 G다. 시트 노트에 "실제는 공식 원본(그라디언트 G), 앱 PNG가 기준"을 적는 것으로 끝낸다. 시안 그림을 공식 원본으로 바꾸려면 아티팩트를 다시 게시해야 해서 보류한다.
  - Google Sans 대신 OS 서체를 쓰는 것은 규정상 '권장' 위반이라 위험이 낮다고 본다. 출시 전 재확인 항목(LCC #23)에 그대로 둔다.
