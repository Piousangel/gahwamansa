# TalkBack 순회 기준표 (DZ-11, 디자인 L5 + QA L6 공동, 2026-11-18)

QA-02(실기기)와 QA-01(에뮬레이터)에서 화면·상태마다 TalkBack으로 한 바퀴 돌며 이 표의 칸을 채운다. 결과 칸 표기는 다음과 같다.
- ✓: 표와 같음
- ✗: 다름(무엇이 다른지 적음)
- —: 해당 없음

## 기준
- 세부 순서·문구는 `talkback-spec.md`(R1~R16, §5-1 칸 라벨)를 따른다. 문구 원본은 `docs/team/copy.ko.json`의 확정 키다.

## 모든 화면 공통으로 볼 것(각 행의 '공통' 칸)
| 기호 | 확인 | 근거 |
|---|---|---|
| a | 첫 포커스가 화면 제목(header)이다. 시스템 '뒤로'·상단 '‹'가 먼저 오지 않는다 | R2 |
| b | 장식(심볼·해님·스티치·테이프·칸 하나하나)은 읽지 않는다 | R3·R14 |
| c | 상태 변화(오류·저장 중·토스트·완료)는 polite로 **한 번만** 읽는다 | R11 |
| d | 누르는 것은 '버튼/링크/스위치', 고르는 것은 '라디오, 선택됨'으로 역할이 붙는다 | R9·R10 |
| e | 시트·대화상자는 안에서만 돌고, 닫히면 연 자리로 돌아간다 | R12 |
| f | 글자 200%에서도 순서가 같다(숨긴 요소는 읽지 않음) | R15 |
| g | 금지어를 읽지 않는다: 연속 숫자·개수 평가·'칭찬' 문장·'아직' | DECISIONS·11-2 |

## 기록 방법
- 기기·Android 버전·TalkBack 버전·글자 배율을 적고, 화면마다 결과 칸을 채운다.
- ✗이면 `docs/team/qa/<날짜>-talkback.md`에 화면·상태·실제로 읽은 말·기대한 말을 적는다.
- 디자인 판정이 필요하면 L5로 넘긴다. 문구 문제면 라이터에게 넘긴다.
