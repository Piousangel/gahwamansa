# TalkBack 읽기 순서·라벨 명세 (디자인 리드, 2026-11-17)

> 읽기 문구는 copy-v3-confirmed 11-2가 확정본이다(이 문서의 '(라이터 확인)' 표시는 11-2로 대체). P7 완료 알림: "오늘 코스를 마쳤어요. 도장을 찍었어요".

앱 개발 줄이 그대로 옮길 수 있게 쓴 명세다. 시안 기준: 아티팩트 v18, `docs/design/v3/`. 문구는 `docs/team/copy-v3-confirmed.md`(10절 우선). 새로 만든 읽기 문구는 **(라이터 확인)** 표시.
그림 보드: `a11y/A11Y_order.dc.html`(번호 = 읽는 순서, 첫 실행·어르신 코스·자녀 핵심 8화면).

## 0. 공통 규칙 (모든 화면)
| # | 규칙 | RN 구현 |
|---|---|---|
| R1 | **읽는 순서 = 위→아래, 왼→오.** 화면에 보이는 순서와 다르게 읽지 않는다. 하단 고정 영역은 본문 다음에 읽는다 | 레이아웃 순서 그대로. `accessibilityViewIsModal`·순서 강제 없음 |
| R2 | **화면에 들어오면 첫 포커스는 화면 제목**(상단 바가 있으면 '이전' 다음의 제목). 첫 화면은 워드마크 영역 | 제목 `accessibilityRole="header"`. 화면 진입 후 `AccessibilityInfo.setAccessibilityFocus(findNodeHandle(titleRef))`(300ms 뒤) |
| R3 | 상단 바 '‹ 이전' 라벨은 "이전 화면으로 가기", 코스 단계는 "오늘 코스로 돌아가기". 화살표 글자 '‹'는 읽지 않음 | `accessibilityRole="button"`, 라벨 고정(copy `nav.back_a11y`·`back_course_a11y`) |
| R4 | 제목 줄의 단계 표시 "1 / 3"은 제목과 한 덩어리로 "사진 보기, 3단계 중 1단계" | 제목 행 컨테이너 `accessible` + 라벨 합성 **(라이터 확인)** |
| R5 | **장식은 읽지 않는다**: 아이콘(글자 옆), 테이프·바늘땀·점선, 도장 줄 테두리, 해님 그림(말풍선이 있으면 말풍선 글만), 브랜드 심볼(워드마크 옆) | 아이콘·장식 `importantForAccessibility="no-hide-descendants"` 또는 `accessible={false}` |
| R6 | **뜻이 있는 그림은 한 번 읽는다**: 코스 사진 "오늘 사진, {caption}, AI가 만든 그림", 첫 화면 사진 묶음 "옛날 사진 예시, AI가 만든 그림" | `accessibilityRole="image"` + 라벨 |
| R7 | 아이콘만 있는 버튼은 없음(규칙). 글자+아이콘 버튼은 글자만 읽음 | 버튼 라벨 = 보이는 글 |
| R8 | **비활성 버튼은 이유를 힌트로**: "다 썼어요, 사용할 수 없음, 한 글자만 써도 누를 수 있어요" | `accessibilityState={{disabled:true}}` + `accessibilityHint`=이유 줄 문구. 이유 줄 자체는 중복 읽기 막음(`importantForAccessibility="no"`) |
| R9 | **선택 카드는 라디오**: "봄, 라디오 버튼, 선택 안 됨, 2개 중 1번째" / 고르면 "선택됨" | `accessibilityRole="radio"`, `accessibilityState={{checked}}`, 묶음 `accessibilityRole="radiogroup"` |
| R10 | **토글은 스위치**: "배경 음악, 스위치, 꺼짐, 오늘 코스 화면과 마친 화면에서만 나와요" | `accessibilityRole="switch"`, `accessibilityState={{checked}}`, 보조 글은 힌트 |
| R11 | **상태 변화는 한 번만 알림**(시끄럽지 않게): 저장 실패·오류·토스트·'잠시만요'(2초 넘을 때만)·완료 문장 | `accessibilityLiveRegion="polite"`(Android) 또는 `AccessibilityInfo.announceForAccessibility(문구)` 1회. 오류 상자는 `"assertive"` 아님(polite) |
| R12 | **시트·대화상자**: 열리면 포커스를 시트 제목으로, 바깥은 읽지 않음, 닫히면 연 버튼으로 포커스 복귀. 뒤로가기 = 닫기 | 시트 루트 `accessibilityViewIsModal`(iOS)·Android는 배경 `importantForAccessibility="no-hide-descendants"`, 닫힘 후 `setAccessibilityFocus(openerRef)` |
| R13 | **로딩 자리표시**(정지 막대·회색 행)는 읽지 않고 "잠시만요"만 | 자리표시 `no-hide-descendants`, 컨테이너 라벨 "잠시만요" |
| R14 | 숫자 번호는 끊어 읽기: 연결 번호 "연결 번호 4 8 2, 9 1 5", 인증번호 칸 "인증번호 6자리 중 3번째 칸" | 라벨에서 숫자 사이 공백·쉼표 |
| R15 | 큰 글씨 200%에서도 순서 동일. 확대 때 숨기는 요소(첫 화면 소개·사진, P6 제목)는 읽기에서도 빠짐 | 같은 조건으로 렌더 제외 |
| R16 | 화면 읽기가 켜져 있으면 '읽어 주세요' 버튼 숨김(소리 겹침), 배경 음악 자동 정지 | `AccessibilityInfo.isScreenReaderEnabled()` |

## 2. 어르신 (P)
### P1 번호 입력
| 순서 | 요소 | 읽는 말 |
|---|---|---|
| 1 | 이전 | "이전 화면으로 가기" |
| 2 | 제목 | "가족에게 받은 번호를 써 주세요" |
| 3 | 번호 칸 묶음 | "연결 번호 6자리, 3자리 썼어요" **(라이터 확인)** — 칸마다 따로 읽지 않음(소음). 각 칸 라벨 `connect.code_a11y`는 탐색 모드에서만 |
| 4~15 | 키패드 1~9, 모두 지움, 0, 지움 | "1" … "지우기" / "모두 지우기" |
| 16 | 다음(비활성이면 이유 힌트) | "다음, 사용할 수 없음, 번호 6개를 모두 써 주세요" |
| 17 | 번호가 없어요 | "번호가 없어요, 링크" |
- 오류(invalid 등): 칸 아래 오류 상자 polite 1회, 포커스는 번호 칸 묶음으로.

### P2 동의
1 이전 → 2 제목 "고른 답을 가족과 나눠요" → 3 세 줄 목록 한 덩어리("최근 한 달 고른 답과 날짜가 가족에게 보여요. 안 한 날은 보이지 않아요. 그만 보여 주면 지난 답은 지워져요") → 4 안심 줄 → 5 좋아요 → 6 싫어요.

### P12 알림 안내(N1_push)
1 알림 그림 "알림 예시, 오늘의 사진이 왔어요" (그림 한 덩어리) → 2 제목 → 3 본문 → 4 "알려 주세요" → 5 "괜찮아요". 시스템 창은 OS가 읽음.

|---|---|---|
| 1 | 날짜 | "11월 20일 금요일" (header) |
| 2 | 음악 켜기/끄기 | "음악 켜기, 버튼" (R16: 화면 읽기 켜짐이면 음악 자동 정지, 버튼은 남김) |
| 3 | 설정 | "설정, 버튼" |
| 4 | 한 줄 안내 | "둘 남았어요" (완료 때 해님 말풍선은 글만) |
| 5 | 이번 주 도장 | "이번 주 도장, 월요일, 화요일, 수요일, 목요일에 찍었어요"(copy 11-2 #13, 요일은 전체 이름) — 빈 날·개수 없음, 앱 `stamps_a11y`의 개수형은 쓰지 않음 |

### P4 사진 보기
1 오늘 코스로 돌아가기 → 2 제목 "사진 보기, 3단계 중 1단계" → 3 사진 "오늘 사진, 가을 마을, AI가 만든 그림" → 4 안내 → 5 회상 질문 2개(목록, "1. 감을 따 본 적 있으세요?") → 6 읽어 주세요(R16) → 7 다 봤어요.

### P5 둘 중 고르기
1 돌아가기 → 2 제목 "둘 중 고르기, 3단계 중 2단계" → 3 안내 → 4 질문(header) → 5 읽어 주세요 → 6·7 선택 카드(R9) → 8 정했어요(비활성 힌트 "하나를 골라 주세요").
- 저장 실패: 오류 상자 polite, 고른 카드는 "선택됨" 유지(빨강 없음과 일치).

### P6 자판으로 쓰기
| 순서 | 요소 | 읽는 말 |
|---|---|---|
| 1 | 돌아가기 | "오늘 코스로 돌아가기" |
| 2 | 제목 | "자판으로 쓰기, 3단계 중 3단계" |
| 3 | 안내 | "보이는 낱말을 아래 칸에 써요" |
| 4 | 낱말 카드(사진+칸 한 덩어리) | "쓸 낱말, 가을, 두 글자"(copy 11-2 #16) — 음절 칸 채움 변화는 읽지 않음 |
| 5 | 읽어 주세요 | 낱말을 읽음 |
| 6 | 입력칸 | "낱말 쓰는 칸, 편집 상자, 여기를 누르면 자판이 나와요" |
| 7 | 천천히 써 봐요 | 텍스트 |
| 8 | 다 썼어요(비활성 힌트) | "한 글자만 써도 누를 수 있어요" |
| 9 | 오늘은 넘어갈게요 | 링크(화면 읽기 켜짐이면 처음부터 또렷한 보조 버튼 — 자판 입력이 어려운 사용자 대체 경로) |

- 다른 낱말 시트: R12, 첫 포커스 시트 제목 "낱말을 한 번 더 볼까요?".

### P7 완료 · P8 응원
- P7: 1 제목 "오늘 코스를 마쳤어요" → 2 도장 "이번 주 도장, …" → 3 본문 → 4 알겠어요. 음악 권유 시트는 R12.
- P8(대화상자): 첫 포커스 제목 "가족이 보낸 응원이에요" → 응원 문장 → 읽어 주세요 → 알겠어요. 닫히면 P3 제목으로.

### P13 설정
제목 → 섹션 머리글(header) → 행 순서대로. 이동 행 "가족에게 답 보여 주기, 보여 주는 중이에요, 버튼", 토글 행 R10, '모두 지우기'는 "모두 지우기, 고른 답과 도장이 지워지고 연결도 끊겨요, 버튼".

## 3. 자녀 (C)
### C0 로그인
1 이전 → 2 제목 "로그인하고 시작해요" → 3 안내 → 4 "카카오 로그인, 버튼" → 5 "Google로 계속하기, 버튼" → 6 "이메일로 시작하기, 링크". 로그인 중: "로그인하고 있어요" polite, 두 버튼 `disabled`.

### C4 앨범 · C5 지난 답

- C5: 제목 → 설정 → 보조 줄 → 행마다 "11월 16일, 봄과 가을 중, 고른 답 가을"(C.md, 조사 없음) → 어르신 2명이면 호칭 머리글 header → 이야기 주제 추천 "곧 유료" → 탭.

### C7 설정
제목 → 섹션 머리글 → 행. 로그인 행은 정보만("로그인, 카카오로 로그인했어요"), 로그아웃 확인 대화상자 R12.

| 시트·대화상자 | 컴포넌트 미구현 | R12 포함해 구현 |

## 6. 검증
실기기 TalkBack(삼성 One UI·픽셀) 순회는 QA 게이트에서 화면별로 이 표를 체크리스트로 쓴다. 시안 단계에서는 aria 속성으로만 표시(렌더 점검 대상 아님).
