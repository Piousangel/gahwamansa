# 3D 시안 노트 · 가화만사성 (2026-11-17, 브랜드 디자이너)
비교: `compare-3d.png`(계열별 한 줄, 회색=평면 원본·흰색=3D). 안별 시트 `X3D-n.svg`(라이트/다크 워드마크 + 48dp·96px 원형·둥근사각 런처), 심볼 `X3D-n-symbol.svg`, 생성 소스 `_gen3d.mjs`. 앱·아티팩트 미반영, AI 생성 없음.

## 의견(솔직하게)
1. 3D는 C의 '낡음'은 확실히 지운다. 두께감·광택이 붙는 순간 서예 액자보다 '말랑한 젤리 도장'으로 읽힌다. 훈계 느낌은 색이 좌우한다. 진홍(C3D-1)은 여전히 관공서 직인 같고, 살구(C3D-3)부터 친근해진다.
2. 어르신: 붉은 도장 + 家는 낯익어서 '우리 집 앱'으로 바로 받아들일 것. 자녀: 한자는 못 읽어도 '집 도장' 모양으로 기억한다. 3D 스타일은 토스·배민 아이콘에 익은 30~40대에게 오히려 요즘 앱처럼 보인다.
3. UI 조화: 앱은 평면·종이색·갈색이다. 3D는 런처·스플래시·스토어에만 쓰고, 앱 안 머리글엔 같은 인장의 평면판을 쓰는 2단 운영이 맞다(토스도 같은 방식).
4. 48dp: 인장 계열이 가장 강하다(빨간 덩어리 하나). 家는 48dp에서 획이 뭉치지만 굵은 손그림 획이라 실루엣은 남는다. A3D는 갈색 테두리를 빼니 크림 배경에 묻혀 가장 약하다.
5. 사진 요소: C3D-2(뒤 폴라로이드)는 큰 크기에선 좋지만 48dp에선 흰 조각이 잡음이 된다. C3D-4(폴라로이드 사진 창 속 인장)가 '앨범+家'를 한 덩어리로 묶는 가장 깔끔한 방법이나 인장이 작아진다. 앨범은 워드마크 한 줄("하루 한 장, 우리 집 앨범")에 맡기는 편이 아이콘을 지킨다.
6. B의 '새집·사당' 위험은 3D로 줄지 않는다. 기와 골·먹색을 넣으니 한옥답긴 하나 이번엔 정자·등갓·사당 쪽으로 읽힌다(B3D-1·2). 3D가 해결하는 건 질감이지 오독이 아니다.

## 家 글자 (서체 미사용)
- 시판 서체 대신 `_gen3d.mjs`의 `GLYPH`에 획 10개를 100×100 상자 좌표로 직접 설계(둥근 끝 선). 필순: 宀 점→왼점→가로꺾고 갈고리(3획), 豕 가로→삐침→굽은 갈고리→삐침→삐침→짧은 삐침→파임(7획). 확대 렌더로 宀+豕 구조 확인
- 원래 C(`../C-symbol.svg`)는 AppleMyungjo `<text>`라 출시 전 반드시 이 손그림 패스로 교체해야 함. 워드마크 글자는 아직 시스템 서체(미리보기용), 확정 시 OFL 서체(Jua·Gowun Batang 등) 아웃라인화

## AI 렌더(Gemini 등) vs 손으로 쓴 의사 3D
| | AI 고품질 렌더 | 손 SVG 의사 3D(이번) |
|---|---|---|
| 품질 | 진짜 재질·조명, 첫인상 강함 | 젤리·클레이 '느낌' 수준 |
| 세트 일관성 | 아이콘·도장·스플래시를 같은 조명으로 맞추기 어렵고 매번 달라짐 | 같은 코드·토큰이라 세트가 자동으로 맞음 |
| 크기별 품질 | 래스터. 48dp로 줄이면 뭉개짐, 크기별 재작업 | 벡터. 48dp용 획 굵기만 따로 조정 |
| 권리 | 순수 AI 생성물은 저작권 보호 불확실, 상표 등록 시 식별력·선행 유사 이미지 위험, SynthID 워터마크 내장 | 직접 설계라 권리 명확, 상표 출원 서류에 제작 경위 기재 가능 |
- 결론: 로고 원본은 손 벡터로 확정하고, AI 렌더는 쓰더라도 스토어 홍보 이미지 정도에 한정

## 추천: C3D-3 살구빛 말랑 인장
- 이유: 48dp 식별 최고, 이름(家)과 직결, 살구색이 훈계·엄숙을 가장 많이 덜어 냄, 해님(주황) 계열 색과도 이어짐. 앨범은 워드마크 한 줄로 보완
- 차선: C3D-4(앨범을 아이콘에 꼭 넣어야 한다면). A3D·B3D는 비추천(A는 대비 약화, B는 오독 미해결)
- 조건: 어르신 2~3명에게 48dp 아이콘만 보여 "무슨 앱 같아요?" 확인(패널 B 조건과 동일). 앱 안에는 같은 인장 평면판 사용
- 바꾸는 비용(추정 약 8h): 인장 다듬기·48dp 전용 획 굵기 2h + 평면판 1h + 앱 반영 2h(`brandSymbol.tsx`·`symbol-sun-polaroid.svg` 대체, Android 적응형 아이콘은 그림자 블러 때문에 `mipmap-*` PNG 5밀도로 내보내기, 스플래시는 평면판 벡터) + 시안·시트 1.5h + 실기기 확인 1.5h
- 적기: 패널과 같음. 이번 주(11/19~21), 스토어 그래픽 제작·Play 업로드(11/25) 전
