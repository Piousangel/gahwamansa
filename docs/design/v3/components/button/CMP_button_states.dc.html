큰 버튼 · 모든 상태

어르신 화면의 큰 버튼 3종. 모든 상태를 실제 크기(폭 342 = 390 화면에서 좌우 여백 24)로 나열. 접근성 값은 문서(README)에 있고 여기 표시한 숫자는 모두 같은 값이다. 앱 연결: BigButton(variant primary|secondary) → variant에 danger 추가, loading·focus 상태와 icon 슬롯 추가 제안. 읽어주는 이름은 label 그대로 + 상태("누를 수 없어요" / "잠시만요"). 아이콘 슬롯은 장식이라 읽지 않음.

주 버튼 (primary) — 화면에서 가장 눌러야 할 것 하나

한 화면에 주 버튼은 1개만. 글자는 동사 하나("이어서 하기", "다 봤어요"). 쓰지 말아야 할 때: 같은 화면에 주 버튼이 이미 있을 때, 되돌릴 수 없는 일을 하는 버튼(위험 외곽선을 쓴다), 이동만 하는 작은 링크 자리.

보조 버튼 (secondary) — 하나 더 선택지가 있을 때

주 버튼 바로 아래 12px. 보조 버튼은 하단 고정 영역에서 한 개까지만. 쓰지 말아야 할 때: "취소"처럼 주 버튼과 뜻이 반대인 두 번째 확인 버튼(한 화면에 확인·취소를 섞지 않음), 내용을 읽어 주는 버튼(말풍선 안 스피커 버튼으로 붙임).
