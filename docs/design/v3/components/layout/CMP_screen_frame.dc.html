규칙
Screen frame (표준 화면 틀)
TopSafe(고정) → TopBar(선택, 고정) → Body(스크롤) → BottomDock(고정) 4층 구조. Body와 BottomDock은 겹치지 않는 형제(position:absolute 금지). 이 구조 자체가 F2(고정 버튼에 가려진 카드)를 불가능하게 만든다.
글자 확대 150%
Body만 스크롤. BottomDock은 높이가 조금 커져도 화면의 40%(약 338)를 넘지 않게 라벨을 7자 이내로. Body 끝에 28 높이 페이드를 두어 "아래에 더 있어요"를 보여 줌(스크롤 막대에만 의존하지 않음).
안전 영역
위: insets.top, 아래: max(28, insets.bottom). 바닥 버튼이 홈 인디케이터에 닿지 않게. Android 제스처 바도 insets.bottom으로 처리.
한 화면 한 일
주 행동은 하단 고정 영역의 큰 버튼 1개(높이 72)로만 둔다. 보조 행동은 (1) 그 내용에 붙여 작게(읽어 주세요 = 말풍선 옆 64x64), (2) 본문 끝의 작은 링크(64 터치), (3) 꼭 필요하면 보조 버튼 1개까지. 같은 화면에 큰 버튼 2개 + 카드 3개 + 링크를 모두 크게 두지 않는다(F4).
밀도 한도(어르신 한 화면)
큰 요소 = 주 버튼 1 + 강조 카드 1(지금 할 것). 나머지 정보는 compact(높이 60 이하)나 글자 한 줄. 본문 영역 안에 큰 카드 3개 이상 금지, 박스류(안내·경고)는 1개.
키보드가 올라올 때
BottomDock이 키보드 위로 따라 올라오고 Body가 줄어든다(KeyboardAvoiding). 번호 입력은 자체 키패드를 Body 하단에 둔다.
줄바꿈(F1)
모든 한국어 루트에 keep-all. 상태 글자를 제목 오른쪽 열에 두지 않고 제목 위·아래 줄로 둬 제목이 전체 폭을 쓴다. 제목 balance, 마지막 두 어절 NBSP.
앱 연결
현재 Screen({children})은 ScrollView 한 겹 → Screen({top, bottom, children, scrollEnabled}) 로 교체 제안: top·bottom은 고정, children은 ScrollView 안. 기본 패딩은 위 4/좌우 24/아래 24(코스 홈 기준).
