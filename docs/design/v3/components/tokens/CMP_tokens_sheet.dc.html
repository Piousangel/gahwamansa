모션 규칙

어르신 화면: 빠르거나 번쩍이는 애니메이션 금지(초당 3회 이상 깜박임·점멸 금지, 흔들기 금지, 화면 전체가 움직이는 전환 금지). 움직임은 300ms 이상, 기본 300ms / 느린 450ms, easing ease-in-out(cubic-bezier .4,0,.2,1). 눌림 색 변화는 움직임이 아니라 즉시(100ms 이하) 반응해야 눌렸다고 느낌(예외로 기록). 도장 붙이기 = 한 번 scale 1→1.12→1, 300ms. 로딩 = 점선 막대 1.6초 주기 이상 천천히 또는 정지. 화면 전환 = 불투명도만(위치 이동 없음).
움직임 줄이기(시스템 설정): 모든 movement·scale 제거, 도장은 즉시 표시, 로딩은 정지 상태 + 글자만, 전환은 즉시. 불투명도 페이드(300ms)만 남김.
자녀 화면: 같은 금지 규칙, 시간만 200ms 이상 허용.

한국어 텍스트 규칙

keep-all: 모든 한국어 텍스트의 루트에 word-break: keep-all + overflow-wrap: break-word(긴 단어 안전망) + text-wrap: pretty(마지막 줄 한 글자 방지, 웹). 제목·말풍선·카드 제목은 text-wrap: balance.
한 글자 orphan 방지: 마지막 두 어절 사이 공백을 NBSP(U+00A0)로 묶는다(앱 RN은 CSS가 없어 문구 데이터에서 처리: copy.ts에 nbsp() 도우미 제안). 의미 단위로 줄을 나누고 싶은 곳은 문구 데이터에 \n을 직접 넣는다.
줄 높이: 제목 1.3 / 말풍선 1.35 / 어르신 본문 1.5 / 자녀 본문 1.5 / 손글씨 1.15 / 버튼 1.2. 자간 0(한글은 자간을 줄이지 않음). 글 한도: 어르신 문장 20자 안팎, 큰 버튼 7자, 선택 카드 14자, 단계 제목 10자/14자(full), 제목 14자.
