굵기 비교 (24·32·48)

스피커: 2.5 → 24·32·48, 3.5 → 24·32·48
홈: 2.5 → 24·32·48, 3.5 → 24·32·48
응원(하트): 2.5 → 24·32·48, 3.5 → 24·32·48
사진: 2.5 → 24·32·48, 3.5 → 24·32·48

규칙

  1. 격자 24x24, 바깥 2px는 안전 영역(주황 점선). 선의 중심선은 4~20 안에 둔다 → 굵은 3.5에서도 가장자리가 2px 안쪽을 넘지 않는다.
  2. 선 굵기 기본 2.5, 어르신 굵은 3.5. 24px에서 2.5는 약 10%, 3.5는 약 15%다. 3.5에서도 안쪽 틈이 막히지 않도록 선과 선 중심 간격 4.5 이상을 목표로 그렸다(막히는 것은 굵은 변형만 별도 도면: 경고·사진·복사·달력·설정).
  3. 끝과 꺾임은 둥글게(round cap, round join). 네모의 모서리 반경은 3~4. 뾰족한 각은 별·경고 삼각형처럼 꼭 필요한 곳만 선 끝 둥글림으로 눌러 준다.
  4. 외곽선형으로 통일. 작은 점(눈·느낌표·자물쇠 구멍)은 길이 0.01 선으로 그려 같은 선 굵기를 쓴다. 채움형을 섞지 않는다.
  5. 색은 currentColor. 둘 이상 색을 한 아이콘에 쓰지 않는다.
