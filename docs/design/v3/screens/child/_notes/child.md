# 자녀 화면 v3 노트 (2026-11-17)

## 결정
- 자녀 본문 최소 20(제품 결정): 탭·칩·배지·링크까지 모두 20 이상. 측정에서 20 미만 글자 0개(아트보드 안).
- 자녀 홈은 카드 1장(폴라로이드형 테이프 1곳 + 스티치 1줄)에 "{호칭}의 최근 답 / 선택지 72 / 날짜(본문 글씨) / 이야기 문구"만 둔다. 칩·연속일·참여·완료 여부 없음. 주 버튼은 응원 보내기 1개.
- 안2 개성: 테이프는 C4 카드 1곳, 스티치는 C4 카드 안 1곳. 도장·손글씨 폰트는 자녀 화면에 쓰지 않음.
- 응원은 정해진 문구 4개 선택, 누르면 바로 전송("{호칭}께 보냈어요" 확정 문구).
- C6은 결제 없는 가격 확인 시트: 월·연·선물 [가격], 신청(알려 주세요)만. 비활성 버튼은 이유 한 줄.
- 삭제 용어는 "지우기" 통일, 입력 단어도 "지우기". 주 버튼은 안전한 "그만둘래요".
- 호칭 변수는 시안에서 기본값 "부모님"으로 표시. 조사 붙이는 문구 없음(예외: 토스트 "{호칭}으로 바꿨어요").

## 한계
- 렌더링은 헤드리스 Chrome 스크린샷으로 C4·C6 등 일부만 눈으로 확인. 나머지는 측정(가로 넘침·20 미만 글자)만. Google Fonts는 온라인일 때만 로드(오프라인이면 대체 글꼴로 폭이 달라질 수 있음).
- support.js는 폴더에 없음(기존 components도 동일). 줄은 규칙대로 유지.
- 320폭 측정은 아트보드 폭을 320으로 줄여 가로 넘침만 봄. 높이는 844 고정이라 320에서는 본문이 길어져 세로로 잘림(실기기는 스크롤).
- 글자 150%는 C2·C4에 1장씩. 나머지 화면의 150%는 미작성.
