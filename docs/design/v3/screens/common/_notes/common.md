# 공통 화면 노트 (2026-11-17)

## 결정
- 모든 아트보드 390x844, 표준 틀(상단 52 비움 + 스크롤 본문 + 하단 고정 버튼 형제). 버튼 1개, 어르신 72·자녀 56.
- S1: 보여 줄 내용이 없을 때만 전체 화면, 내용이 있으면 상단 배너. 오프라인=state-offline, 일반 오류=sun-worry, 연결 끊김=state-connection-lost.
- S2: 로딩은 400ms 지연 후 표시, 최소 600ms 유지, 8초 넘으면 한 줄 추가, 회전 스피너 없음, 막대는 느린 깜박임(동작 줄이기 정지). 빈 상태는 어르신 버튼 1개, 자녀는 버튼 없음.
- 스티치·테이프·도장은 쓰지 않음(해당 위치 아님). 개성은 해님·상태 일러스트로.
- 자녀 화면은 호칭 기본 "부모님"을 대입해 그림(변수 {호칭}, 조사 없음).
