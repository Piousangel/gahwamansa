화면 흐름 시트

빌드 1의 흐름 4개와 연결이 풀렸을 때의 흐름을 화면 ID 칸과 화살표로 보여 줍니다. 칸의 셋째 줄은 화면 파일 이름이며 링크 없이 글자로만 적었습니다. 점선 칸은 공통 화면입니다.
