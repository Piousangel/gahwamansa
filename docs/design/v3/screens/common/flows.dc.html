화면 흐름 시트

빌드 1의 흐름 4개를 화면 ID 칸과 화살표로 보여 줍니다. 칸의 마지막 줄은 계획된 화면 파일 이름이며, 파일이 없을 수 있어 링크 없이 글자로만 적었습니다.
