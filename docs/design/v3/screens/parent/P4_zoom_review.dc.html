B1·B2 규칙

  • 들어가기: P4 폴라로이드 전체(캡션 포함)가 누름 영역. 핀치·확대 없음(한 장을 크게 보는 것만). TalkBack 라벨 '오늘 사진, {caption}, AI가 만든 그림, 두 번 눌러 크게 보기'(역할 button)
  • 나가기: '닫기' 버튼(64, 위 왼쪽), 안드로이드 뒤로. 사진 누르기로는 닫지 않음(실수 방지, DZ-06 수정). 닫으면 P4 같은 스크롤 자리
  • 첫 안내(DZ-06 11-18 수정): P4 사진 아래 '사진을 누르면 크게 보여요'. 시간으로 사라지지 않음(어르신 읽기 속도) — 크게 보기를 한 번 열면 다시 안 보임, 안 열면 P4 3번째 방문까지만
  • AI 표기: 크게 보기에서도 늘 보임(세로: 캡션 아래, 가로: 오른쪽 아래)
  • 회전: 크게 보기만 가로 허용(앱 다른 화면은 세로 고정). 가로면 사진이 세로 꽉, 닫기 왼쪽 위
  • 모션: 300ms 페이드+살짝 커짐(.96→1). 동작 줄이기면 페이드만
  • TalkBack: 열리면 포커스 '사진 크게 보기, {caption}, AI가 만든 그림' → '닫기'. 닫히면 사진으로 복귀
  • 이벤트 photo_zoom_opened(내용 없음). 보기 전용(B2)에서도 같은 크게 보기. 사진을 못 불러왔으면 크게 보기 진입 없음(P4의 사진 자리 상태 그대로)
  • B2 보기 전용: P3 완료 상태의 '오늘 코스 다시 보기'·했어요 행 › → 세 단계 보기 전용(P4는 이 보드, P5·P6은 P5_P6_review). 단계 n / 3 숨김, 하단 '돌아가기', 기록 호출 0
