B1·B2 규칙

  • 들어가기: P4 사진(폴라로이드)을 누르면 화면 가득 크게. 핀치·확대 없음(한 장을 크게 보는 것만)
  • 나가기: '닫기' 버튼, 안드로이드 뒤로, 사진 한 번 더 누르기. 닫으면 P4 같은 자리
  • 첫 1회 안내: P4 처음 열 때 사진 아래 '사진을 누르면 크게 보여요' 한 번(3초 또는 아무 데나 누르면 사라짐), 다시 안 보임
  • AI 표기: 크게 보기에서도 늘 보임(세로: 캡션 아래, 가로: 오른쪽 아래)
  • 회전: 크게 보기만 가로 허용(앱 다른 화면은 세로 고정). 가로면 사진이 세로 꽉, 닫기 왼쪽 위
  • 모션: 300ms 페이드+살짝 커짐(.96→1). 동작 줄이기면 페이드만
  • TalkBack: 열리면 포커스 '사진 크게 보기, {caption}, AI가 만든 그림' → '닫기'. 닫히면 사진으로 복귀
  • 이벤트 photo_zoom_opened(내용 없음). 보기 전용(B2)에서도 같은 크게 보기
  • B2 보기 전용: P3 완료 상태의 '오늘 사진 다시 보기' → P4 보기 전용(단계 n / 3 숨김, 하단 '돌아가기', 기록 호출 0). 고르기·자판 단계는 다시 열지 않음
