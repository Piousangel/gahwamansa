읽어 주기 버튼 규칙

기본누르면 휴대폰 내장 한국어 목소리로 읽어요
읽는 중읽는 문장에 하늘색 밑줄. 다시 누르면 멈춤
다 읽음저절로 기본으로 돌아옴. 화면을 떠나면 멈춤
  • 위치: 읽을 글 바로 아래 가운데 한 개. P4 회상 질문, P5 질문, P6 낱말, P8 응원 문장
  • 읽는 동안 배경 음악은 10% 이하로 줄였다가 끝나면 되돌림(덕킹)
  • 자동으로 읽지 않음(공공장소 소리 방지). TalkBack 켜짐이면 버튼 숨김(화면 읽기와 겹침)
  • 아이콘만 쓰지 않음. 버튼 높이 64, 글자 24(확대 상한 1.5)
