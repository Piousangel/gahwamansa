# 앱 반영 라운드 계획 (2026-11-17)

근거: 시안 v3(`docs/design/v3/`), 확정 문구(`docs/team/copy-v3-confirmed.md`), 보드 결론·사용자 결정(`DECISIONS.md`). 크기 L. 서버 계약 변경이 있는 단계는 서버 → 앱 순서(REPO.md), 단계마다 TDD·직접 검증·커밋. 아래 시간은 앱 개발 위원 r1·r2 추정과 이번 화면 수 기준의 **가정**이다.

## 단계
| 단계 | 내용 | 서버 | 추정(가정) |
|---|---|---|---|
| A | 문구·이름·용어 반영: `copy.ko.json` 이관(tempCopy 제거), 탭 "앨범·지난 답", 지우기 확인 입력 단어 "지우기", 사진 아래 "AI가 만든 그림" 표기, 금지어 검사 테스트를 문구 전체로 확대 | 없음 | 4~6h |
| B | 미연결 열람 모드(P14): 프로필 없는 기기는 코스를 보되 답은 저장하지 않고 "번호 쓰기"로 연결 | 가능성: 콘텐츠 읽기가 공개인지 확인, 아니면 소규모 RPC | 6~8h |
| C | 자녀 연결 흐름 C0~C3: 역할 선택, 호칭 선택 1칸, 번호 만들기·공유·복사·만료·여러 개, 연결 대기·연결됨 | `set_parent_title` 이미 있음 | 12~16h |
| D | 곧 유료 시트 C6(관심 표시만, 결제·연락처 없음), 자녀 설정 C7(호칭·지우기) | 관심 표시 집계 이벤트 1개(선택) | 6~8h |
| E | 새 디자인 시스템 적용: tokens v3, 컴포넌트 14종, 표준 화면 틀(상단 고정·스크롤·하단 고정), 안2 개성(스티치·테이프·도장), keep-all, 150% 스크롤 | 없음 | 20~28h |
| F | QA 게이트: 접근성 필수 8개, 문구·화면·RPC 대조표, 실기기(폰 연결 필요) | 없음 | 6~8h |

## 순서와 병렬
- A → B → C는 앱 코드가 겹치므로 순차. E는 A 이후 별도 담당이 병행 가능(화면 파일 충돌 주의: 한 번에 한 담당이 한 화면만).
- 토스 클라이언트(`toss/`)는 이 계획 밖이다(콘솔 appName·mTLS 인증서 수령 후 별도 계획).

## 완료 기준
각 단계: tsc·lint·jest·통합 테스트 통과(직접 실행 결과 보고), 확정 문구와 화면 1:1 대조, 금지어 0, 서버 변경은 pgTAP 포함. 임시 문구가 남으면 단계 완료로 치지 않는다.
