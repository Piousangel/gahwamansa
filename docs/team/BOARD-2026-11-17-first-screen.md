# 디자인 리뷰 패널 · 첫 화면과 메인 화면 (2026-11-17)

사용자 피드백(실기기, 갤럭시 S25): "처음 화면 자체가 너무 위에 떠 있는 것 같고, 마스코트 아이콘이 필요한가 싶기도 하고, 메인 화면이 가장 중요한 UI 중 하나라 토스·배민·카카오 디자이너·PM 리뷰를 받아 보면 좋겠다." 인증번호 화면: "하단 버튼은 플로팅이 낫겠다, 뒤로가기가 불친절, 색이 하나라 입력칸과 키패드가 헷갈린다."
