# 제품 회의(Board) 안건 · Gemini로 마스코트·에셋 만들기 (2026-11-17)

사용자 제안(원문 요지): "기본 마스코트 '해'는 신경 써서 Gemini로 뽑으면 좋겠다. 팀 내부에서 필요한 아이콘·에셋도 Gemini를 충분히 활용할 수 있을 것 같다. 팀 내부 회의를 거쳐 논의해 봐."
규칙은 `BOARD-2026-11-17.md` §0과 같다: 라운드 1 독립 의견(다른 위원 파일 읽지 않음) → 라운드 2 상호 반박·표결 → 리드 종합. 최종 결정은 사용자.

## 배경(사실)
- 지금 해님은 팀이 만든 SVG 28개(표정 5·자세·도장 3·빈 상태 4 등, `design-system/assets/character`), UI 아이콘은 SVG 36종(`assets/icons`, currentColor, 24 격자). 개성은 안2(스티치·테이프·도장).
- Gemini API(나노바나나) 연결 완료. 옛날 사진 14장을 생성해 품질 확인: 눈에 보이는 워터마크 없음, SynthID는 모든 생성물에 포함(문서). 스크립트 `scripts/photos/gen-photo.mjs`.
- 알려진 위험: 시안 검토에서 "해님이 어린이 콘텐츠처럼 보여 어르신이 아이 취급을 느낄 수 있다"는 지적(이름 후보 검토 때). 40px 이하에서 표정 구분이 어렵다(브랜드 디자이너).
- 미확인: Gemini 생성물의 상업 이용 약관, AI 생성 캐릭터의 저작권·상표 보호 가능 여부, 참조 이미지를 이용한 캐릭터 일관성 유지 정도, 장당 비용.
