# 에셋 목록 (전문 에셋 디자이너 전달용) · 2026-11-16

원칙: 아이콘·캐릭터·그래픽은 전문 에셋 디자이너(Claude Design)가 만든다. 개발 쪽은 임시로 그린 그림을 쓰지 않고, 에셋이 없는 자리는 라벨 박스로 표시한다. 크기·개수는 개발 쪽 요구 초안이며 디자이너가 조정할 수 있다(Play 규격은 출시 전 Play Console 안내로 재확인 필요).

납품 기한(제안): 빌드 1 통합(계획 11단계) 전, 11월 26일 전후. 이 날짜는 일정 추정에서 온 것이다.

## 2. 해님 캐릭터 (컨셉 "해님이 안내하는 우리 집 앨범")
- (2026-11-18 갱신, gemini DECISION-MEMO E·DECISIONS) 표정 3종: 기본, 입 닫은 미소(완료), 걱정(오류·연결 안 됨). **볼터치 없음**, 하트 없음. 해님이 말하는 때는 첫 만남·완료·오류 세 순간뿐이고 칭찬 평가는 하지 않는다. 자녀 화면에는 해님을 두지 않는다.
- 도장용 해님 1종(`SunStamp`): 이번 주 코스를 마친 날 표시(연속 일수 표시 아님), P3·P7 도장 줄과 P7 큰 도장(120). 인주 번짐은 토큰 `brandSealDeep`.
- SVG 또는 고해상도 PNG(투명 배경), 어르신 화면에서 크게 보여도 깨지지 않을 것.

## 3. UI 아이콘 (어르신 화면은 크기·획 굵기 중요)
읽어 주세요(스피커), 완료 체크, 뒤로, 홈, 리포트, 응원(하트 등), 설정, 알림, 잠금/곧 유료 배지, 닫기, 공유, 경고. 상태별(기본·눌림·비활성)이 필요한 것은 표시해서 전달.

## 4. 앨범 장식
폴라로이드 프레임, 테이프 조각, 앨범 페이지 스티치 테두리, 종이 질감 배경.

## 5. 별도 관리
AI 옛날 사진(14장 → 30장)은 에셋 디자이너가 아니라 AI 사진 큐레이터 단계에서 만든다(2라운드). 저작권·실존 인물 검수 포함.

## 6. 전달 형식
`app/src/ui/assets/`에 두는 것을 기준으로, 파일명은 `kebab-case`, 아이콘은 SVG 우선. 변경은 파일 교체만으로 반영되도록 레지스트리에서 참조한다.
