# A. 자녀 연결 대기 화면(C3) — 막다른 길 없애기
근거: 사용자 "코드 보내면 연결을 기다리고 있어요 해서 뭐든 못하는데 이게 맞아?", 실기기 21-first.png(제목·설명·버튼 2개, 가운데 빈 화면). 번호 기한 7일(core.sql `expires_at`), 푸시 빌드1 필수(DECISIONS 결정 1), 형제 초대 빌드1 밖(DECISIONS 123행).

## 1. 관점별 의견
- **PM**: 대기는 몇 분~며칠. 이 사이 자녀가 할 일은 "부모님이 번호를 쓰게 돕기" 하나뿐이다. 그래서 1순위는 놀거리가 아니라 **부모님 폰에서 할 일 3단계 안내**(전화로 불러 줄 수 있게)와 **번호·남은 기간**. 2순위는 앱 가치를 미리 보여 줘 이탈을 막는 미리보기. 형제 초대는 빼기(연결 전엔 가족이 없음).
- **디자이너**: 가운데 빈 칸이 "고장"처럼 보인다. 위→아래로 ① 번호 카드(번호를 바로 보여 줌, "번호 다시 보기" 버튼 불필요) ② 3단계 ③ 미리보기 폴라로이드 1장 + 질문 예시 순. 상단 바에 설정(톱니) 아이콘. 하단 고정 버튼은 "번호 보내기" 1개.
- **라이터**: "기다리고 있어요"는 자녀를 수동적으로 만든다. 제목을 할 일로: "{호칭} 폰에서 번호를 쓰면 연결돼요". 상태는 작은 칩 "연결 기다리는 중"으로 내린다. 미리보기 문구는 "{호칭}께 매일 이런 사진이 가요".
- **정책**: ① 미리보기 사진은 AI 생성이므로 "AI가 만든 그림" 표기 유지(첫 화면만 예외였음). ② 푸시 권한은 이 화면이 가장 자연스러운 맥락("연결되면 알려 드릴게요")이나 거절해도 화면이 매번 다시 묻지 않게. ③ 미리보기에서 답을 고르게 하면 자녀 답이 저장되는 오해 → 보기 전용.

## 2. 반박 1회
- 디자이너 → PM: 3단계 안내를 늘 펼쳐 두면 화면이 길어진다. 접기로? / PM: 대기 화면의 핵심 일이므로 펼쳐 둔다. 대신 미리보기를 아래로 내린다.
- 정책 → 디자이너: 번호를 화면에 늘 보이면 어깨너머 노출. / 디자이너: 7일·1회용·가족 연결뿐이고 자녀가 불러 줘야 하는 값이라 노출 이득이 크다. 수용, 단 앱 전환 화면 미리보기에서는 가리지 않음(위험 낮음, 가정).
- 라이터 → PM: "호칭 바꾸기"를 본문에 두자. / PM: 설정에 있으면 충분(빈도 낮음). 본문 버튼 수를 늘리지 않는다.

## 3. 결론 (PM 종합)
넣기: 번호 카드(번호·남은 기간·만료 시 새 번호), 부모님 폰 3단계, 미리보기(보기 전용, 샘플 1일분 앱 내장), 푸시 권한 한 줄, 설정 진입(호칭·로그아웃·지우기 = 기존 C7).
빼기: 형제 초대(빌드1 밖), 앨범·지난 답 탭(연결 전 탭 바 숨김 유지), 응원 미리 쓰기.
연결되면: 앱이 열려 있으면 바로 C3 연결됨으로, 닫혀 있으면 푸시 "연결됐어요" → 누르면 C3 연결됨.

## 4. 화면 구조·문구 초안
```
[상단 바]                                   (설정 톱니)
제목  {호칭} 폰에서 번호를 쓰면 연결돼요
칩    연결 기다리는 중 (·애니메이션 점 3개, 동작 줄이기 시 정지)
[번호 카드]  482 915   /  11월 24일까지 쓸 수 있어요
             (만료) 번호 기한이 지났어요  [새 번호 받기]
[이렇게 하시면 돼요]
  1  {호칭} 폰에 가화만사성을 설치해요
  2  첫 화면에서 '부모님' 버튼을 눌러요
  3  번호 6개를 쓰면 끝이에요
[{호칭}께 매일 이런 사진이 가요]  폴라로이드 1장(AI가 만든 그림) + "봄과 가을, 어느 쪽이 좋으세요?"
  [하루 코스 미리 보기 ›] → 사진·고르기·자판으로 쓰기 3장 보기 전용 넘김
(알림 꺼짐일 때만) 연결되면 알려 드릴게요  [알림 켜기]
[하단 고정] 번호 보내기
```
- 푸시 본문: "연결됐어요" / "{호칭}과 이어졌어요" 대신 조사 없는 "{호칭} 폰과 연결됐어요".
- 화면 읽기: 번호는 "연결 번호 4 8 2, 9 1 5"(기존 규칙), 칩은 상태 변화 때만 알림.
- 토스 표면: 1단계 "설치해요"는 규정상 "가화만사성 앱을 열어요"로 바꿈(설치 유도 금지, 가정).

## 5. 개발 작업·추정 (가정)
| 작업 | 담당 | 추정 |
|---|---|---|
| C3 대기 시안 v4(기본·만료·알림 꺼짐·150%·200%) | 디자이너 | 3h |
| 문구 확정 → copy-v3-confirmed 7절 | 라이터 | 1h |
| 대기 화면 재구성(번호 카드·3단계·미리보기 진입·설정) | 앱개발 | 5h |
| 하루 코스 미리 보기 3장(보기 전용, 샘플 1일분 앱 내장, 서버 호출 없음) | 앱개발 | 3h |
| 번호 남은 기간·만료 표시: 발급 응답에 `expires_at` 포함 확인, 없으면 추가 | 서버 | 0.5~1h |
| 연결 시 자녀 푸시(redeem 후 트리거 → Edge Function) | 서버 | 2~3h (U15 푸시 기반 선행) |
| 실기기 2대 E2E(대기→푸시→연결됨) | QA | 1.5h |
합계 약 16~17h. 사용자 질문 없음(Firebase 계정은 결정 1에서 이미 사용자 몫).
