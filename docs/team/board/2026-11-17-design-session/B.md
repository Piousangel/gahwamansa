# B. 한글 단계를 "자판으로 낱말 쓰기"로 전환 (P6)
근거: DECISIONS 결정 2 "휴대폰 키보드로 낱말 치기 — 키보드 사용 연습 자체가 목적". 원칙 "평가하지 않는다"(금지어: 틀렸·못 했·아직). 서버 단계 값은 'hangul' 그대로(core.sql check).

## 1. 관점별 의견
- **PM**: 목적이 "카톡에서 쓰는 그 자판에 익숙해지기"이므로 **시스템 키보드**가 맞다. 앱 전용 큰 글자판은 쉽지만 앱 밖으로 옮겨지지 않는 기술을 가르친다. 천지인·두벌식 어느 쪽이든 사용자 설정 그대로.
- **디자이너**: 시스템 키보드는 화면 아래 절반을 가린다. 자판이 올라오면 사진을 숨기고 [낱말 카드 → 입력칸 → 버튼]만 남긴다. 입력칸 높이 72dp 이상, 글자 32sp, 낱말 카드는 음절별 칸(가|을)으로 보여 주고 맞게 친 칸은 채워진다.
- **라이터**: "치기"는 어르신에게 낯설거나 거칠다. 일상어는 "자판", "쓰다"(카톡 쓴다). 단계 이름 "자판으로 쓰기", 소개 "사진 속 낱말을 자판으로 써요". 틀린 칸을 빨갛게 표시하지 말 것.
- **정책**: 입력한 글자는 서버에 저장하지 않는다(단계 완료만). 분석 이벤트에도 글자 내용 금지, 일치 여부·시도 횟수만. P2 동의 문구에서 이미 "글씨 기록"을 빼 두었으므로 그대로 정합.

## 2. 반박 1회
- 디자이너 → PM: 삼성 키보드 자동 완성이 낱말을 통째로 넣어 연습이 무력화된다. / PM: 추천 낱말 고르기도 실제 카톡에서 쓰는 기술. 끄지 않는다(안드로이드에서 강제로 끄는 `visible-password`는 한글 입력을 막아 불가).
- 라이터 → 디자이너: 음절 칸이 "채점표"처럼 보일 수 있다. / 디자이너: 맞은 칸만 채우고 다른 칸은 빈 칸 그대로 둔다. 틀림 표시는 어디에도 없다. 수용.
- 정책 → PM: 정확히 일치해야만 통과면 못 하는 어르신은 도장을 못 받는다. / PM: 완료는 막지 않는다. 일치하면 칭찬, 다르면 "다시 쳐 볼까요 / 이대로 마칠게요" 선택.

## 3. 결론 (PM 종합)
- **시스템 키보드**, 앱 전용 글자판 없음. 자동 고침·추천은 기기 설정 그대로(`autoCorrect=false`만 지정, 대문자 등 무관).
- **판정**: 양쪽을 NFC 정규화·공백 제거 후 비교. 조합 중인 마지막 음절은 판정하지 않음(목표 음절과 같아질 때만 채움). 전체 일치 시 0.6초 뒤 자동으로 완료 표시(버튼 안 눌러도 됨).
- **불일치로 "다 썼어요"**: 시트 "한 글자가 달라요. 다시 볼까요?" [다시 쳐 볼게요](주) [이대로 마칠게요] → 어느 쪽이든 단계 완료 저장 가능.
- **건너뛰기**: 입력칸 아래 글자 버튼 "오늘은 넘어갈게요" → 단계 완료로 저장(평가하지 않는다). 주요 버튼 2개 유지.
- **저장**: 글자 저장 안 함. 이벤트 `hangul_done {matched, attempts, skipped}`만.
- 자판 자동으로 띄우지 않음: 입력칸을 누르는 것 자체가 연습. 뒤로가기는 자판 먼저 닫기(안드로이드 기본).

## 4. 화면 구조·문구 초안
```
[‹ 오늘 코스]                 자판으로 쓰기 3 / 3
안내  보이는 낱말을 아래 칸에 써요        (자판 열리면 사진 숨김)
[사진 작게]  낱말 카드  [가][을]  (맞게 친 칸만 채움)
입력칸 (72dp, 32sp)  자리글: 여기를 누르면 자판이 나와요
보조  틀려도 괜찮아요. 천천히 써 봐요
[하단 고정, 자판 바로 위] 다 썼어요   (한 글자 이상일 때 누름)
글자 버튼  오늘은 넘어갈게요
일치 시   잘 쓰셨어요 / 사진도 보고 자판으로 쓰기도 하셨어요 [마치기]
```
- 화면 읽기: 카드 "쓸 낱말, 가을, 두 글자", 입력칸 "낱말 쓰는 칸", 일치 시 라이브 영역으로 "잘 쓰셨어요" 1회. 음절 칸 변화는 읽지 않음(소음).
- 첫 화면 `first.intro[1]`: "사진 속 낱말을 따라 써요" → **"사진 속 낱말을 자판으로 써요"**(13자, 읽기 라벨도 같이).
- 단계 이름: "글씨 쓰기" → **"자판으로 쓰기"**(P3 단계 행·P6 상단·P7 문구). 기존 P6 "점선을 따라 손가락으로 써요"·"한 글자만 써도 누를 수 있어요"·"다시 쓰기"는 폐기.
- 150%·200%·폭 320: 자판이 열리면 안내·보조 문구도 숨기고 카드+입력칸+버튼만(스크롤 없이 보이게).
