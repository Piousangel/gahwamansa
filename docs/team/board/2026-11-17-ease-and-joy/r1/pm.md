## A. 연결 — 지금 퍼널을 단계로 쪼개 보기
자녀 "번호 보내기" → (카톡) → 어르신이 메시지를 읽음 → **앱이 어디 있는지 모름**(공유 문구에 스토어 링크가 없다: `code.share_message` "앱을 열고 번호 6개를 써 주세요") → Play 검색·설치 → 앱 열기 → 첫 화면 "부모님 휴대폰이에요" → **카톡으로 돌아가 번호를 외움** → 앱으로 돌아와 6칸 입력 → "다음".
어르신 손이 가는 동작이 최소 9~11번이고, 그중 앱 전환 2번 + 6자리 단기 기억이 가장 큰 이탈 지점(가정, 측정 0회). 사용자 실기기 테스트 "너무 어렵다"와 일치.

| 안 | 어르신 단계 | 핵심 실패 지점 | 내 평가 |
|---|---|---|---|
| (1) 링크 한 번 누르기(설치 경로로 번호 전달 + 이미 설치면 앱 바로 열림) | 링크 누름 → 설치 → 열기 → "부모님 휴대폰" → **[연결하기] 1번** | 카톡 인앱 브라우저가 Play로 넘길 때 번호가 살아남는지(미확인), 설치 후 '열기' 대신 홈 아이콘으로 열 때 | **기본안**. 토스식 "한 화면 한 행동"에 가장 가깝다 |
| (2) QR(어르신이 카메라로) | 카메라 앱 찾기 → 비추기 → 링크 누르기 | 카메라 조작, 같이 있어야 함 | 어르신 쪽 QR은 반대. 방향을 뒤집은 "어르신 화면 QR → 자녀가 찍기"는 부모님 먼저 흐름(빌드 2)과 합칠 가치 있음 |
| (3) 대신 연결(자녀가 옆에서 어르신 폰 설정) | 0(자녀가 다 함) | 같이 있을 때만 | 비용 거의 0, 첫 화면 질문이 이미 이 상황을 전제. **안내 문구로 지금 바로** |
| (4) 클립보드 자동 감지 | 카톡에서 길게 눌러 복사 → 앱 | "복사" 자체가 어르신에게 어려움 | 효과 대비 개인정보 인상 나쁨. 기각 |
| (5) 문자 자동 읽기 | 문자로 받아야 함 | 가족 대부분 카톡(가정), 5분 창 | 빌드 1 기각 |
| (6) 단어 조합 | 한글 입력 | 자판이 더 어려움(사용자 결정 근거 "키보드에 익숙하지 않다") | 기각 |

PM 추천 조합: **(1) 링크 + 번호가 채워진 확인 화면을 기본**, 숫자 입력은 그대로 보조, (3) 대신 연결 안내 문구 추가, 공유 메시지 재구성(링크 맨 위, 번호 단독 줄 "123 456"). 6자리 다 쓰면 자동 확인(자녀 인증번호와 같은 규칙).
지표: 번호 발급 → 연결 완료율, 발급~연결 시간 중앙값, 경로별(링크 자동 채움 / 손 입력) 비율.

## B. 어르신 기록 보기
- "오늘 한 것": 기능 회의 B2(오늘 사진 다시 보기)를 **세 단계 전부 다시 보기로 확장**. 완료 상태의 P3 행 3개를 눌러 보기 전용 화면으로. 사진·내가 고른 쪽·오늘 낱말.
- "지난 날": F05 내 앨범(지난 회의에서 빌드 2 '다음')을 사용자가 직접 요청했으므로 **빌드 1로 당기자**. 범위는 자녀 "지난 답"과 같은 **최근 30일**(보관 31일 안). 달력이 아니라 **한 날 = 한 장의 목록**(한 날만 있음, 빈 날 표시 없음).
- 그 밖에 어르신에게 필요한 것: 받은 응원 다시 보기(P8은 한 번 보면 끝), "내일은 어떤 사진?" 예고(F26, 빌드 2), 가족이 연결돼 있는지 확인(설정 안 "연결된 가족" 한 줄).

## C. 완료감
토스 송금 완료처럼 **"끝났다"가 1초 안에 몸으로 느껴져야** 한다. 지금 완료는 P3 맨 위 텍스트 두 줄뿐(캡처 20). 전용 P7 순간(도장 쾅 + 짧은 진동 + 소리) → P3로 돌아오면 오늘 칸에 도장이 찍혀 있음. 단계 끝날 때마다 행이 초록으로 바뀌는 작은 체크. 칭찬 문구 없이 "사실"만.

## D. 디자인
캡처에서 비어 보이는 것: 완료 상태 P3 하단이 통째로 빈다(할 일이 없으니 주 버튼도 없음). 완료 상태의 주 버튼 자리에 "오늘 다시 보기"를 두면 빈 공간과 B가 한 번에 풀린다.

## E. 추가 발굴
1. 공유 메시지에 **스토어 링크가 없다**(가장 싼 개선, 자동 채움 이전에도 효과).
2. 연결 안 된 상태로 코스를 끝내도 "도장을 찍었어요"가 나온다(캡처 20). 실제 도장은 없음 — 사실과 다른 문구.
3. 자녀 쪽: 연결 완료 순간 자녀에게 푸시("연결됐어요")가 있어야 자녀가 다음 행동(응원)을 한다.

## 빌드 1 범위 의견
A(링크·확인 화면·문구) + C(완료 순간) + D(리듬 수정)는 필수. B 지난 날은 넣되 순서는 맨 뒤, 디자인 동결을 넘기면 첫 업데이트.

## 내가 틀릴 수 있는 이유
- 이탈 지점은 실기기 1회 관찰과 추정이다. 실제 가구 테스트에서 "설치"가 더 큰 벽일 수 있다(그럼 링크의 가치는 더 커짐).
- 카톡 인앱 브라우저 → Play 넘김에서 번호가 사라지면 (1)의 자동 채움은 '이미 설치' 경우에만 효과가 있다.
- 지난 날 화면은 "다시 보기 20% 미만이면 흡수" 검증 계획을 건너뛴다. 사용자 요청을 근거로 삼았다.
