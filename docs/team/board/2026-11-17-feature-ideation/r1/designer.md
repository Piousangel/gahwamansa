# r1 · 디자이너 — 독립 의견

기준: 시안 v3 1:1 구현(최소판 폐기), 안2 개성(도장 줄·폴라로이드·스티치 2곳·테이프 2곳·해님 도장), 해님은 어르신 화면 도장, 말은 첫 만남·완료·오류만, 자녀 화면 해님 없음, UI 에셋 SVG만·사진만 래스터, 하단 고정 = 주 버튼 1 + 보조 링크 최대 2, 주요 버튼 3개 이하.

## 디자인 쪽에서 본 빈자리
- 폴라로이드가 "앨범"의 핵심인데, 지금은 **보는 물건**일 뿐 **만지는 물건**이 아니다. 누르면 크게 보이거나 뒤집히는 상호작용이 앨범 콘셉트를 완성한다.
- 계절감이 없다. 12월 출시인데 화면은 사계절 같은 종이색이다.

## 빌드 1에 넣자고 주장하는 것
**F01만.** 시안 P4의 한 상태 추가로 끝나고, 폴라로이드를 "만지는 물건"으로 만든다. F25는 F01과 같은 탭을 두고 다투므로 빌드 2에서 F01 사용 데이터를 보고 정한다.
F02(다시 보기)는 디자인 비용이 작다(P3 완료 상태의 보조 링크 1개 + P4 보기 전용 상태). 찬성하되 **P4 하단 고정 영역의 버튼 수**를 다시 세야 한다.

## 디자인 시안 요청이 생기면 필요한 것
- P4 "크게 보기" 상태: 360·100%, 320·200%, TalkBack 순서("사진, 크게 보기 버튼" → 크게 본 화면 "사진 설명, 이전"), 동작 줄이기(페이드 → 즉시).
- C4 답 카드: "첫마디" 줄이 들어가면 카드 높이 증가 → 320·200%에서 응원 보내기 버튼이 첫 화면 밖으로 밀리는지 확인.

## 내가 틀릴 수 있는 이유
- "만지는 앨범"은 디자이너의 낭만일 수 있다. 어르신은 누르면 무언가 바뀌는 것을 **오류로 느낄** 수 있다(햅틱 결정 때 같은 이유로 햅틱을 3곳으로 제한).
