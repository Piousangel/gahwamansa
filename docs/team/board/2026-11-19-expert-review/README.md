# 앱 전체 전문가 리뷰 (2026-11-19 시작, 오너 지시)

오너 요청: 토스·배달의민족·카카오·네이버 UI/UX·기획자, Figma 디자인 시스템 전문가 관점으로 버튼 위치·문구·글꼴·디자인 시스템·기획 전체를 A~Z로 따지고, 시중 앱과 무엇이 다른지(특히 'AI스러움') 밝힌다. 기간 제한 없음, 완성도 우선.

> 패널은 실제 회사 직원이 아니라 각 회사의 **공개된 디자인 원칙·UX 라이팅 가이드·출시 화면**을 근거로 그 관점을 재현한 에이전트다. 같은 모델이라 시각 다양성에 한계가 있음 — 근거 URL·실측 값으로 보완한다.

## 단계
| 단계 | 내용 | 산출물 |
|---|---|---|
| 0a | 화면 전수 캡처: 현재 앱(어르신·자녀, 모든 상태, 360×640·411×914 × 100%·200%) + v4 시안 렌더 | `inventory/` (캡처는 에뮬레이터 전용, 개인 알림 아이콘 없는 것만) |
| 0b | 레퍼런스 조사: 4사 공개 디자인 원칙·UX 라이팅·디자인 시스템, 시니어 모드, 가족·회고 경쟁 앱 화면 패턴 | `references/` (링크·우리말 요약만, 타사 이미지 커밋 금지) |
| 1 | 패널 r1: 관점별 독립 리뷰(요소 하나하나 '왜', 시중 앱 대비 차이, AI 티 판정) | `r1/*.md` |
| 2 | r2: 교차 반박·표결, 충돌 정리 | `r2.md` |
| 3 | 종합: 우선순위 백로그(H/M/L·화면별·담당) + 리드 결정 | `SUMMARY.md` |
| 4 | 실행: 디자인 시안 수정 → 레인 구현 → 실기기 재캡처 → 패널 재심사(필요 시 반복) | PR들 |

## 패널(r1)
1. 토스 관점 — 한 화면 한 일, UX 라이팅(해요체·능동), 마찰 제거, 숫자·상태 표현
2. 배달의민족 관점 — 브랜드 개성·글꼴·일러스트·말투, '기억에 남는 한 가지', AI 티 제거
3. 카카오 관점 — 어르신에게 익숙한 패턴, 공유·초대 흐름, 접근성
4. 네이버 관점 — 정보 구조·탐색·큰 글씨 모드, 검색·목록 패턴
5. Figma 디자인 시스템 전문가 — 토큰·타입 스케일·간격 격자·컴포넌트 일관성·시안과 구현 차이
6. 기획(PM) — 가치 제안, 첫 설치→첫날 퍼널, 재방문·리텐션, 경쟁 앱 대비 포지셔닝
7. 시니어 접근성 전문가 — 65세 이상, KWCAG, TalkBack, 손 떨림·시력
8. AI 티 감사관 — frontend-design 점검표 + 시중 앱 대비 '생성된 느낌' 요소 목록
