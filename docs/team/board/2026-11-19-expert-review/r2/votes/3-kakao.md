## 3. 내 r1 철회·정정
1. **B2 v2 이득 '노랑 = 어르신이 쓴 말 = 카톡 내 말풍선'(3:143) 정정.** 낱말은 콘텐츠가 준 것을 따라 쓴 것이고 저장되지 않는다(6:199, 1:174). 그래서 이 비유는 A1 ①의 '고르신 쪽'에만 적용된다. '카톡 기본 테마 내 말풍선이 노랑'이라는 관찰도 공개 화면 기준이며 원문은 미확인이다.
2. **B2 v2 고칠 점 1(3:153) 정정**: '엄마가 쓰신 낱말' → '엄마가 고르신 쪽'.
3. **P7 제안 '고른 답이 {자녀 이름}에게 갔어요'(3:64) 정정**: 보여 주는 중일 때만이다. 미연결·거부·그만 보여 주기 중에는 다른 문장을 쓴다(1:176).
4. **C2 삭제(3:86) 철회**: D:380(빌드 1에서 합치지 않음)을 인용하지 않았다. A15-a로 대체한다.
5. **P8 '고마워요 보내기'(3:67) 빌드 2로 이동**: D:149와 충돌한다.
6. **해님 '다음부터 유지'(3:62) 철회**: A13 ②·③을 따른다.
7. **카톡 공유 템플릿 '앱 이름이 자동으로 붙는다'(2-1a 부연) 미확인 표시**: K6 원문에서 확인하지 않았다. 스파이크 항목에 넣는다.
8. **A6 내 제안 ①(자유 입력 + 카카오 닉네임 기본값) → ②로 바꿈**: 카카오 닉네임은 별명일 수 있고, 동의 항목 변경(콘솔·방침)이 필요하다.
