## 2. 반박 요지 (위원별 원문은 r2/*.md)
- **V7 '연결 강제' 전제 정정 (D)**: 지금 코드에서도 P1 '코스 보기'로 들어가면 연결 없이 P4~P7을 끝까지 할 수 있다(`useFinishStep.ts:24-36`). 링크 경로에서 연결을 미루면 손해가 셋이다.
  - 첫날 고른 답이 저장되지 않는다(`QuestionStep.tsx:48`).
  - 미연결 완료는 계측되지 않는다.
  - 연결한 날 사진이 바뀔 수 있다(추정, 서버 확인 필요).
- **V24·A의 Komp 근거 (B·C·D·E·H)**: Komp는 받기만 하는 기기다. 단계 위치 단서를 주는 P3와는 맥락이 다르다. A는 r2에서 썸네일안으로 스스로 줄였다.
- **V21 (A 철회, D·E·H 반대)**: P6 진입 직후 '다 썼어요'는 비활성이다. 그 상태에서 같은 무게의 '넘어갈게요'가 유일하게 눌리는 큰 버튼이 되면 사실상 기본값이 된다. 또 누르면 되돌릴 수 없는 완료다.
- **V13a network 보이스 (G)**: network 보이스는 읽는 문장을 서버로 보낸다. local Enhanced로 한정한다.
- **H의 Wolters 2007 인용 (F)**: 이 논문은 속도를 조작한 실험이 아니다. 대신 낯선 낱말에서 합성 음성 정답률이 35%, 사람 음성이 66%(표 3)라는 결과가 V13b의 발음 검수 근거가 된다.
- **V10 hangul result (E)**: matched/kept는 사람별 정오 기록이 된다. finished/skipped 둘로 줄인다.
- **V11 외래어 '보기만' 조건 (E→H)**: 28.4점은 새 외국어 표현을 잰 수치다. 시드 낱말 '라디오'·'버스'는 한글 자판으로 치므로 한/영 전환이 없다. H의 반대 의견은 r2에서 없어졌고 V11은 8/8이다.
- **V15 (A·H)**: '기다리는 중' 표시를 숨겨도 어르신은 자기가 물은 것을 기억해서 빈자리가 남는다. 그래서 실험을 선행 조건으로 둔다.
- **V23 (G)**: 14mm는 정사각형 탭 대상의 한 변이다. 폭이 54mm인 주 버튼에 그대로 옮길 수 없다.

## 3. 상충 정리 (주재자)
- V1과 V7 원안을 같이 하면 첫날 끝에 결정이 세 번 이어진다(H). V7 원안을 기각했으므로 해소된다.
- V3의 자동 포커스로 자판이 열리면, 현재 코드는 '넘어갈게요'를 숨긴다(H). 그래서 V3 조건에 "자판이 열려도 넘어가기가 보이게"를 넣었다.
- V16과 F22는 같은 안이다(C). 새 공수는 없고 빌드 2 순서만 V16(F22) → V15로 확정한다.
