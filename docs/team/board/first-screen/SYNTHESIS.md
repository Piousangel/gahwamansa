# 첫 화면 리뷰 종합 (토스·배민·카카오 관점 패널, 2026-11-17)

## 세 패널 공통(합의)
1. "위에 떠 있는" 원인: 누를 것이 상단 58%에 몰리고 엄지 영역(하단 40~45%)이 비어 있다 → **버튼 묶음을 하단에 고정**
2. 버튼 설명이 버튼 사이에 떠서 어느 버튼 것인지 애매 → **설명은 버튼 안 둘째 줄**
3. **말하는 해님은 첫 화면에서 뺀다**(그림 없이 이름만 말함, 자녀도 보는 화면, 아이 취급 위험). 해님의 첫 인사는 어르신 연결 직후 앨범이 처음 열릴 때
4. 두 버튼의 기준이 상황("받은 번호가 있어요")과 신분("자녀예요")으로 섞여 자녀가 부모 폰을 대신 설정하다 잘못 누를 위험
5. 인증번호 화면: 안전 영역 버그, 입력칸·키 재질 구분, 이전 버튼, **6자리 채우면 자동 확인**, 문구 줄이기

## 엇갈린 것 → 시안 3안으로 비교
| 안 | 출처 | 질문·버튼 | 가운데 |
|---|---|---|---|
| A 누구 폰 | 카카오 | "이 휴대폰은 누구 거예요?" [부모님 휴대폰이에요] [자녀 휴대폰이에요] | 비움(여백) |
| B 행동 | 토스 | 제목 하나 + [번호를 받았어요] [번호를 만들게요] | 작은 브랜드만 |
| C 브랜드 | 배민 | 심볼+워드마크+한 줄 설명, [번호를 받았어요] [가족에게 번호를 보낼게요] | 폴라로이드 1장(AI 사진) |
공통: 얼굴 없는 해 실루엣 심볼(작게), 버튼 하단 고정, 설명은 버튼 안, 해님 말 없음
