# 카카오 시니어·접근성 PM 관점 리뷰 · 첫 화면 (2026-11-17)

전제: 어르신은 자녀가 깔아 준 폰을 들고, 자녀가 옆에서 "이 번호 눌러요"라고 불러 주는 상황이 대부분이다. 첫 화면의 일은 "이 폰 주인이 누구냐"를 3초 안에 가르는 것.

## 1. 첫 화면 가장 큰 문제 3개 (01-first-screen.png 근거)
1. **누가 누르는 버튼인지 이름이 엇갈린다.** 위 버튼은 상황("받은 번호가 있어요"), 아래 버튼은 신분("자녀예요")이다. 어르신은 "나는 번호 없는데?"(아직 문자 확인 전)라며 멈추고, 자녀는 부모 폰을 대신 설정하다 "나 자녀니까" 하고 **부모 폰에서 '자녀예요'를 누르는 사고**가 난다. 이게 이 화면의 최대 위험.
2. **설명 문구가 어느 버튼 것인지 애매하다.** "가족에게 받은 번호를 써요"가 두 버튼 사이 한가운데 떠 있어 아래 버튼의 제목처럼도 읽힌다. 확대·저시력 사용자는 위아래 근접만으로 묶음을 판단한다. 설명은 버튼 안(2줄 라벨)으로 넣어야 한다.
3. **모든 게 위 55%에 몰리고 아래 45%가 비어 있다.** S25 한 손 조작 시 엄지가 닿는 곳은 하단인데, 정작 누를 것이 상단에 있다. 사용자 말 "위에 떠 있다"의 정체는 여백 문제가 아니라 **조작 영역과 내용 영역이 뒤집힌 것**.
- 덧: "어떻게 쓰실 거예요?"는 어르신에게 추상적이다(쓰다=사용? 글쓰기?). "안녕하세요, 해님이에요"는 그림 없이 이름만 나와 '해님이 누구지?'를 하나 더 만든다.

## 2. 마스코트(해님): 조건부
- 첫 화면의 일(신분 가르기)에는 기여하지 않는다. 지금처럼 **그림 없이 이름만 말하는 건 불필요**(낯선 고유명사 하나 추가).
- 쓴다면 상단 작은 그림 1개, 말은 하지 않는다. 해님 소개는 연결이 끝난 첫 만남 화면(DECISIONS 원칙)으로 미루는 게 맞다. 자녀도 이 화면을 보므로 "자녀 화면 해님 제외" 원칙과도 첫 화면 대사는 충돌한다.

## 3. 첫 화면 개선안
- **위(약 35%)**: 서비스명 "가화만사성" + 한 줄 "가족 사진을 같이 모아 보는 앨범이에요". 해님 대사 삭제.
- **가운데**: 질문 "이 휴대폰은 누구 거예요?" (어르신·옆의 자녀 모두 같은 답을 낸다 = 폰 주인 기준).
- **아래(엄지 영역, 하단 고정)**: 같은 크기의 큰 카드 버튼 2개, 위계는 색이 아닌 순서로.
  - ① [부모님 휴대폰이에요 / 자녀에게 받은 번호를 넣어요] — 채움, 위
  - ② [자녀 휴대폰이에요 / 부모님께 보낼 번호를 만들어요] — 테두리, 아래
  - 각 버튼 최소 높이 72dp 이상, 2줄 라벨, 아이콘(어르신/자녀 얼굴 실루엣) 왼쪽에. TalkBack 라벨은 두 줄을 한 문장으로("부모님 휴대폰이에요. 자녀에게 받은 번호를 넣어요. 버튼").
- **빈 공간**: 지우려 애쓰지 말고 위·가운데를 세로 중앙 정렬, 버튼 묶음은 하단 고정. 글씨 크기 최대(시스템 200%)에서도 버튼이 화면 밖으로 밀리지 않게 스크롤 대신 상단 문구가 줄어들도록.
- 안전장치: ②를 눌렀는데 이 폰에 이미 다른 기기 연결 이력이 없고 사용자가 망설이면, 다음 화면 첫 줄에 "부모님 폰이면 뒤로 가 주세요" 한 줄.

## 4. 인증번호 화면 (02-child-otp.jpeg)
- **입력칸/키 구분 — 동의, 가장 시급.** 입력칸과 키가 같은 흰 바탕·같은 갈색 테두리·같은 둥근 모양이라, 어르신이 아니어도 입력칸을 누르려 한다. 입력칸은 테두리 없는 밑줄 또는 회색 채움 + 현재 칸만 진한 강조, 키는 채움 버튼으로 재질을 달리할 것. 입력칸 높이도 키보다 낮게.
- **하단 고정 — 동의, 그리고 지금은 버그.** "확인하기"가 시스템 내비게이션 바 뒤에 깔려 반쯤 가려져 있다(edge-to-edge 인셋 미처리). 하단 고정 + safe area 반영, 6자리 다 차면 자동 확인 + 버튼은 보조.
- **이전 — 동의.** 화면에 뒤로 갈 수단이 시스템 뒤로뿐이다. 좌상단 "‹ 이전" 텍스트 버튼(48dp 이상). 이메일 주소 잘못 쓴 경우를 위해 주소 옆 "주소 바꾸기"도.
- 이 화면은 자녀용이므로 커스텀 키패드 자체가 과하다. 시스템 숫자 키보드 + 자동완성(oneTimeCode)이 자녀에게 더 빠르다. 커스텀 키패드는 어르신 번호 입력 화면에만.

- 자녀 화면의 커스텀 키패드.
