# 토스 프로덕트 디자이너 관점 리뷰 · 첫 화면 (2026-11-17)
근거: 실기기 캡처 01-first-screen.png, 02-child-otp.jpeg (갤럭시 S25, 1080x2340)

## 1. 첫 화면 가장 큰 문제 3개
1. **무게중심이 위로 쏠림**: 내용이 화면 위쪽 58%(설명 마지막 줄이 y≈1145/2000)에서 끝나고, 아래 40%는 비어 있음. 엄지가 닿는 아래쪽이 비고 버튼은 위쪽에 있어 "떠 있다"는 느낌이 듦. 사용자 피드백과 같은 원인.
2. **설명이 어느 버튼 것인지 애매함**: "가족에게 받은 번호를 써요"가 위 버튼과 아래 버튼 사이에 거의 같은 간격으로 떠 있음(위 버튼과 약 70px, 아래 버튼과 약 95px). 근접성이 깨져 설명이 아래 버튼 제목처럼 읽힘. 설명은 버튼 안에 넣거나 버튼에 8px 이내로 붙여야 함.
3. **질문과 답의 결이 다르고 텍스트 층이 4개**: 브랜드명 / 해님 인사 / 질문 / 버튼으로 크기·굵기가 비슷한 갈색 텍스트가 4층 쌓임. 답도 "받은 번호가 있어요"(상태)와 "자녀예요"(신분)로 결이 달라 비교하는 데 한 박자 걸림. 그림 없이 "해님이에요"라는 말만 있으면 해님이 누구인지 알 수 없음.
- 세부: 시스템 내비게이션 바는 흰색인데 배경은 크림색이라 아래쪽이 끊겨 보임. 주 버튼 그림자는 이 배경에서 탁해 보임.

## 2. 마스코트(해님): **첫 화면에서는 불필요**
- 첫 화면이 할 일은 "나는 어느 쪽인지" 고르는 것 하나. 인사말은 그 고르기를 늦추기만 함. 지금은 그림도 없이 이름만 나와 정보로서 가치가 0.
- DECISIONS의 원칙(말은 첫 만남·완료·오류에만, 자녀 화면 제외)에 따르면, 첫 만남은 **어르신 쪽으로 연결된 직후**(앨범이 처음 열리는 순간)가 맞음. 자녀도 보는 갈림길 화면은 대상이 아님.
- 남긴다면 조건: 말 없이 작은 그림(48~64dp)으로 브랜드 옆에만. 말풍선·인사는 빼기.

## 3. 개선안 (한 화면 한 행동)
- **위(상태바 아래 24dp)**: 작은 브랜드 표시 "가화만사성"(20sp 정도, 위계 낮춤).
- **가운데(세로 중앙보다 약간 위)**: 제목 하나. "가족과 앨범을 나눠요"(28~32sp 굵게) + 보조 한 줄 "누가 쓰시나요?"(18sp 회갈색). 인사말은 삭제.
- **아래(엄지 영역, 하단 안전 영역 + 16dp에 고정)**: 선택 카드 2개를 세로로 쌓기. 각 카드 = 제목 + 설명을 **카드 안**에 둠.
  - 주(채움): **"번호를 받았어요"** / 안: "가족이 보내준 번호로 시작해요" (어르신)
  - 보조(흰 바탕 + 얇은 테두리 또는 연한 회색 채움): **"번호를 만들게요"** / 안: "부모님께 보낼 번호를 만들어요" (자녀)
  - 둘 다 행동형("~했어요/~할게요")으로 맞춤. 신분("자녀예요")보다 할 일을 말하는 게 덜 망설여짐.
- 높이: 주 카드 72dp 이상, 카드 사이 12dp. 그림자 빼고 색 대비로만 위계.
- 빈 공간: 제목과 카드 사이를 비워 두는 건 괜찮음. 빈 공간은 위쪽에 두고, 행동은 아래에 몰아둠.
- 시스템 바: 배경색과 맞추기(edge-to-edge + 내비게이션 바 투명/크림).

## 4. 인증번호 화면
- **치명적 버그 먼저**: "확인하기"가 제스처 내비게이션 바 아래로 잘려 있음. 하단 안전 영역(inset) 처리 누락. 플로팅 고정 버튼으로 바꾸고 `bottom = inset + 16dp`로 둘 것.
- **입력칸과 키 구분**: 지금은 둘 다 흰 채움 + 갈색 테두리 + 둥근 모서리로 똑같음. 입력칸 = 연한 회색 채움 또는 밑줄, 입력 중인 칸만 진한 테두리, 채워진 칸은 숫자를 굵게. 키패드 = 테두리 없이 배경과 같은 면 위에 숫자만(눌렀을 때만 회색). 서로 다른 재질로 보여야 함.
- **자동 확인**: 6자리를 다 넣으면 바로 확인 요청. 버튼은 실패하거나 다시 시도할 때만 쓰게. 그러면 하단 버튼 문제도 대부분 사라짐.
- **문구 4덩어리를 2개로**: 제목 "yyh…@gmail.com으로 보낸 6자리를 입력해 주세요" + 보조 한 줄 "10분 안에 입력 · 메일이 없으면 스팸함 확인". 남은 시간은 숫자로 보여 주기(09:41).
- **이전**: 상단 왼쪽에 48dp 뒤로 가기 아이콘 + 아래쪽 텍스트 버튼 "메일 주소 바꾸기 / 다시 보내기". 지금은 다시 보내기도 없어 길이 막힘.
- 키 라벨: "모두 지움"은 빼고 "지움"은 ⌫ 아이콘으로(길게 누르면 전체 삭제).

## 5. 빼야 할 것

- 인증 화면의 "모두 지움" 키, 문구 4줄 중 2줄, 입력칸·키 공통 갈색 테두리
