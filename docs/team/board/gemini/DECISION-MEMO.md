# 회의 결론 · Gemini로 마스코트·에셋 만들기 (2026-11-17)

위원 6명(브랜드·아이콘·UX 감사관·정책·QA·사업 기획), 2라운드(독립 의견 → 상호 반박·표결). 원문 `r1/`, `r2/`. 최종 결정은 사용자.

## 한 줄 요약
**Gemini는 "탐색 도구"로 적극 쓰되, 앱 안과 브랜드 최종본은 사람이 다시 그린 SVG만 쓴다.** 해님의 "어린이 느낌"은 그림보다 볼터치·말풍선 서체·칭찬 말투가 겹쳐 생기므로 빌드 1에서 함께 고친다.

## 위원들이 입장을 바꾼 점
- 사업: 앱 아이콘 "앨범·집 상징" → **얼굴 없는 해 실루엣**(요소 3개 이상은 16~24px에서 뭉개진다는 아이콘 디자이너 반박 수용).
- 아이콘: 빌드 1 앱 안 래스터 0장(사진 예외)으로 정리. 브랜드: 표정 3종 축소 동의.
- QA: "앱 안 래스터 금지"를 "UI 에셋은 SVG만, 사진은 예외"로 고침.

## 남은 이견(소수 의견 보존)
- 해님 재설계 시점: 사업만 빌드 2 주장(일정 위험). 다수는 "스크립트 수치 조정이라 반나절(추정, 미검증)"로 빌드 1.
- 자녀 화면의 해님: 브랜드는 도장만 유지, UX는 전면 제외.
- 판화·도장풍 질감 전환(UX 제안)은 브랜드가 반대(40px에서 뭉개짐) → 형태 언어만 참고.

## 사용자 결정이 필요한 것
1. 해님의 역할: "평소엔 앨범의 상징(도장), 말은 첫 만남·완료·오류에만"(권고)
2. 자녀 화면의 해님: 전면 제외(리드 권고: 자녀 화면은 정보 화면이고 해님은 어르신의 앨범 상징) / 도장만 유지
3. 앱 아이콘 방향: 얼굴 없는 해 실루엣 + 폴라로이드 틀(요소 2개 이하), 16·24·48px 판독 확인 후 자녀 몇 명 반응으로 고름(권고)
4. "가화만사성" KIPRIS 1차 검색(사용자 수행)에서 충돌하면 이름을 바꿀지, "가화만사성 + 식별 요소" 결합형으로 갈지
5. 사용자 원래 의도 확인: "신경 써서 뽑자"는 그림체를 바꾸자는 뜻인가, 지금 해님을 다듬자는 뜻인가(위 권고는 "다듬기 + Gemini로 방향 확인")
