# 정책 의견 (Gemini 에셋 R1) · 2026-11-17
법률 자문 아님. 법적 판단은 모두 **전문가 확인 필요**. 다른 위원 파일은 읽지 않음.

## 확인한 사실 (출처, 확인일 2026-11-17)
- Gemini API 약관(https://aistudio.google.com/docs/terms, "Effective March 23, 2026"): 구글은 생성물의 소유권을 주장하지 않음. 생성물 사용 책임은 이용자. **같거나 비슷한 생성물을 다른 사람에게도 만들어 줄 수 있고 구글이 그 권리를 유보함.** 무료(Unpaid) 이용 시 입력·출력이 제품 개선에 쓰이고 사람이 검토할 수 있음, 유료는 개선에 쓰지 않음. 만 18세 이상. "상업 이용 허용"을 명시한 문장은 이 페이지에서 확인 못 함(전문 서비스·업무 목적 이용이라고만 씀) → 상업 이용 범위는 **미확인**(생성형 AI 금지 사용 정책 등 연결 문서 미조회).
- Play AI 생성 콘텐츠 정책(https://support.google.com/googleplay/android-developer/answer/14094294): 대상은 AI로 콘텐츠를 **생성하는** 앱. 생성 기능 없이 AI 생성물만 담은 앱은 대상이 아니라고 명시. 라벨 표시 요건은 이 페이지에 없음. 스토어 등록정보 규정의 AI 이미지 조항은 **미확인**.
- 한국 인공지능기본법(2026-01-22 시행, 뉴시스 2026-01-21 보도의 과기정통부 안내 요약, https://www.newsis.com/view/NISX20260121_0003485509): 표시 의무 주체는 생성형 AI 제품·서비스를 이용자에게 제공하는 **AI 사업자**. AI를 도구로만 쓴 이용자는 대상 아님. 서비스 화면 안에서만 보이는 결과물은 개별 표시 대신 사전 고지. 명백한 가상 일러스트·애니메이션은 딥페이크 아님. 계도기간 1년 이상. 시행령 원문은 미조회 → **전문가 확인 필요**.
- 토스(앱인토스) 정책의 AI 생성 이미지 조항: **미확인**(03 문서 범위에도 없음).

## 안건별 입장
**A 해님 하이브리드: 찬성(정책상 가장 안전).** 근거(가정·전문가 확인 필요): 사람의 창작적 기여가 없는 순수 AI 생성 이미지는 저작물로 보호받기 어렵다는 것이 일반적 해석이라, 래스터를 그대로 마스코트로 쓰면 **남이 비슷한 그림을 써도 막기 어렵다**. 약관상 비슷한 그림이 남에게도 나올 수 있음(사실). 하이브리드의 의미: 팀이 SVG로 다시 그린 형태·비율·표정 세트·도장 등은 **사람 창작분**으로 주장할 여지가 생긴다. 조건: (1) Gemini 안은 "참고 스케치"로만 쓰고 최종 SVG는 사람이 새로 그림(트레이싱만으로 충분한지는 전문가 확인 필요). (2) 프롬프트·생성 원본·수정 과정(날짜별 파일)을 보관해 창작 경위를 증명. (3) 기존 유명 캐릭터·작가 화풍을 프롬프트에 넣지 않음("○○ 스타일" 금지), 유사성 검색 1회.
**B UI 아이콘 Gemini 미사용: 찬성.** 정책 이슈는 작음. 오픈소스 아이콘 섞을 때 라이선스 기록만.
**C 일러스트형 에셋: 조건부.** 앱 안 빈 상태·축하·온보딩 그림은 위 표시 예외 범위에 가까움(가정). 조건: 스토어 그래픽·앱 아이콘은 **브랜드 식별 자산**이므로 하이브리드(사람 정리) 원칙 적용. 사진·실존 인물처럼 보이는 그림, 실재 장소·브랜드 로고가 들어간 생성물은 제외. 무료 등급으로 미공개 브랜드 자료를 올리지 않음(사람 검토 가능, 사실).
**D 법·표시: 조건부(초안 "표기는 사진만"을 수정).**
| 에셋 | 표시 권고 | 근거 |
|---|---|---|
| 옛날 사진(실사풍) | 화면 안 작은 고지 + 앱 설명·방침에 "AI로 만든 그림" 명시 | 실제 과거 사진으로 오인 가능. 어르신이 "진짜 우리 동네 사진"으로 믿는 것은 사용자 관점 문제 |
| 마스코트(SVG 최종) | 개별 표시 불필요(가정) | 사람이 정리한 최종물, 명백한 가상 캐릭터 |
| 앱 안 일러스트 | 앱 설명·정보 화면에 일괄 고지 1회 | 화면 안 결과물은 사전 고지로 갈음(위 보도 요약) |
| 앱 아이콘 | 표시 안 함(가정) | 사람이 정리하는 것을 전제 |
| 스토어 그래픽 | 실사풍 사진을 쓰면 "AI 생성 이미지" 캡션 권장 | 스토어 규정 미확인, 오인 방지 |
- 우리가 AI 사업자인지(생성 기능을 이용자에게 제공하지 않음 → 단순 이용자일 가능성)는 **전문가 확인 필요**. v3 실시간 생성 도입 시 사업자가 되어 고지·표시 의무가 생길 수 있음.
- SynthID가 모든 생성물에 들어간다는 것은 팀 문서 기준(사실). 기계 판독 표시로 충분한지는 미확인.
**상표(서비스명 가화만사성·해님):** "가화만사성"은 널리 쓰이는 관용구라 **식별력이 약해 등록이 어렵거나 이미 선등록이 있을 가능성**(가정, KIPRIS 미조회). 출시 전 KIPRIS 검색(9류 앱, 41·42·45류 등 지정상품 범위는 변리사 확인 필요)과 대안명 1~2개 준비. 마스코트는 도형 상표로 출원 가능성이 있고, 상표는 저작권과 별개라 AI 관여가 곧 거절 사유는 아니라고 보지만(가정) **전문가 확인 필요**. 출원은 최종 SVG 확정 뒤.
**E 해님 성격: 찬성.** 정책 관점 이슈 없음. 의료 표현 금지 규칙(어르신을 환자·아이로 대하는 말 금지)과 맞춤.
**F 빌드 1 컷 제안:** 마스코트는 기존 SVG 28개 유지 + Gemini 탐색은 병행만. 스토어 그래픽·아이콘 최종본은 상표 검색 결과 이후. 실사풍 생성 사진 신규 추가는 고지 문구 확정 후.

## 내가 틀릴 수 있는 이유
1. Gemini 약관의 연결 문서(금지 사용 정책, Google 서비스 약관)에 상업 이용 제한이 있을 수 있는데 읽지 않았다.
2. 한국 저작권 판단(사람 기여 정도)과 표시 의무 범위는 보도·일반론 기반이다. 시행령·가이드라인 원문은 읽지 않았다.
3. 앱 안 사진 고지는 법적 의무가 아닐 수 있다(사용자 신뢰 차원 권고).
4. 토스 검수가 AI 이미지를 별도로 다룰 수 있는데 확인 못 했다.

## 빠진 질문
- 어르신이 생성 사진을 실제 과거 사진으로 믿고 자녀에게 "여기 가 봤다"고 말한다면 앱은 무엇을 책임지는가?
- 유료(Paid) 등급으로 생성하는가? 무료 등급이면 브랜드 시안이 학습·사람 검토 대상이다.
