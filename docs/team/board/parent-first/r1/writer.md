# 라이터 의견 (parent-first R1) — 관점: 어르신이 번호를 "보내는" 말
가정: 서비스명 가화만사성, 어르신 화면 해요체·20자 안팎·버튼 2~6자(공백 제외), 확정 용어("가족", "보여 주기", "모두 지우기")를 그대로 쓴다.

## 안건별 입장
**A 조건부 찬성** — 어르신에게 "번호를 만들어 보낸다"는 일은 은행·택배 문자에서 사기 경고로 배운 행동과 겹친다(가정). 말이 "보내기·인증·코드"면 멈춘다. 조건: 행동 이름을 **"보내기"가 아닌 "알려 주기"**로 쓰고, 무엇이 안 가는지 먼저 말한다.
- 진입 버튼 후보: ① "가족에게 보여 주기"(초안, 확정 용어와 같음·추천) ② "가족 부르기" ③ "같이 볼 가족 찾기"
- 번호 화면 후보(제목 / 안심 줄):
  1. "이 번호를 가족에게 알려 주세요" / "번호만 알려 주면 돼요. 돈이나 개인 정보는 묻지 않아요" (추천)
  2. "가족이 이 번호를 쓰면 연결돼요" / "전화로 불러 줘도 돼요"
  3. "번호 6개를 가족에게 보여 주세요" / "가족만 알려 주세요"
- 버튼: "카톡으로 알리기"(주) 하나 + 링크 "말로 불러 줄게요"(큰 숫자 화면만 유지). "공유"는 외래어 느낌이라 쓰지 않음.
**B 조건부 찬성** — 연결 확인 한 번은 꼭 말로 남긴다. 후보: "{이름}님이 연결됐어요. 아는 가족인가요?" 버튼 "네, 가족이에요" / "모르는 사람이에요". 거절 시 "연결을 끊었어요. 번호는 다시 만들 수 있어요". 자녀 이름이 토스·카카오에서 오는지 미확인(없으면 "가족 한 명이 연결됐어요"로는 사칭 확인이 불가 → 반대로 바뀜). 24시간 만료 문구: "24시간 동안 쓸 수 있어요"(시계 숫자 카운트다운 금지).
**C 찬성** — 처음부터 가족을 만들면 "답이 저장된다"고 말할 수 있어 문구가 단순해진다. 미연결 열람의 "고른 답은 저장되지 않아요"와 섞이면 같은 앱에서 두 사실이 생긴다 → 부모님 먼저 흐름에서는 "가족이 연결되면 고른 답이 보여요" 한 문장으로.
**D 찬성(초안 그대로)** — 큰 숫자 + 버튼 하나. 숫자는 "482 915"처럼 3자리 띄움, TTS는 "사, 팔, 이 … 구, 일, 오" 한 자씩.
**E 의견 없음(사업)** — 단 "자녀가 안 들어오는 가족"에게 독촉 문구를 보내지 않는다. 어르신 화면에는 "가족이 연결되면 여기에 알려 드려요" 정도만.
**F 조건부** — 동의 시점이 연결 순간이면 어르신이 동의 화면을 "자녀가 들어온 뒤" 본다. 문구 후보: "가족이 연결됐어요. 이제 고른 답을 보여 줄까요?" 좋아요/싫어요. 자녀가 여럿이면 "연결된 가족 모두에게 보여요"(확정 용어).
**G 찬성(합치기)** — 같은 "번호 만들기/번호 쓰기" 화면을 역할만 바꿔 재사용하면 문구도 키 하나에 `{상대}`(가족/부모님)만 바꾸면 된다. 단 `{상대}` 뒤 조사는 붙이지 않는 구조로("가족에게"·"부모님께"를 통째로 변수화).

## 첫 화면 역할 선택 (누가 고르는지 헷갈리지 않게)
문제: 자녀가 어르신 폰에 깔아 주며 고르는 경우와 어르신 본인이 고르는 경우가 섞인다. "자녀예요/부모님이에요"는 고르는 사람 기준이라 틀리기 쉽다. **폰 주인 기준**으로 묻는다.
- 후보 1(추천): 질문 "이 폰으로 무엇을 하실 건가요?" / 버튼 "사진 보고 답하기"(아래 작은 줄: 부모님이 쓰는 쪽) / "부모님 답 받아 보기"(자녀가 쓰는 쪽). 하는 일로 고르게 해 누가 눌러도 같은 답이 나온다.
- 후보 2: "이 폰은 누구 폰인가요?" / "부모님 폰이에요" / "자녀 폰이에요" (자녀가 대신 설치할 때 명확, 어르신 본인에겐 자기를 "부모님"이라 부르는 어색함)
- 후보 3: "어떻게 시작할까요?" / "제가 사진을 볼래요" / "부모님과 연결할래요"
- 어르신 쪽 다음 화면: "받은 번호가 있어요"(번호 쓰기) / "처음이에요"(코스 시작, 가족은 나중에). "처음이에요"가 부모님 먼저 흐름의 입구.

## 카톡 메시지 본문 후보 (사칭 오해 방지)
원칙: 서비스명을 맨 앞에, 돈·급함·개인정보 요구 없음, 링크는 하나, 모르면 무시해도 된다는 줄, 번호 만료 표시.
1. (어르신→자녀, 추천) "[가화만사성] 엄마/아빠가 보낸 연결 번호예요. 번호 482 915 (24시간 동안 쓸 수 있어요). 앱에서 이 번호를 쓰면 제가 고른 옛날 사진 이야기를 같이 볼 수 있어요. 돈이나 개인 정보는 묻지 않아요." — "엄마/아빠" 자리는 어르신이 고르지 않으므로 실제로는 **"가족이 보낸"**으로 고정(호칭 조사 문제·성별 추정 회피).
2. "[가화만사성] 가족 연결 번호: 482 915. 매일 옛날 사진 한 장으로 이야기를 나누는 앱이에요. 번호는 24시간 뒤 사라져요. 모르는 분이 보낸 거라면 지워 주세요."
3. (자녀→어르신, 기존 흐름 개정) "[가화만사성] 같이 쓸 번호예요. 앱을 열고 번호 6개를 써 주세요. 482 915 (7일 동안 쓸 수 있어요). 돈이나 개인 정보는 묻지 않아요."

## 내가 틀릴 수 있는 이유
1. "돈이나 개인 정보는 묻지 않아요"라는 문장 자체가 오히려 사기 문자 문법을 닮아 의심을 키울 수 있다(미확인).
2. "알려 주기"가 "보내기"보다 부담이 적다는 것은 가정이다. 어르신은 카톡의 "보내기"에 이미 익숙할 수 있다.
3. 역할 선택을 "하는 일"로 물으면 자녀가 부모님 폰에 대신 설치하면서 자기 기준으로 "부모님 답 받아 보기"를 누를 수 있다.

## 빠진 질문
- 카톡 공유 시 보내는 사람 이름이 카톡 프로필로 보이는가(그렇다면 메시지에 "가족이 보낸"을 쓸 필요가 줄어듦).
- 토스 안에서 카톡 공유가 허용되는가(자사 앱 설치 유도 금지와의 경계, 미확인).

## 사용자에게 묻고 싶은 것
- 역할 선택 후보 1(하는 일 기준)과 2(폰 주인 기준) 중 어느 쪽이 자연스러운지 어르신 1~2분께 보여 드려도 되는지.
