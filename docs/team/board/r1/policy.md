# 정책·개인정보 의견 (R1)
2026-11-17. 법률 자문이 아닌 제품 점검. 법적 판단은 "전문가 확인 필요". 사실=기존 policy.md·03 문서·UX-AUDIT에서 읽은 것, 가정=내 추정.

## 안건별 입장
**A 자녀 범위 축소: 조건부 찬성.** 사용자 관점: 어르신은 "내가 한 일을 누가 얼마나 보는지" 알고 눌러야 한다. 사실: UX-AUDIT 5번, P2는 "고른 답"만 말하는데 자녀 홈은 단계 완료·연속일까지 보여 준다. 축소하면 동의 문구와 화면이 일치하기 쉬워진다.
- 조건 1: 동의 문구가 **자녀 화면에 실제로 뜨는 항목과 1:1**이어야 한다. "고른 답"과 "오늘 했는지" 둘 다 쓰면 둘 다 적는다. 보이는 데이터가 늘면 동의 문구와 방침(site/index.html 1·2절)도 같은 날 고친다.
- 조건 2(구멍): 동의 거부 시 "답은 저장 안 함" 결정과 "오늘 했는지는 자녀에게 보임"이 충돌한다. 참여 여부도 어르신의 활동 기록이다. 거부하면 **참여 여부도 자녀에게 보내지 않는 것**이 일관적이다(자녀 홈은 "아직 연결만 됐어요" 같은 중립 상태). 이 선택은 사용자 결정(아래).
- 철회 수단: (1) 어르신 앱 설정에 "자녀에게 보이는 것 끄기"와 "연결 끊기"를 큰 버튼으로, 코스 홈 밖에 둔다. (2) 철회 후 새 기록은 저장·전송 안 함. (3) 이미 저장된 기록은 철회 시 지울지 남길지를 화면에 쓴다(방침 2절 자리표시 미결). (4) 앱을 못 여는 경우의 이메일 요청은 delete-account.html. 철회 시점·문구 버전 저장은 유지.
- 대리 동의 위험(가정): 자녀가 어르신 폰에서 대신 눌러 동의하는 경우가 흔하다. 어르신 본인 동의로 볼 수 있는지는 **전문가 확인 필요**. 화면에서 "어르신이 직접 보고 누르세요" 안내와 동의 시점 기기 로그로 완화.
- 의료 표현: 범위 축소 후에도 리포트가 상태를 해석하는 문구는 금지(policy.md 3절).

**B 재연결·P11·P14 토스 보류: 조건부 찬성.** 재연결만 보류한다. **철회·삭제 화면(P9/P10, 연결 끊기)은 토스에서도 필요**(토스 가이드: 연결 해제 시 데이터 삭제 의무). 사실: anonKey가 기기를 넘어 유지된다는 점은 내가 문서로 확인하지 못함(미확인).

**C P8·C7 빌드 1 포함: 찬성.** C7은 삭제·호칭·알림 철회가 한곳에 있어 Play 삭제 요건(앱 안 경로)의 실체다. 빠지면 출시 차단. P8은 어르신 알림 수집(FCM 토큰)의 사용자 이득이 생기는 화면이라 푸시 동의와 함께 의미가 있다. 푸시 동의 문구는 답 공개 동의와 **분리**(가정: 분리가 안전, 법적 요건은 전문가 확인 필요).

**D 삭제 위계·문구: 찬성 + 문구 요건.** "그만둘래요"가 주 버튼. 삭제 확인 화면은 아래를 **전부** 말한다.
1. 무엇이 지워지나(답, 기록, 도장, 응원, 푸시 알림 설정).
2. 자녀에게서도 사라지나 / 연결이 끊기나 / 가족이 남나(자녀 전원 탈퇴 시에만 가족 전체 삭제는 제안안, 미결).
3. 되돌릴 수 없다.
4. 백업·외부 서비스(Supabase, Firebase 등)에 남는 사본의 삭제 시점. 법정 보존이 있으면 항목·기간. 모르는 값은 "[운영자 입력 필요]" 그대로 둠.
5. 끝난 뒤 다음 단계(P10 이후 안내 없음).
- 용어: 어르신 "지우기", 자녀 "삭제"의 불일치는 방침·삭제 안내 페이지와도 맞춘다("지우기" 한 단어 권장, "데이터"는 "고른 답과 기록").
- 자녀 삭제 화면 C8: "엄마 폰은 다시 연결해야 해요"처럼 어르신 영향을 한 줄로.

**토스 트랙 개인정보**
- anonKey는 개인정보인가: 가정=**개인정보로 취급**. 우리에겐 토스가 준 불변 식별자이고 답·참여 기록과 결합되어 개인을 계속 구분한다. 토스는 원본 사용자와 결합할 수 있어 "다른 정보와 쉽게 결합해 알아볼 수 있는 정보" 또는 가명정보에 가까울 수 있다. 법적 분류는 **전문가 확인 필요**. anonKey의 생성 방식·유효 범위는 문서 미확인.
- 처리위탁·제3자 제공: 토스(토스 앱 이용 약관 하의 제공자), Supabase, FCM 등. 토스가 우리에게 anonKey를 주는 관계가 위탁인지 제공인지는 **전문가 확인 필요**. 방침에 토스 경유 수집 항목과 제공 주체를 쓴다.
- 해외 이전: Supabase 리전 미정(미확인). 해외면 이전 국가·시기·방법·연락처 고지와 동의 요건 **전문가 확인 필요**. Firebase 푸시도 동일.
- 토스 로그인 없이 anonKey만: 토스 로그인의 연결 해제 콜백이 없어 **삭제 의무를 어떤 이벤트로 트리거하는지 미확인**(콘솔·문서 확인 필요). 고지는 방침(이 앱이 받는 항목은 anonKey, 답, 참여 기록, 푸시 토큰)과 앱 안 동의 화면으로 충분한지 전문가 확인 필요. 자체 로그인 금지와의 관계는 문서에 없음(03 문서 §2 미확인 유지).
- 방침 접근 구멍: 토스 미니앱은 토스 도메인 외 이동·렌더링 불가(확인). `site/index.html`을 앱에서 링크로 열 수 없을 수 있다. **방침·삭제 안내를 앱 안 화면으로도 제공**해야 한다(미확인, 콘솔 검수에서 확인). 라이트 모드·글자 규칙은 동일.
- 자동 동의창 금지는 토스 로그인·알림 동의 바텀시트 얘기(확인). 우리 P2 동의는 앱 화면이라 대상이 아닐 가능성이 높지만 "진입 즉시 뜨는 동의"는 피하고 코스 직전에 둔다(가정).
- 토스 트랙이 자녀만이면 어르신 동의 없이 어르신 데이터가 생기지 않도록 연결은 반드시 어르신 쪽 동의 후 시작한다.

**E 호칭: 찬성.** 자녀가 쓰는 호칭은 제3자(어르신) 관련 자유 입력이므로 길이 제한만 두고 방침의 수집 항목에 "호칭(자녀 입력)" 한 줄 추가(사실: 현재 방침 표에 없음).

**F 토스 전제(어르신=토스 사용자): 조건부.** 근거 없음(확인). 대안은 사업 기획에 맡기되 정책 관점 제약은 위 "자녀만" 항목.

**G 화면 컷: 의견.** 정책상 빌드 1 필수: P2 동의(범위 일치), 철회/연결 끊기, P9·P10 지우기, C8, C7, 방침·삭제 안내 접근 경로, 의료기기 아님 고지(설정 하단). 컷 가능: 재연결 변형, 장식 상태.

**H 못 한 날을 알리지 않는 원칙: 조건부(수정 제안).** 사용자 관점: 어르신은 쉬는 날에 압박받지 않고, 자녀는 서운함·불안 없이 본다. 하지만 정보 비대칭이 생길 수 있다.
- 자녀는 "표시 없음"을 "안 함"인지 "안 알림"인지 구별 못 한다. 며칠째 빈 화면이면 앱 고장·연결 끊김·어르신 건강 이상을 구별할 수 없다. 좋은 소식만 보이면 **안부 확인 서비스로 오해**하기 쉽다.
- 제안: (1) 빈 상태 문구를 "엄마가 하면 여기에 보여요"처럼 중립으로, "안 했어요"는 쓰지 않음. (2) 약관·앱 설명·온보딩에 "이 앱은 안부·안전 확인 서비스가 아니며, 보이지 않는다고 문제가 있다는 뜻이 아닙니다" 고지. (3) 어르신 동의 화면에 "하지 않은 날은 자녀에게 보이지 않아요"를 넣으면 오히려 부담을 덜어 동의율에도 이롭다(가정). (4) 연결 끊김은 못 한 날과 별개로 자녀에게 알림(안전·연결 문제는 숨기지 않음).
- 의료 표현 연결: 활동 감소를 인지 상태 신호로 해석하는 리포트 문구는 금지.

## 내가 틀릴 수 있는 이유
1. anonKey가 토스 측 가명 처리만 거친 값이라 우리 쪽에서는 사실상 개인정보가 아닐 수 있는데, 나는 보수적으로 취급했다(과잉 대응 가능).
2. 참여 여부까지 거부 시 숨기면 자녀 가치가 떨어져 전환·사업 목표와 충돌한다. 법적 필수가 아닐 수도 있다.
3. 어르신 대리 동의 우려는 실제 법 해석이 아니라 내 가정이다.
4. 토스 약관·콘솔이 방침 링크를 허용할 수도 있다(내가 확인한 건 "외부 이동 불가" 문장뿐).
5. 한국 법 조문 원문을 이번에도 읽지 않았다.

## 안건에 없지만 가장 중요한 질문
1. 어르신이 "자녀에게 무엇이 보이는지"를 앱 안 어디서든 다시 볼 수 있는가("내 화면 미리보기")?
2. 토스 트랙에서 삭제·철회를 트리거하는 이벤트는 무엇인가(연결 해제 콜백이 없을 때)?
3. 자녀가 어르신 폰에서 대신 가입·동의했을 때 어르신 본인 확인은 어떻게 하나?

## 사용자에게 묻고 싶은 것
1. 동의 거부(또는 철회)한 어르신의 "오늘 했는지"도 자녀에게 숨길까요, 아니면 보이게 하고 동의 문구에 적을까요?
2. 철회 때 이미 저장된 기록을 지울까요, 남길까요?
3. 방침을 앱 안 화면으로도 넣는 일정(토스 검수 대비)을 허용할까요?
4. 법률 전문가 확인 예산·시점은(anonKey 분류, 국외 이전, 대리 동의)?
