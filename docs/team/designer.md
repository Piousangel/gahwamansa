# 디자이너 산출물: "해님이 안내하는 우리 집 앨범"

작성 2026-11-16. 시안: scratchpad `bumo-design/project/M_Main · M_Photo · M_Question · M_ChildHome.dc.html` (게시 안 함).
가정: 화면 390x844 기준, 단위 px는 RN dp로 그대로 쓴다. 대비값은 WCAG 상대휘도 공식으로 직접 계산(소수 2자리). 시안 속 이름·숫자·답변은 예시이고 통계가 아니다.

## 1. 컨셉
어르신은 매일 아침 "우리 집 앨범"을 한 장 넘긴다. 종이색 바탕 위에 폴라로이드 사진이 놓여 있고, 해님이 말풍선으로 인사하고 칭찬하고 다음 할 일만 알려 준다. 연속 접속은 앨범 페이지에 해님 스티커를 한 장씩 붙이는 것으로 보여 준다. 모든 모양은 둥글다. 화면 하나에는 할 일 하나만 크게 둔다. 자녀 화면은 같은 앨범을 "어머니의 앨범"이라는 이름으로 더 촘촘하게 보여 주고 해님은 작은 스티커로만 남긴다. 효능 문구("치매 예방")는 어느 화면에도 쓰지 않는다.

## 3. 해님 사용 규칙
- 등장해도 되는 곳: 오늘의 코스 첫 인사, 사진 회상의 질문 말풍선, 밸런스 질문의 안내 한 줄, 완료 칭찬, 연속 도장 스티커, 오류·빈 상태의 위로 한 줄.
- 표정 3종(모두 기존 C 시안 SVG를 기본으로, 입 모양만 바꾼다): 기본 미소(인사·안내), 활짝(완료·칭찬: 입을 크게 벌린 반달), 걱정(오류·연결 실패: 눈썹을 내리고 입을 일자에 가깝게). 현재 시안에는 기본 미소만 그렸고 나머지 2종은 구현 때 추가한다.
- 금지 장소: 한글 따라 쓰기 획 영역, 사진 본체 위(사진을 가리지 않음), 동의·개인정보 화면, 버튼 안, 자녀 리포트 본문. 해님이 대신 말하는 문장에 책임·의학 판단을 넣지 않는다.
- 크기: 어르신 화면 56~92, 도장 44, 자녀 화면 30 이하. 한 화면에 큰 해님은 1개만.
- 말풍선 문장은 20자 안팎, 존댓말, 명령형 대신 권유("눌러 보세요").

## 4. 폴라로이드 규칙
- 사진 영역 위 14, 좌우 14, 아래 흰 여백에 손글씨 설명(최대 12자 한 줄). 흰 테두리는 #FFFFFF.
- 기울기 -3~+3도, 한 화면에 1~2장. 읽는 글자(질문·버튼)는 기울이지 않는다.
- 위쪽 테이프(92x28, tape색)로 붙인 느낌을 낸다. 사진 비율은 약 1:0.87, AI 사진 미준비 시 "[AI 옛날 사진 들어갈 자리]" 자리표시.
- 자녀 화면 축소판은 너비 84, 설명 20px 손글씨(자녀 화면은 예외로 허용).

## 5. 도장(스티커) 규칙
- 접속 완료한 날 = 해님 스티커 44px, 요일 글자 18px 아래, 날마다 -4~+4도 다른 각도로 붙인다(고정값, 렌더마다 바뀌지 않게 날짜 해시 사용).
- 아직 안 온 날 = 점선 원(#8C7A55 2px dashed) + 요일. 붙이기는 코스 완료 시 한 번 통통 커지는 모션(0.3초), 시스템 "동작 줄이기" 설정이면 모션 없이 바로 표시.
- 연속이 끊겨도 "끊겼어요" 문구 금지. 빈 칸은 점선으로만 두고 다음 칸을 안내("오늘 붙여 볼까요?").
- 제목 줄에 "N일 연속 해냈어요". 숫자는 서버의 연속일 값만 쓴다.

## 7. 어르신 화면 접근성 체크리스트
- [ ] 본문·버튼 글자 20px 이상 (시안 확인: 자녀 화면만 16 사용)
- [ ] 버튼·카드 터치 영역 64px 이상, 사이 간격 12 이상 (큰 버튼 72, 보조 64)
- [ ] 한 화면 주요 버튼 3개 이하 (시안: 2개)
- [ ] 글자 대비 4.5:1 이상 (표의 모든 글자 조합 충족, disabled만 미확인)
- [ ] 상태를 색+글자/아이콘으로 동시 표시
- [ ] 이모지·글자 체크 대신 SVG 아이콘, 장식 SVG는 aria-hidden
- [ ] 모든 단계에 "읽어 주세요"(TTS), 읽는 중 정지 가능
- [ ] OS 글자 크기 확대 150%에서 줄바꿈만 일어나고 잘리지 않음(실기기 미확인)
- [ ] 시스템 "동작 줄이기"일 때 스티커 모션 제거
- [ ] 한 번 잘못 눌러도 되돌릴 수 있음(선택은 다시 누르면 바뀜, 확정은 큰 버튼)
- [ ] 화면에 효능·의학 문구, 실패·끊김 같은 부정 표현 없음

### 8.3 터치 영역
어르신: 버튼·카드·코드 칸 64 이상(큰 버튼 72, 코드 칸 68), 사이 12 이상. 자녀: 48 이상(권장 56). 아이콘만 있는 버튼은 시각 크기보다 hitSlop으로 64까지 확대. 오른쪽 아래 한 손 영역에 주 버튼을 둔다.

### 8.4 글자 크기 스케일 (어르신 20 이상, 자녀 16 이상)
`display 36 / title 32 / titleSm 28 / bubble 24 / bodyLg 22 / body 20 / hand 32(손글씨 최소 30) / childTitle 30 / childBody 18 / childMin 16 / hangulGuide 120`. 14·12 같은 글자는 자리표시 라벨(시안 전용)에만 있고 실제 앱에서는 쓰지 않는다. 시스템 글자 확대는 allowFontScaling을 켜고 maxFontSizeMultiplier 1.3까지(이상은 레이아웃 미확인).

### 8.5 라벨 박스 자리표시 규칙
에셋 전 자리는 `<PlaceholderBox label="[해님 기본]" w h />`로 그린다: 2px dashed line, 배경 #EFE4CC, 글자 inkSub(대비 6.42) 굵게. 라벨 형식 `[에셋종류: 이름]`(예 `[아이콘: 스피커]`, `[해님: 걱정]`, `[테이프]`). 크기는 최종 에셋 크기와 같게 잡아 레이아웃이 에셋 교체 때 움직이지 않게 한다. 에셋이 들어오면 레지스트리(`app/src/ui/assets/`)에서 같은 키로 교체하고, 라벨 박스는 개발 빌드에서만 허용한다. 직접 그린 임시 SVG 금지.
