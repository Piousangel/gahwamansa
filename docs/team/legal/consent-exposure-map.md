# 동의 문구 ↔ 자녀 노출 1:1 대조표 + 금지어 grep (LG-06, L6, 2026-11-18)

> **법률 자문 아님.** 출시 게이트 G-18(release-gates)의 판정 문서. 기준: main(서버 0001~0045, `app/src/copy/copy.ko.json`). 기능 동결(W2) 뒤 한 번 더 돌린다.
> 방법: 부모님이 보는 동의·설정 문장마다 "그 문장이 약속하는 범위"를 적고, 자녀가 받는 **모든 경로**(RPC 반환값·푸시·이벤트)와 맞춘다. 판정: **일치** · **차이**(문장과 실제가 다름) · **고지 밖**(문장이 말하지 않는 노출).

## 3. 금지어 grep (출시 게이트 C-04, 11-18 실행 결과)
- 범위: `copy.ko.json` 전 키(_meta 제외) + `app/src` 소스.
- 패턴: `아직|못 ?했|미완료|\d+일째|틀렸|치매|두뇌|안부|안심|칭찬|잘하셨|예방|치료|효과|개선`.
- 결과(copy): **2건, 둘 다 허용 예외** — `child.settings.not_safety`·`app_info.not_medical`의 "안부나 안전을 확인하는 서비스가 **아니에요**"(부정 고지, 약관 제13조와 같은 뜻). 그 밖 0건.
- 결과(소스): 화면 문자열 0건. 주석 8건(예: `ConnectScreen.tsx:199` "안심 줄", `KeyboardStep.tsx:129` "칭찬") — 화면에 안 나옴.
- 푸시 광고성 낱말(0046·0048 예정, 서버 check 제약): `push_copy`(제목·본문·대체·여러 개)·`cheer_texts`에 혜택·할인·이벤트·무료·쿠폰·적립·포인트·경품·광고·"다시 오세요"가 있으면 거부(공백·폭 없는 공백 제거 뒤 검사). 방침 2절 "혜택·유료 안내 알림은 보내지 않습니다"의 서버 근거(단 "유료"는 서버 목록에 없음 — 앱 테스트로만). 위 앱 금지어 grep과 별개.
- 자동화 제안(release-gates §6-1과 같음): `copyBan.test.ts`에 `두뇌|안심|칭찬|잘하셨` 추가 + "안부"는 `아니에요`로 끝나는 고지 키 2개만 허용 목록.
