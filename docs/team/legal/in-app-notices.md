# 앱 안 법적 고지 위치 목록 (법률팀 → 디자인·앱·라이터, 2026-11-17)

> **법률 자문이 아닙니다.** 아래 위치·문구는 실무 권고안이며, 법적 충분성은 실제 법률 전문가 확인 대상입니다(questions-for-lawyer.md).
> 화면 코드는 시안 v3 기준(P=부모님, C=자녀, N=알림, S=공통). 문구는 **라이터 확정 전 초안**, 글자 크기·버튼 규칙은 디자인 시스템을 따릅니다. 근거 번호는 compliance-checklist.md의 #.

## 1. 첫 실행·가입 흐름
| 위치 | 고지 내용 | 형태 | 근거 | 빌드1 | 담당 |
|---|---|---|---|---|---|
| 첫 화면(역할 고르기) | 없음 유지. 시각 디자인 우선, 법적 고지는 다음 화면에서. TalkBack 라벨에 "AI가 만든 그림" 유지 | 라벨 | #13 | 필수(라벨) | 앱 |
| P1 번호 입력(부모님) 하단 | "번호를 넣으면 이용약관에 동의하고 개인정보처리방침을 확인한 것으로 봐요" + 링크 2개 [이용약관] [개인정보처리방침] | 본문 아래 한 줄 + 글자 링크(터치 64) | #19, #1 | 필수 | 디·라·앱 |
| C0 로그인(자녀) 하단 | "로그인하면 이용약관에 동의하고 개인정보처리방침을 확인한 것으로 봐요. 만 14세 이상이 쓰는 앱이에요(나이 확인 절차가 없으므로 '가입 제한'이 아니라 이용 대상 안내, 방침 7절·약관 제4조와 같은 뜻)" + 링크 2개 | 로그인 버튼 아래 한 줄 + 링크 | #19, #3 | 필수 | 디·라·앱 |

| N1 알림 권한 안내 | 이미 있음: "하루 한 번만 알려 드려요". **추가**: "안 받으셔도 앱은 그대로 써요" 한 줄(선택 권한 거부 가능 고지). 시스템 권한 창은 이 안내 뒤에만 띄움 | 기존 화면 | #9, #10 | 필수 | 라·앱 |

- 링크 열기: 외부 브라우저(또는 시스템 Custom Tab). 앱 안 WebView라면 상단 "‹ 이전" 바 유지. 오프라인이면 "인터넷이 연결되면 볼 수 있어요" 토스트.
- 체크박스("모두 동의")는 만들지 않는다: 계약 이행에 필요한 처리는 동의 대상이 아니고, 선택 동의(P2·N1)는 이미 따로 받는다(#2). 체크박스 방식이 필요하다는 법률 의견이 나오면 이 줄만 바꾼다.

## 3. 설정(P13 부모님 · C7 자녀) "앱 정보" 묶음 — 한 목록 순서 제안
1. 이용약관 → 웹 약관 URL
2. 개인정보처리방침 → 웹 방침 URL
3. 오픈소스 라이선스 → 앱 안 목록 화면(빌드 때 자동 생성, #20)
4. AI 안내: "앱의 옛날 사진은 AI가 만든 그림이에요. 실제 장소가 아니에요" / "배경 음악은 AI(Google Lyria)가 만든 연주곡이에요"(부모님만) — 확정 문구 copy-v3 316~318행
5. "병원 앱이 아니고, 안부나 안전을 확인하는 서비스가 아니에요" — C7에는 이미 있음, P13에도 한 줄(약관 제13조)
6. 사업자 정보: 상호 행복가게 · 대표 ○○○ · 사업자등록번호 ○○○ · 주소 ○○○ (접힘 가능, 탭하면 펼침) — #21
7. 문의하기: 메일(메일 앱 열기) [·카카오톡 채널]
8. 앱 버전
- 같은 화면의 다른 묶음: 알림 켜기/끄기(#10), 배경 음악 켜기/끄기, 답 보여 주기 그만두기(P13), 모두 지우기(P9)·계정 지우기(C8).
- 사업자 정보 값은 방침·약관·삭제 안내·Play 개발자 정보와 **글자 하나까지 같게**. 값은 한 곳(설정 상수 파일)에서 관리.

## 5. 빌드 2(유료화) 때 추가할 자리 — 지금은 만들지 않음
- 결제 화면: 가격·결제 주기·무료 체험 기간과 **유료로 바뀌는 날짜**·자동 결제·해지 방법(설정 → 구독 → Play 구독 관리)·청약철회 기준, 유료 서비스 약관 링크. 결제 버튼 문구에 "체험 후 매월 ○원"
- 체험 종료 전 알림(기간은 법령 확인), 가격 인상 전 알림
- 광고성 알림 동의(별도 토글, 기본 꺼짐) — 켜면 처리 결과 안내, 2년마다 재확인
- 설정 사업자 정보에 통신판매업 신고번호
