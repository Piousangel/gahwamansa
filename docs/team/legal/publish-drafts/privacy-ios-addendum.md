# 방침·삭제 안내 iOS 부록 초안 (빌드 2 iOS 출시 때 합침, L6, 2026-11-19)

> **법률 자문 아님.** iOS 준비도 감사 N4(`docs/team/qa/2026-11-19-ios-readiness-audit.md`)를 처리한다. 빌드 2의 iOS에서 쓸 예정인 Apple 로그인(Sign in with Apple, 이메일 가리기 전달 주소 포함)과 APNs(Apple 푸시 알림 서비스)를 방침에 넣을 문장을 미리 만들어 둔다.
> 표기: **사실** = 코드·결정·공식 문서로 확인 · **추정** = 확인 전 · **제안** = 팀 제안, 결정 필요. 확정 못 한 값은 `{…}`로 둔다.

### 1-1. 2절 자녀 표 새 행 (범위 결정됨, B2 구현 전)
```html
<tr><td>Apple로 로그인(아이폰)</td><td>Apple 계정 고유 번호(이 앱에서만 쓰는 번호), 이메일 주소. Apple의 "이메일 가리기"를 고르시면 Apple이 만든 전달용 주소만 받습니다. 이름은 받지 않습니다</td><td>로그인, 내 계정 구분</td><td>서비스 제공</td></tr>
```
- **결정(리드 위임, 11-19)**: Apple 로그인 범위는 **이메일만** 요청(이름 요청 안 함) — 최소 수집, 앱 화면에 이름을 쓰지 않는다(0047 display_name 제거와 같은 방향).
- 이메일 가리기 주소는 이용자별·앱별로 다르게 만들어진다(추정. 근거: Apple 지원 문서 "Sign in with Apple"(https://support.apple.com/en-us/102609, 11-19 조회)이 이메일 가리기를 "Apple's private email relay service … create and share a unique, random email address that forwards to your personal email"로 설명. 이메일 가리기 전용 문서는 따로 있으며 입력 전 대조). 운영자가 이 주소로 메일을 보내려면 Apple 개발자 계정에 보내는 도메인을 등록해야 한다(추정) — 지금은 로그인 후 메일을 보내지 않으므로 해당 없음.
- Apple 로그인 토큰은 로그인 때 저장하지 않는다(§1-2 설계). 그래서 이 행에는 토큰을 적지 않고, 4절(§1-2)에만 적는다.

### 1-2. Apple 연결 해제 설계와 4절 보관 새 행 (설계·기간 결정됨, B2 구현 전)
**설계(리드 결정, 최소 보관, 11-19)** — refresh token을 로그인 때 저장하지 않는다.
1. 계정 지우기를 누르면 앱이 Apple 확인(재인증)을 한 번 더 띄워 새 authorization code를 받는다.
2. 서버가 그 code를 곧바로 Apple 토큰으로 바꾸고, 그 자리에서 해제(revoke)를 요청한 뒤 토큰을 버린다. 저장하지 않는다.
3. Apple 쪽 오류로 해제가 실패하면 받은 토큰만 재시도 큐에 넣는다. 성공하면 바로 지우고, 늦어도 **30일**(카카오 큐와 같은 상한) 뒤 지운다. 계정 삭제는 해제 결과와 상관없이 그대로 진행한다.
4. 재인증을 취소했거나 실패했으면(code를 못 받음) 아래 안내를 띄운다. code는 몇 분 안에 만료되므로(추정, Apple 문서 재확인) 재시도 큐에 둘 수 없다.
- 큐: 감사 문서 선택안대로 `kakao_unlink_queue`를 제공자 열이 있는 일반 큐로 바꾸면 30일 파기·포기 행 처리(내부관리계획 §4-5·§7)를 같이 쓴다. B2 병합 때 서버 코드와 대조.

```html
<tr><td>Apple 로그인 연결 해제용 토큰(Apple로 가입한 분)</td><td>평소에는 저장하지 않습니다. 계정을 지우실 때 Apple 확인을 한 번 더 받아 그 자리에서 Apple에 연결 해제를 요청하고 버립니다. Apple 쪽 문제로 바로 해제되지 않으면 다시 요청하는 데만 두고, 해제되면 바로, 늦어도 <strong>30일 안에</strong> 지웁니다</td></tr>
```

**재인증 실패 때 앱 안내 초안(제안 — 문구는 라이터, 버튼 구성은 리드·디자인 결정)**
```
제목: Apple 확인을 마치지 못했어요
본문: Apple로 가입한 계정은 지울 때 Apple 확인을 한 번 더 받아요. 확인이 끝나야 Apple과의 연결도 함께 끊을 수 있어요.
버튼 1: 다시 확인하기
버튼 2: 확인 없이 계정 지우기
버튼 2를 누르면: 계정은 지금 지워요. Apple과의 연결은 아이폰 설정 → (이름) → {Apple로 로그인 메뉴 경로} → 가화만사성에서 직접 끊어 주세요.
```
- 버튼 2를 두는 이유: Apple 확인이 안 된다고 계정 삭제를 막으면 앱 안 삭제 요건(App Review 5.1.1(v))과 방침 10절(언제든 지우기)에 어긋날 수 있다(추정).

## 3. 합치기 전 조건
1. B2 구현 병합: Apple 로그인(이메일만), 삭제 때 재인증 → 즉시 교환·해제·버림, 실패 시 재시도 큐 30일, 재인증 실패 안내, iOS 백업 제외 여부, FCM→APNs 발송.
2. 공식 상담 A-1~A-3 회신(또는 "미회신·잠정 유지" 기록).
3. `{…}` 0건, App Store 라벨(`../app-privacy-label.md`)·앱 Privacy Manifest(`NSPrivacyCollectedDataTypes`)와 단어 대조.
4. 방침·약관 버전 등록과 앱 상수 배포를 같은 날(내부관리계획 §6 약관·방침 게시 절차).
