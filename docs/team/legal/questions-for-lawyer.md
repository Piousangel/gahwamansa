## P1 — 빌드 1(Play 비공개 테스트) 전에 답이 필요
1. **하루 한 번 알림이 광고성 정보인가.** "오늘의 사진이 왔어요 / {사진 설명}"을 N1에서 "알려 주세요"를 누른 사람에게만 보낸다. 지금은 무료지만 유료 구독 예정 서비스다. 정보통신망법 제50조의 영리목적 광고성 정보에 해당하는가, 해당한다면 N1 동의를 광고 수신 동의로 갈음할 수 있는가(KISA 안내서상 알림 권한≠광고 동의). 잠정: 정보성, 단 08~21시 발송·홍보 문구 금지로 위험 축소.
2. **부모님 답을 자녀에게 보여 주는 것의 법적 성격.** 제17조 제3자 제공 동의인가, 서비스 본질 기능(계약 이행, 제15조①4호)인가. 고령 이용자(인지 저하 가능)의 동의 유효성, 자녀가 옆에서 대신 누르는 경우. 동의 문구 v1→v2(범위 축소)를 재동의 없이 고지로 처리해도 되는가.
3. **국외 이전 고지 방식.** Supabase(계약 주체 싱가포르 법인, 데이터는 서울, 로그는 EU, 지원 인력 해외 접근), Firebase FCM·Crashlytics(미국). 제28조의8①3호(방침 공개로 갈음)로 충분한가, 별도 동의가 필요한 부분이 있는가. 카카오·구글 로그인을 위탁도 제3자 제공도 아닌 것으로 분류한 판단.
4. **약관 성립 방식.** 체크박스 없이 "번호를 넣으면/로그인하면 동의한 것으로 봐요" + 링크 고지로 약관이 성립하는가(약관규제법 제3조). 이름·연락처가 없는 익명 부모님에게 약관 변경을 "개별 통지"하는 방법(앱 안 배너)이 인정되는가.
5. **책임 제한·관할 조항**(terms-v1 제16·18조)이 약관규제법 제6·7·14조에 비춰 무효 위험이 있는가. "안부·안전 확인 서비스가 아님" 고지로 부모님 위급 상황 관련 분쟁을 충분히 막는가.
6. **연령 기준.** 자녀 계정 "만 14세 이상"(방침·약관)과 Play 대상 연령 "18세 이상" 선택이 충돌하는가. 연령 확인을 고지 한 줄로 해도 되는가.
7. **열람·삭제 처리 기한과 본인 확인.** 10일(시행령 제41·43조, 2차 확인) 기산점, 이름·연락처가 없는 익명 부모님의 웹 삭제 요청 본인 확인 방법(v2.1 원칙: 부모님 본인 요청 1순위, 자녀 대리는 부모님 뜻 확인 시만 — 이 확인 수준이 충분한가).
8. **안전성 확보조치 고시 적용 범위.** 정보주체 1만 명 미만 소규모 사업자의 완화 범위, 관리자 접속기록 1년 보관 의무가 우리(Supabase Studio 접근)에 적용되는가, 내부관리계획 문서가 필요한가.
9. **보존 의무 없음 단정.** 무료 단계에서 "법 때문에 따로 남기는 정보 없음"이 맞는가(통신비밀보호법 로그 3개월, 부가통신사업 신고 대상 여부 포함).
10. **보호책임자.** 개인사업자 1인 운영 시 대표자 지정·공개 연락처로 충분한가(개인 휴대전화 공개 의무 여부).

## P2 — 공개 출시·토스 착수 전
11. **AI 기본법 제31조 의무 주체 여부.** 미리 생성한 사진·음악을 콘텐츠로 배포하는 우리가 "인공지능사업자"인가 "이용자"인가. 첫 화면 소개 이미지의 AI 표시 제거가 괜찮은가. 실사풍 옛날 사진이 "실제와 구분하기 어려운" 결과물인가. v2 가족사진 복원을 넣으면 무엇이 바뀌는가.
12. **AI 생성 사진·Lyria 음원의 권리.** 저작권 보호를 못 받을 때 경쟁 앱의 복제에 약관(제9조)·부정경쟁방지법으로 대응 가능한가. 기존 저작물과 우연히 비슷한 결과가 나왔을 때 책임 구조(Gemini API 추가 약관상 면책 여부). Gemini·Lyria 출력의 상업 이용 조건 해석.
13. **상표 "가화만사성"**(변리사). 관용 사자성어의 식별력, 9·41·42·45류 선등록 충돌, 동명 드라마와의 부정경쟁 위험. 사용자가 KIPRIS 검색 결과를 먼저 가져간다.
14. **토스 미니앱.** 토스 `anonKey`의 개인정보 해당 여부(DECISIONS 11-17 "토스 착수 전 확인"), 토스 로그인으로 받는 정보의 제3자 제공 수령 고지, 토스 약관과 우리 약관의 관계.
15. **장애인차별금지법** 모바일 앱 접근성 의무가 개인사업자 소규모 앱에 지금 적용되는가(시행령 단계적 적용 일정).

## P3 — 빌드 2(유료 구독) 전
16. **구독·무료 체험.** 7일 무료 체험 → 월 구독 전환 시 전자상거래법상 사전 동의·고지 기간과 방법(2025-02-14 시행 다크패턴 규정, 시행령 확정 기간), Google Play 결제 시스템을 쓸 때 고지 책임 분담.
17. **청약철회.** 디지털콘텐츠 구독의 청약철회 제한(제17조②) 고지 방법, 일부 사용 후 환불 기준, Play 환불 정책과의 관계.
18. **"선물 요금"**(형제·친지가 대신 결제): 결제자와 이용자가 다를 때 청약철회 주체, 개인정보(결제자 정보) 처리.
19. **통신판매업 신고**: 앱 내 결제만 있을 때 신고 시점과 면제 기준, 사업자 정보 표시 위치(설정·스토어).
20. **거래기록 보존**(5년 등)과 "계정 지우면 바로 삭제" 정책의 조정, 방침 개정 범위.
