# 법률 회신 반영 틀 (LG-10 + LG-04 전체, L6, 2026-11-18)

> **법률 자문 아님.** 외부 회신(KISA 118·변호사·변리사)을 받아 **어느 문서·화면·코드가 바뀌는지**를 미리 매핑한 틀. 회신이 오면 아래 절차대로 채운다. 질문 번호는 `../lawyer-packet.md`.
> 회신 원문 요지는 이 폴더에 `<YYYY-MM-DD>-<기관>.md`로(양식 §3). 상담원·변호사 개인 이름, 사용자 개인정보는 적지 않는다.

## 1. 절차
1. 사용자가 회신 요지 전달 → L6가 §3 양식으로 파일 생성.
2. 질문별 판정: **확정**(잠정 판단과 같음) / **변경**(바꿔야 함) / **불명**(추가 질문 필요) / **미회신**.
3. "변경"이면 §2의 영향 칸을 보고 레인별 작업을 리드에게 "결정 필요"로 올림(DECISIONS는 리드).
4. 관문 기록: G-CLOSED 전 필수(1~12) 미회신은 release-gates C-05에, G-PUB 전(13~19)은 P-06에 "미회신·잠정 판단 유지" 사유로 적음.
