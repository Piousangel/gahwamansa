# 시설 선생님용 안내지 — 지금 흐름판 (2026-11-25 확정)

작성: 가화 · M-LEAD(마케팅 리드) + WR-1(라이터), 한 레인. 문서만 바꿨다. 인쇄 주문·시설 연락·외부 게시는 하지 않았다.
근거: DECISIONS 2026-11-25 '부모님 먼저 시작 → 부모 번호 → 자녀 입력 연결'·'오늘 코스 3단계 → 5단계', `board/2026-11-25-parent-first-link.md` §5.1·§6.1, `marketing/guardrails.md`, `writer.md` 1절.
인쇄본: `2026-11-25-facility-handout.html`(A4 한 장, 외부 스크립트·글꼴 없음). 글은 이 문서 1절과 한 글자도 다르지 않게 둔다.

## 0. 이 판이 정한 것
- **쓰는 곳**: 요양원·실버타운 선생님이 어르신 휴대폰에 앱 설치를 도울 때 옆에 두는 A4 한 장.
- **흐름**: 지금 빌드 그대로다. 어르신 휴대폰에 먼저 설치하고 '코스 보기'로 써 보시다가, 가족이 만든 번호 6자리를 나중에 쓰면 연결된다. 역방향 번호(부모님 휴대폰에서 만드는 번호)는 1.1이라 쓰지 않았다.
- **어르신 본인이 누르는 것**: '이 번호로 연결하기'(약관 동의가 같이 일어남)와 '고른 답을 가족과 나눠요' 화면의 '좋아요'·'싫어요'. 선생님은 설치와 번호 입력까지만 돕는다(§5.1 경계표).
- **단계 수를 말하지 않는다.** 코스가 3단계 → 5단계(12/13 목표)로 바뀌어도 고칠 곳이 없게 '사진 한 장을 보고, 둘 중 한쪽을 고르는 앱'까지만 쓴다(11-26 대기열 64: 기획 v2.1 Q1 판단어를 빼고 하는 일만).
- **§6.1 초안에서 바꾼 것**
  - '번호가 없어요 → 코스 보기'를 '번호 칸 아래 [코스 보기]'로 고쳤다. 지금 P1 화면에서 두 글자 링크는 나란히 있고, '번호가 없어요'는 도움 줄만 연다(`ConnectScreen.tsx` links).
  - 가족 쪽 단계에 [번호 만들기]를 넣었다. 로그인만으로는 번호가 나오지 않는다(호칭 고르기 → 번호 만들기).
  - '지금은 안드로이드 휴대폰만 돼요'를 넣었다(`code.android_only`와 같은 사실). 시설에서 아이폰에 설치하다 막히는 일을 먼저 막는다.
  - 연결 전에 코스 홈 띠의 [번호 쓰기]로 번호 화면에 다시 갈 수 있다는 줄을 넣었다.
  - '꼭 지켜 주세요' 머리말을 '부탁드려요'로 바꿨다. '지켜'가 감시 낱말(지켜보기)과 겹쳐 읽히지 않게 했다.
  - '사진에서 고르는 것은 어르신이 직접 하세요'는 '…하세요'(시키는 말)라 '어르신이 직접 고르시는 거예요'로 바꿨다.
  - 번호와 어르신 성함을 같이 적어 두지 않는다는 줄을 넣었다(§5.4 3번: 이름 + 번호 명단 금지).

· 선생님 휴대폰에서 번호를 만들어 연결하지 말아 주세요. 고르신 답은 연결된 가족만 봐요.

- **검사 목록**

## 5. 확인하지 못한 것
- 어르신 검증 0회, 선생님 검증 0회. 첫 시설 1곳에서 이 판을 써 보고 막힌 줄을 적는다(board §9).
- A4 한 장은 Chrome 헤드리스 PDF 인쇄(`@page` A4, 여백 11·14·10mm, 본문 14.5pt)로 1쪽을 맞췄다. 실제 프린터 출력은 하지 않았다. 프린터가 여백을 더 잡으면 마지막 '문의' 줄이 넘어갈 수 있다.
- '광고 없음'은 출시 AAB 병합 매니페스트 확인 전이다(2절).
- 선생님이 번호 6자리를 대신 써 드리는 것까지는 된다고 보았다(board §5.1 '설치 도움'). 판단 능력이 떨어진 어르신의 동의 효력은 법률 L-9 상담 전이다.
