# 마케팅 가드레일 — 게시 전 이 표로 한 번 확인
원칙: 목표는 **대화를 늘리는 것**이지 감시가 아니다(board/DECISION-MEMO). 법 해석은 검색 요약 기준이며 전문가 확인 전이다.

## 1. 금지 표현
| 분류 | 쓰지 않는 말 | 대신 |
|---|---|---|
| 의료·효능 | 치매 예방·치료, 뇌 건강, 인지 기능, 기억력 향상·개선, 두뇌 훈련, "의사가 추천" | 옛날 사진 보기, 기억 떠올리기, 이야기할 거리 |
| 효도 압박 | 효도, 불효, "아직도 전화 안 드려요?", "후회하기 전에", "부모님은 기다리지 않습니다" | "할 말이 없을 때 시작하기 좋아요" |
| 감시·안부 오해 | 안부 확인, 오늘 했는지 확인, 실시간, 지켜보기, 위치, 안심 서비스, "N일째 소식 없음", 연속 며칠 | "엄마가 고른 답이 보여요", "그 답으로 말을 걸어요" |
| 어르신 비하·아이 취급 | 노인, 치매 걸리기 전에, 깜빡깜빡, 잘하셨어요·참 잘했어요, 숙제, 우리 엄마 귀여워, 하트·볼터치 강조 | 부모님, 어머니·아버지, 담백한 사실 문장 |
| 과장·약속 | 무조건, 평생 전부 무료, 1위, 효과 보장, 가격 확정 전 금액 | "부모님은 계속 무료예요. 자녀 기능 일부는 나중에 유료가 될 수 있어요" |

- 해님은 "말동무" 톤. 칭찬·하트 금지, 앱 아이콘·도장 상징으로만(gemini/DECISION-MEMO).

## 2. 사진·AI 이미지
- 실제 사람·실제 가족 사진 금지(사용자 본인 가족 포함). 얼굴 나온 스톡 사진도 쓰지 않는다.
- 소재는 세 가지뿐: **앱 화면(예시 데이터)**, **AI로 만든 그림**(content/photos, 사람 없음), **문구 카드**.
- AI 그림이 보이는 모든 이미지·영상 첫 장면에 **"AI로 만든 그림"**을 그림 위 구석(최소 글자 크기 피드 기준 24px [가정])과 캡션 첫 줄에 함께 쓴다. 앱 안 표기 "AI가 만든 그림"과 같은 뜻으로 본다.
- AI로 가상의 어르신·가족 얼굴을 만들지 않는다. 가상 인물이 추천하는 광고는 표시 의무 대상(공정위 추천·보증 심사지침 2026-06-01 적용, 출처 아래).
- 생성물 출처 표시(워터마크·SynthID)를 지우거나 잘라내는 가공 금지(DECISIONS 11-17).

## 3. 토스 안과 밖
- **토스 미니앱 안**(화면·카톡 공유 문구 포함): Play 앱 설치·외부 사이트 이동 유도 금지(docs/plans/03). 공유 문구는 "앱을 열고 번호 6개를 써 주세요"까지만.
- **외부 SNS(인스타·블로그 등)**: 우리 계정에서 Play 링크와 "토스에서도 만나요"를 함께 안내하는 것은 가능 [가정, 토스 운영 정책 원문 재확인 필요].

## 4. 개인정보·후기
- 실제 가족의 답·사연·후기 인용은 **서면(카톡 메시지 가능) 동의** 후. 동의 범위: 문구, 이름 표기 방식(기본 익명), 게시 채널, 삭제 요청 시 즉시 내림.
- 앱 화면 녹화는 테스트 계정의 예시 데이터만. 실제 가족 코드·호칭·날짜가 보이면 쓰지 않는다.
- 테스터 Gmail·연락처는 마케팅에 쓰지 않는다.

## 5. 광고 표시 의무
- 협찬·체험단·제품 무료 제공·이용권 제공 등 경제적 이해관계가 있으면 게시물 **첫머리(제목·첫 줄·영상 시작 화면)**에 "광고", "협찬(무료 이용권 제공)"처럼 한국어로 명확히. "sponsored·thanks to·partner"만 쓰는 것은 불충분으로 보도됨.
- 테스터에게 후기를 부탁할 때 대가가 있으면 같은 표시를 요청한다. 대가 없는 부탁이면 "부탁받아 쓴 글"이라고 쓰도록 권한다 [가정].
