# 매주 운영 (월요일 30분, 주 10시간 안에서)
## 볼 숫자 (지난주 대비)
- 설치 → 자녀 가입 → 부모 연결 → 첫 리포트 본 자녀(strategy.md 6장). 채널별 연결 가족 수(utm).

- 게시물별 저장·공유 수(좋아요는 참고만).

## 주간 회고 질문 5개
1. 이번 주 **연결된 가족**은 어느 채널에서 왔나? 0명인 채널에 쓴 시간은 몇 시간인가?
2. 퍼널에서 가장 많이 빠진 단계는 어디이고, 그건 콘텐츠 문제인가 설치 안내 문제인가?
3. 저장·공유가 가장 많았던 게시물의 기둥은 무엇인가? 다음 주에 같은 기둥을 2배로 할까?
4. 감시·효도·효능으로 읽힐 수 있는 댓글이나 문의가 있었나? 있었다면 어느 문장이 그렇게 읽혔나?
5. 다음 주에 **멈출 것 1개, 늘릴 것 1개, 처음 해 볼 것 1개**는?
