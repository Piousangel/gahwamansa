# 매주 운영 (월요일 30분, 주 6~7시간 상한 안에서)
## 볼 숫자 (지난주 대비, 이름은 strategy.md 7장)
- 설치 → 자녀 가입 가족 → 연결 가족 → 첫 답 생긴 가족 → 연결 후 첫 답을 본 자녀(이벤트 생기기 전엔 대리값).
- 출처별 가입 가족(명단 시트·문의 "어디서 보셨어요?"), 카톡 문의에서 가장 많은 막힘 1개, 게시물별 저장·공유.

## 주간 회고 질문 5개
1. 이번 주 **연결된 가족**은 어디서 왔나? 지인 1:1과 콘텐츠의 비율은?
2. 퍼널에서 가장 많이 빠진 단계는 어디이고, 콘텐츠 문제인가 설치 안내 문제인가?
3. 저장·공유가 가장 많았던 게시물의 기둥은? 다음 주에 같은 기둥을 한 번 더 할까?
4. 감시·효도·효능으로 읽힌 댓글·문의가 있었나? 어느 문장 때문인가? [대조] 안 된 사실 주장을 올린 적은 없나?
5. 다음 주 **멈출 것 1개, 늘릴 것 1개, 처음 해 볼 것 1개**는? 시간은 7시간 안인가?

- **3주차부터 적용**(첫 2주는 표본이 작아 0이 흔함): 2주 연속 연결 가족 0인 채널은 빈도 절반, 4주 연속이면 중단.
