# PM 계획: 부모와 자식 (2026-11-17 갱신, 확정 계획 반영)

기준: 데이터로 검증, 작게 출시해 빠르게 개선, 한 번에 한 문제. 모든 시간·날짜는 추정(실측 아님).
확정 전제(리드 전달): 시나리오 A(12명·14일 적용 가정, 계정 생성일이 2023-11-13 이후로 보임), "11월 말 전후 비공개 테스트 시작, 12월 중순 공개". 목표: DAU 최소 30 / 기본 60 / 도전 100, 전환 5% / 10~12% / 20%. 사업 방향은 오가닉 공유 루프(형제 초대 범위 미정, 빌드 1 제외).
외부 근거: Google 도움말은 2023-11-13 이후 개인 계정에 "12명 이상, 14일 연속 옵트인 비공개 테스트 후 프로덕션 신청"을 안내하고 검토는 보통 7일 이내라 한다. https://support.google.com/googleplay/android-developer/answer/14151465 (검색 요약으로 확인, 우리 계정 적용 여부는 신청 화면에서 최종 확인 필요). 조직 계정의 D-U-N-S는 최대 30일 걸린다는 2차 출처가 있어 계정 전환은 대안이 아니다.

## 1. 일정 판단

- 빌드 1 합계 71.5h(계획 문서). 서버 4단계(가족 생성·코드 발급)·5단계(코드 사용·재연결·동의)는 구현됨, 검증 중. 1~3단계(13.5h) 완료 여부는 이 문서에서 확인하지 못함(가정: 완료). 가정이 맞으면 남은 약 46h, 아니면 약 59.5h.
- 하루 6h로 환산하면 완료일은 11/25~11/28. 사용자가 본인 확인·테스터 모집을 병행하면 하루 6h가 깎이므로 11/29는 여유가 거의 없는 목표다.
- 공개일: 옵트인이 11/29~12/1에 시작하면 14일 충족은 12/13~12/15, 신청 후 심사 7일 이내(미확인 변동)라 **12/20 안팎이 현실 기준, 12/15는 낙관**이다. "12월 중순 공개"는 시계가 11/29에 시작하고 심사가 빠를 때만 맞는다.
- 시계 시작은 첫 비공개 릴리스가 Play 검토를 통과해 테스터가 설치할 수 있어야 가능하다. 이 검토 시간은 미확인이라 업로드 목표를 11/27로 당긴다. 시작이 하루 늦으면 공개도 하루 늦는다.
- 12월 DAU: 공개가 12/20 안팎이면 12월 중 공개 사용자 확보는 약 10일뿐이다. DAU 30(최소)도 테스터 풀 가구 활성에 의존한다. **제안**: 12월 기준은 "12/25~12/31 7일 평균 DAU"로 정의하고, 달성 판정은 1월 첫 주에 한다(판정 시점 결정은 사용자).

## 4. 병목과 대안

1. **Play 본인 확인 지연**(최대 병목). 대안 없음(조직 계정은 더 느림). 완화: 개발·USB 실기기 검증은 병행, 확인 지연 시 앱 생성만 늦춰짐. 지연 1일 = 공개 1일.
2. **1인 개발 시간**: 단계 6(14h)과 11(12h)이 가장 큼. 컷 순서(11/27까지 3일 이상 밀릴 때): ① 앱 내 계정 삭제를 빌드 2로(공개 전까지만 필요한지 Play 요건은 미확인, 정책 담당 확인 후 결정) ② 자녀 홈 연속일 표시 ③ "곧 유료" 배지. 연결·코스·동의·RLS는 컷 금지.
3. **테스터 12명 유지**: 14일 전 탈퇴하면 시계가 다시 시작될 수 있다고 TODO에 있음. 20명 확보, 옵트인 수락 매일 확인. 대안: 12/6에 2차 모집(옵트인이 늦으면 14일도 늦어짐에 주의).
4. **카카오 로그인 배포 환경 차이**: Play 앱 서명을 쓰면 스토어 설치본의 서명 인증서가 다를 가능성이 높아 키 해시 추가 등록이 필요할 수 있음(미확인). 테스터가 로그인 못 하면 14일이 낭비됨. 대안: 앱 생성 직후 Play 콘솔의 앱 서명 인증서 정보로 카카오에 해시 추가, 업로드 전 내부 테스트(14일에 불포함)로 확인.
5. **어르신 첫 연결 이탈**: 서버 구현은 있으나 실사용 검증이 3가구뿐. 퍼널 이벤트로 한 문제만 집중 개선.

## 6. 지표 정의

- **DAU(활성 어르신)**: 해당 일(KST)에 코스 3단계를 모두 완료한 서로 다른 어르신 수. 보조로 시작 DAU(1단계 이상)와 완료율. 테스트·개발자 계정, 재설치로 늘어난 중복(family_id 기준)은 제외.
- **주간 활성 어르신**: 최근 7일 중 3일 이상 완료.
- **연결률**: 코드 발급 자녀 중 7일 안에 어르신 연결한 비율(최대 병목 예상).
- **전환율**: 분자 유료 가입 자녀 / 분모 부모와 연결되어 첫 리포트를 본 자녀(유료 전환 후 측정). 목표는 5% / 10~12% / 20%.
- **무료 기간 선행 지표**: 상세 리포트 열람 비율, 주 2회 이상 리포트 재방문 비율, "곧 유료" 탭 수·비율, 응원 발송률, 어르신 7일 유지율. 목표치는 데이터가 쌓인 뒤 설정.
- **오가닉 루프 지표**: 초대 링크 공유율, 링크당 신규 자녀, 형제 초대 이벤트(`sibling_invite_*` 이름만 예약, 범위 미정이라 구현 제외).
- 이벤트: `child_signup`, `invite_code_created`, `invite_link_shared`, `parent_code_entered`, `code_error(reason)`, `parent_connected`, `consent_agreed/declined`, `course_started`, `step_completed(step)`, `course_completed`, `tts_played`, `push_permission_result`, `push_opened`, `child_home_viewed`, `report_viewed(type)`, `coming_soon_tapped(feature)`, `cheer_sent`, `account_deleted`. 답변 내용은 로그에 넣지 않음.

## 7. MVP 범위(요약)

- 필수(빌드 1): 카카오 자녀 가입, 코드 연결, 동의, 코스 3단계+TTS, 연속일, 자녀 홈, 콘텐츠 14일분, 방침 페이지, 앱 내 삭제, RLS 테스트.
