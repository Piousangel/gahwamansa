## 2. 앱 안 외부 결제 정책

### Google Play (한국)
- 기본 원칙(확인): 구독·앱 내 기능 결제는 Play 결제 사용 의무. 예외 외에는 다른 결제 수단으로 유도 금지. 대체 결제·외부 링크는 해당 국가 프로그램에 등록한 경우에만 허용. 출처: https://support.google.com/googleplay/android-developer/answer/9858738
- 한국 사용자 선택 결제(확인): Play Console 수익 창출 설정에서 대체 결제 온보딩, PCI DSS 인증, 대체 결제 API 연동, 거래 24시간 안 보고, 청구서로 수수료 납부. 구글 결제만 쓰는 앱은 기존 수수료 유지. 대체 결제 시 당시 수수료에서 4%p 인하. 출처: https://support.google.com/googleplay/android-developer/answer/11222040
- 개편 예고(부분 확인): 구글 공식 한국어 블로그는 연 첫 100만 달러까지 서비스 수수료 10% 시작 요율, 국내 Play 결제 사용 시 결제 수수료 5% 추가, 대체 결제·외부 링크는 결제 수수료 없음, 구독 자동 갱신에도 10% 적용, 외부 링크는 자녀 보호 기능·PCI-DSS 조건이라고 밝힘. 그러나 **한국 시행일, 전체 요율표, 신청 절차는 이 글에서 확인 못 함**. 언론은 12월 말 적용이라고 보도했으나 공식 확인 아님(미확인). 출처: https://blog.google/intl/ko-kr/products/android-play-hardware/play-developer-update-2026-kr/
- 토스·네이버·카카오 사용 가능 여부: 정책상 "대체 결제 프로그램 등록 후" 가능한 구조로 보이나, 특정 PG 지정 가능 여부·PG 사 요건은 미확인. 요약: **등록 없이 앱에서 외부 결제로 유도하면 정책 위반(확인)**.
- 부모는 결제하지 않고 자녀만 결제하므로 "자녀 보호 기능" 조건의 적용 해석은 미확인.
- 실행안: 유료 전환 시점에 (a) Play 결제(구글 결제 수수료 포함, 가장 단순), (b) 대체 결제 등록 후 토스 등 병행 중 택일. 무료 기간에는 결제 문구·외부 링크를 앱 안에 두지 않음. 이는 심사 위험을 줄임.

### Apple (한국)
- 확인: 한국 전용 StoreKit External Purchase Entitlement. 한국 스토어에만 배포하는 별도 바이너리 필요, 같은 앱에서 Apple IAP와 병행 불가, 사전 승인 PSP는 KCP·이니시스·토스·NICE, 수수료는 결제 금액의 26%, 월간 보고·납부, 환불·구독관리는 개발자 책임. 출처: https://developer.apple.com/support/storekit-external-entitlement-kr/
- 네이버·카카오 결제는 사전 승인 목록에 없음(해당 페이지 기준, 신규 PSP 승인 절차는 미확인).
- 글로벌 앱은 Apple IAP가 기본이므로, iOS 출시 시점(Android 이후)에 별도 결정. 지금은 하지 않음.
- 해당 페이지가 현행인지(2026-11 기준 개정 여부)는 페이지 내 날짜 표기가 없어 미확인.

## 4. 개인정보 점검표

### 수집 항목과 보관 기간 제안 (기간은 제안이며 법정 기준 아님)
| 항목 | 대상 | 목적 | 보관 제안 |
|---|---|---|---|
| 카카오 계정 식별자·닉네임·(이메일, 요청 시) | 자녀 | 가입·로그인 | 탈퇴 즉시~30일 내 삭제. 동의항목은 최소화(이메일 불필요하면 받지 않음) |
| 익명 로그인 ID | 부모 | 기기·가족 연결 | 연결 해제/삭제 요청 시 삭제 |
| 가족 그룹, 초대 코드 | 공통 | 연결 | 코드는 만료/사용 후 30일 내 삭제 |
| 밸런스 답변(취향) | 부모 | 코스 진행, 자녀 리포트 | 부모 삭제 요청 또는 가족 해제 시 삭제, 미사용 시 보관 상한 정해 공지 |
| 참여 기록(세션, 연속일, 소요시간) | 부모 | 연속 도장, 리포트 | 최대 12개월 제안 |
| 응원 메시지(정형 문구 키) | 자녀 | 전달 | 12개월 이내 |
| FCM 푸시 토큰 | 공통 | 푸시 | 로그아웃·삭제·토큰 갱신 시 폐기 |
| 이벤트 분석 | 공통 | 개선 | 식별자 최소화, 14개월 이내 제안 |
| 크래시·진단 정보 | 공통 | 안정성 | SDK 기본값 확인 필요 |

- 가족사진·음성·위치·연락처는 MVP에서 수집하지 않음(SPEC 4). 이 상태를 유지하면 데이터 안전 신고가 단순해짐. TTS는 기기 내 처리라면 신고 대상 아님(구현 확인 필요).
- 결제 정보는 MVP에서 수집하지 않음. 전환 시 PG별 재점검.

### 부모 동의 화면 요건 (SPEC 3의 "내 답변이 자녀에게 공개됩니다" 보강)
- 무엇이: 어떤 답변·참여 기록이 공개되는지 예시 1개 포함.
- 누구에게: 연결된 자녀(가족 그룹 구성원) 명시. 자녀가 여러 명이면 모두에게.
- 왜·얼마나: 목적과 보관 기간 한 줄.
- 거부 가능: "동의하지 않으면 자녀에게 공개 없이 쓰기"는 v2 숨김 기능 전까지 불가이므로, 거부 시 연결하지 않고 종료함을 정직하게 안내. 동의 거부 불이익 고지 필요.
- 철회·해제: 부모 화면에서 언제든 연결 해제 버튼(어르신이 찾을 수 있는 위치, 큰 글씨). 동의 시각·문구 버전 저장.
- 문구: 20sp 이상, 쉬운 말, 음성 읽기 제공, 길면 한 화면 한 문장씩.
- 동의 항목이 2개 이상(공개, 푸시 알림)이면 분리해 받기(법 근거 확인 필요).

### 개인정보처리방침 필수 항목
수집 항목, 처리 목적, 보유·이용 기간과 파기 절차, 제3자 제공 여부, 처리위탁(Supabase, Firebase, 카카오 로그인, 분석 도구 등)과 국외 이전 여부(Supabase 리전에 따라 확인 필요), 정보주체 권리·행사 방법, 안전성 확보 조치, 개인정보 보호책임자 연락처, 자동 수집 장치(식별자) 설명, 처리방침 변경 고지. 정확한 법정 항목(개인정보보호법 제30조 등)은 **확인 필요**(법령 본문 이번에 미조회). 앱 안과 스토어에서 공개 URL 필요(Play 요건, 확인).

### Google Play 데이터 안전 신고 (확인: https://support.google.com/googleplay/android-developer/answer/10787469)
- 앱 밖으로 전송되는 데이터는 "수집"이며 SDK 전송분 포함. 신고 책임은 개발자. 개인정보처리방침 링크는 필수.
- 예상 신고: 개인 정보(이름/이메일/사용자 ID: 카카오), 앱 활동(앱 상호작용, 답변=사용자 생성 콘텐츠 성격 검토), 기기 또는 기타 ID(익명 ID, FCM 설치 ID 등), 진단(크래시) 가능. 푸시 토큰 분류는 해당 페이지에 없어 미확인.
- 전송 중 암호화(HTTPS) 신고, 삭제 요청 수단 제공 신고.
- 부모 답변이 건강 정보로 분류되는지는 아래 5와 같이 확인 필요. 보수적으로 "앱 활동"으로 신고하되 근거 기록.

### 계정·데이터 삭제 (확인: https://support.google.com/googleplay/android-developer/answer/13327111)
- 앱에서 계정을 만들 수 있으면 (1) 앱 안 삭제 경로와 (2) 앱 밖에서 삭제 요청 가능한 웹 링크, 둘 다 필요. 웹 링크는 앱으로 돌려보내지 않고 요청이 가능해야 하며 스토어 표기 앱/개발자명 포함. 계정만이 아니라 연관 데이터 삭제. 보관은 가능하나 보관 사유 고지. 
- 익명 로그인 어르신도 "계정"에 해당하는지 미확인. 안전하게 어르신 쪽도 앱 안 "내 기록 지우고 연결 끊기" 제공.
- 자녀 삭제 시 가족 그룹 처리(부모 기록 유지/삭제)를 정책으로 정해야 함: 제안=자녀 전원 탈퇴 시 가족 데이터 삭제, 일부 탈퇴 시 해당 자녀 데이터만 삭제.
- 웹 삭제 요청 페이지는 SPEC 4의 "웹 버전 안 함"과 충돌 가능. 정적 요청 페이지(폼/메일)만 필요. 결정 필요.

### 한국 개인정보보호법 주의점 (전부 확인 필요, 법령 원문 미조회, 정확한 조문은 개인정보보호위원회 자료로 확인)
- 민감정보: 건강 관련 정보가 민감정보인지. 밸런스 답변(음식·취향)은 일반 취향이지만, 인지 상태를 추정하는 분석·리포트를 만들면 건강정보로 볼 위험이 커짐. 판단 포인트: 질문 내용에 질병·약·건강 상태가 있는가, 리포트가 상태를 추정하는가, 의료 목적 표기가 있는가. 현재 설계는 추정하지 않으므로 낮음(가정).
- 고령자: 일반법상 고령자 특칙은 이번에 확인 못 함. 동의 능력 문제는 5에서 다룸.
- 14세 미만 자녀 사용 방지: 자녀 가입 대상 연령 제한을 약관에 명시(법정대리인 동의 의무 조항 확인 필요).
- 처리위탁·국외이전: Supabase·Firebase 리전. 이전 고지·동의 요건 확인 필요.
- 유출 통지·안전조치: 접근 제어, 암호화, 로그 요건 확인 필요. RLS 테스트가 일부 근거.
- 카카오 로그인: 동의항목 최소화, 카카오 앱 심사(비즈 앱 여부, 이메일 수집) 요건 미확인.

### 7.4 앱 액세스(심사용 안내) 문구 초안
기준(2026-11-17 확인): https://support.google.com/googleplay/android-developer/answer/15748846 (재사용 가능한 자격 증명, 2단계·일회용 코드 회피, 영어로 제공, 제3자 로그인은 단계별 안내와 계정 정보 필요.) Console 경로·입력 개수는 화면 변경 가능성이 있어 미확인.

설정: "일부 기능이 제한됨"을 선택하고 아래를 입력(영어, 예시 값은 운영자가 실제로 만들어 채움).
```
This app has two roles.
1) Parent (no sign-up): open the app and choose "I am a parent". Enter the 6-digit invite code below, then accept the consent screen. Code: [운영자 입력 필요: 심사용 고정 코드, 만료 없는 테스트 가족 그룹]
2) Child: sign-in is via Kakao Login. Test account: [운영자 입력 필요: 카카오 테스트 계정 ID] / [운영자 입력 필요: 비밀번호]. The account has 2-step verification turned off and works from any location.
Daily course for parents: photo -> balance question -> Hangul tracing. The child home and report show the parent's activity.
Account deletion: Settings > [운영자 입력 필요: 메뉴 경로]. Web: [운영자 입력 필요: delete-account URL].
No payment is required; all features are free in this release.
```
- 주의: 일반 초대 코드는 1회용·7일 만료이므로 심사용으로 쓰면 만료됨. 심사용 고정 코드 또는 심사용 테스트 가족 그룹 백도어(릴리스 빌드에서 일반 이용자에게 노출되지 않도록)가 필요하며 개발 담당과 합의 필요. 카카오 테스트 계정은 카카오 개발자 설정상 팀원 등록이 필요할 수 있음(미확인).
