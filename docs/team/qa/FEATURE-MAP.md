## 1. 어르신

### P0 시작
- **하는 일**: "앱을 열어요."
- **기대**
  - P0-1: 처음 열면 상징 그림 뒤 FS(역할 고르기)가 보인다.
  - P0-2: 연결된 휴대폰이면 FS 없이 P3(오늘 코스)가 바로 보인다.
  - P0-3: 2초가 넘으면 '잠시만요'가 보인다.
  - P0-4: 오프라인에서 시작 복원이 실패하면 오프라인 화면과 '다시 하기'가 보인다.
- **이벤트**: 없음(첫 실행 이벤트는 FS에서 역할을 고를 때 보낸다)

### FS 역할 고르기
- **하는 일**
  - 어르신: "이 휴대폰은 내 거예요. 가족에게 받은 번호를 쓸래요."
  - 자녀: "제 휴대폰이에요. 부모님께 보낼 번호를 만들래요."
- **보이는 것**
  - 질문 '이 휴대폰은 누구 거예요?'
  - 두 버튼 '부모님 휴대폰이에요' / '자녀 휴대폰이에요'
  - (예정, V18: '이 휴대폰은 누가 쓰세요?', '제가 부모예요' / '제가 자녀예요')

| # | 상태 | 하면 | 보여야 하는 것 |
|---|---|---|---|
| FS-1 | 처음 | 그대로 본다 | 질문, 두 버튼, 사진·기능 줄(높이가 부족하면 기능 줄부터 숨김) |
| FS-2 | 카톡 링크·설치 링크로 열림 | — | 위에 띠 '가족이 보낸 번호가 있어요'. (예정: 둘째 줄 '아래 '제가 부모예요'를 눌러 주세요') |
| FS-3 | — | '부모님 휴대폰이에요' | P1 번호 쓰기. 링크로 번호가 있으면 P1c |
| FS-4 | — | '자녀 휴대폰이에요' | C0 로그인 고르기 |
| FS-5 | 200% | — | 질문과 두 버튼이 먼저 보이고 사진은 숨겨진다(130%부터). 스크롤로 모두 닿는다. 캡처 `320-200-fs-*`([evidence/2026-11-25-200-gap](evidence/2026-11-25-200-gap/README.md)): 둘째 버튼이 첫 화면 끝에 반쯤 걸림(M1, 열림) |

- **이벤트**
  - `app_first_open`: 역할을 처음 고를 때 1회. 속성은 `role_guess`, 설치 경로가 있으면 `install_source`. `role_guess`는 서버가 허용하는 속성(0053)이라 그대로 둔다. r2 A11에서 철회된 것은 새로 제안된 E2(history_opened)의 `role_guess`이고, 이 이벤트와는 관계없다.
  - `link_opened`: 앱 링크로 열림.
  - `referrer_found`: 설치 경로에서 번호를 찾음.
  - 번호 값은 어떤 이벤트에도 보내지 않는다.

## 3. 공통
- **오프라인**: 대부분의 화면은 '인터넷이 잠깐 끊겼어요. 연결되면 이어서 해요'와 [다시 하기]를 보인다. 입력한 숫자·글자는 지우지 않는다.
- **200%**
  - 버튼과 글자가 잘리지 않고 스크롤로 모두 닿는다.
  - 아래 고정 영역은 화면의 40%를 넘지 않는다.
  - 넘칠 때만 아래 흐림·화살표가 보인다.
- **화면 읽기(TalkBack)**
  - 버튼 읽기 이름 = 보이는 글이다. 예: '오늘 코스로', '낱말 쓰기, 3단계 중 3단계'.
  - BackLink는 목적지를 읽는다.
- **[읽어 주세요](기기 TTS)**: 화면 글자는 그대로 두고, 엔진에 넘기기 직전에만 읽기용 문장으로 바꾼다(날짜 '(화)' → 화요일, 세는 말 앞 숫자는 고유어 '9시' → 아홉 시, 'AI' → 에이아이, 범위 '3월~5월' → 삼월에서 오월, 숫자 사이 가운뎃점은 목록에 있는 기념일만). 문장 사이 400ms 쉼, 빠르기·높낮이는 그대로(#238·#241). 실제 소리는 오너 S25 듣기 목록으로만 확인된다(`docs/team/dev/2026-11-24-tts-reading.md` 6절).
- **앱 정보**
  - 'AI가 만든 것': 사진, 배경 음악
  - '병원 앱이 아니고, 안부나 안전을 확인하는 서비스가 아니에요'
  - 약관·방침(주소가 없으면 '[설정 필요]', 개발·staging만)
  - 오픈소스, 사업자 정보, 문의하기

- **실기기 확인 목록(자녀, 11-20 리뷰 L — 에뮬레이터·jest로 확인할 수 없는 것)**
  - C4s-2·C4s-3 (#158): S25에서 TalkBack을 켜고 응원을 보낸다. 확인할 것 셋.
    - 토스트가 뜨면 초점이 '되돌리기'로 가고, '{호칭}께 보냈어요, 되돌리기'를 한 번만 읽는다.
    - 10초 뒤 초점이 '응원 보내기'로 돌아온다.
    - [되돌리기]를 누르면 '응원을 보내지 않았어요'를 다 읽은 뒤 초점이 '응원 보내기'로 간다. 안내가 끊기면 초점 이동을 300ms → 600ms로 늦춘다.
  - C0-6 (#163): TalkBack이 출구 링크를 '부모님은 로그인하지 않아요. 처음으로'로 읽는다('가운뎃점'을 읽지 않음). 문구(`login.parent_exit_top`)가 바뀌면 다시 듣는다. 읽기 이름은 문구의 ' · '를 마침표로 바꿔 만든다.
  - C4-2·C4-5 (#167): 200%에서 첫 카드의 어르신이 응원을 받을 수 없는 분이어도(연결 풀림·나누지 않음) 응원 버튼은 첫 카드 바로 아래에 붙는다. 어르신 둘 중 첫 분이 그런 경우, 버튼이 누구에게 보내는 것으로 읽히는지 본다.

## 4. 출시 전 테스터 가족 내부 사용 — 해 볼 일 목록 (1~2일)

DECISIONS 11-20 '출시 직전 테스터 가족 내부 사용 1~2일 = 출시 게이트'.
- **준비**: 어르신 폰 1대(안드로이드, 글자 크게)와 자녀 폰 1대. 가능하면 자녀를 한 명 더 둔다.
- **기록**: 한 줄마다 '했음 / 막힘(어디서·무슨 말을 했는지)'을 적는다. 막힌 곳은 위 줄 번호로 적는다(예: 'P1-3에서 숫자가 지워질까 봐 멈춤').
- **어르신 행동 관찰**은 `elder-observation-guide.md`를 따른다. 도와주지 말고 본다.

### 1일차
1. [자녀] 앱을 깔고 '자녀 휴대폰이에요' → 카카오(또는 구글·이메일)로 로그인한다. 확인: C0-1·C0-2.
2. [자녀] 부르는 이름을 고르고 [번호 만들기] → [번호 보내기]로 카톡을 보낸다. 확인: C1-2·C3-1·C3-2.
3. [어르신] 카톡의 링크를 눌러 앱을 깔고 연다. 확인: FS-2(번호 띠). 링크 없이 손으로 번호를 쓰는 경로도 한 번 한다(P1-1~P1-3).
4. [어르신] 번호로 연결하고 [좋아요]를 누른다. 확인: P1c·P2-1. [자녀] 화면에 '연결됐어요'와 알림이 오는지 본다(C3-4).
5. [어르신] 해님 인사 뒤 사진 보기 → 크게 보기 → 읽어 주세요 → 다 봤어요. 확인: P3-1·P4-1~P4-3.
6. [어르신] 둘 중 고르기에서 한쪽을 골랐다가 바꾸고 [정했어요]. 확인: P5-2·P5-3. [자녀] C4에 같은 답이 보이는지(C4-3), 첫 답 알림이 한 번만 오는지 본다.
7. [어르신] 낱말 쓰기에서 같은 낱말을 쓴다. 다음에는 일부러 다른 낱말로 [다 썼어요]를 눌러 본다. 확인: P6-3·P6-4.
8. [어르신] 마침 화면 → [알겠어요] → 알림 안내에서 [알려 주세요]. 확인: P7-1·N1-1·N1-2.
9. [자녀] [응원 보내기]로 하나 보내고, 다른 하나는 [되돌리기]. 확인: C4s-2·C4s-3. [어르신] 앱을 다시 열어 응원이 뜨는지 본다(P8-1).
10. [어르신] 설정 → '가족에게 이렇게 보여요'. 자녀 화면과 같은지 나란히 놓고 본다(P13p-1).
11. 둘 다 휴대폰 글자를 가장 크게(200%) 하고 1~9 중 3개를 다시 한다. 잘리거나 누를 수 없는 곳을 적는다.

### 2일차
12. [어르신] 아침 알림 '오늘의 사진이 왔어요'를 눌러 연다. 확인: 매일 알림 → P3. 어제 도장과 '지난 날 보기'(P15-1·P15-3)도 본다.
13. [어르신] 코스 도중 비행기 모드를 켜고 [다 봤어요]·[정했어요]를 눌러 본다. 끄고 [다시 하기]. 확인: P4-5·오프라인 공통.
14. [어르신] 설정에서 [그만 보여 주기] → [자녀] C4가 '답을 나누지 않는 중이에요'로 바뀌는지 본다. 다시 [다시 보여 주기]. 확인: P13-2·P13-3·C4-4.
15. [자녀] 지난 날 탭 → '이야기 주제 추천' → [관심 있어요]. 확인: C5-1·C5-3.
16. [자녀] 로그아웃 → 같은 방법으로 다시 로그인한다. 같은 가족으로 이어지는지 본다(C7-2).
17. (두 번째 자녀가 있으면) 같은 어르신에게 연결해 본다. 첫 답 알림이 그 자녀에게도 다음 답 때 한 번 오는지 본다.
18. 마지막 날에만 한다(되돌릴 수 없음). [어르신] 모두 지우기 두 단계 → '모두 지웠어요' → 처음 화면. [자녀] C4가 '연결이 풀렸어요'로 바뀌는지 본다(P9-1~P9-3·C4-5).
