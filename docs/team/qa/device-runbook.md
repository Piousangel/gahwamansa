| 다크 | 시스템 다크 | `adb shell cmd uimode night yes` / `no` — 앱은 라이트 고정이어야 함 |
| TalkBack | 켬 | 설정 → 접근성 → TalkBack(adb 토글보다 확실). 읽기 속도 기본 |
| 키보드 | 삼성 키보드 천지인, 삼성 키보드 두벌식(쿼티 한글), Gboard 두벌식 | 설정 → 일반 → 키보드 목록. Gboard는 Play에서 설치 |
