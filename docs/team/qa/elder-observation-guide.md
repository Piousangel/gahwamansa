# 어르신 관찰 테스트 — 진행자용 한 장 (V27, 빌드 1 최우선 관문)

70대 어르신 한 분이 **처음 설치한 앱에서 첫 도장까지 혼자** 갈 수 있는지 보는 테스트입니다. 진행자(사용자)는 옆에서 **보고 적기만** 합니다.
- 근거: `docs/team/board/2026-11-19-ux-deep/SUMMARY.md` (c) 퍼널 v2, (h) P0 관문, r1/D §7 관찰 항목, DECISIONS 11-19.
- 같이 쓰는 종이: `elder-observation-sheet.md`(단계별 체크리스트와 기록 양식). 인쇄해서 한 장씩 쓰면 됩니다.
- 걸리는 시간: 준비 20분, 테스트 20~40분, 정리 10분(추정).

---

## 1. 사전 준비 (어르신이 오시기 전에)

**지금 빌드에서 바뀐 점(11-19 기준 사실)**
- 카톡 링크로 번호를 자동으로 채우는 기능은 아직 꺼져 있어요(링크 도메인 미정). 그래서 **번호 6자리를 카톡 메시지에서 보고 직접 쓰는 경로**로 합니다.
- Play 스토어에 아직 없어요. 앱은 **진행자가 미리 설치**하고, 테스트는 "홈 화면 아이콘 누르기"부터 시작합니다. 'Play에서 설치 → 열기' 단계는 이번에 볼 수 없어요(기록지에 "해당 없음"으로 표시).

**준비물 체크**
- [ ] 어르신 폰: 평소 쓰시는 폰이 가장 좋아요. 어렵다면 진행자 폰을 빌려 드리되, 글자 크기는 어르신 평소 값으로 맞춰요.
- [ ] 어르신 폰에 staging 앱(이름 "테스트 가화만사성") 설치. 설치만 하고 **열지는 마세요**(열면 첫 실행 상태가 사라져요). 이미 열었다면 설정 → 애플리케이션 → 테스트 가화만사성 → 저장공간 → 데이터 삭제.
- [ ] 홈 화면 첫 페이지에 앱 아이콘을 둡니다. 어디 있는지는 어르신께 **알려 드리지 않습니다**. 대신 시작 문장에서 "이 그림(아이콘)"이라고 가리켜만 드려요.
- [ ] 자녀 쪽: 진행자 폰의 staging 앱에서 **자녀로 로그인 → 번호 만들기**(번호는 7일 동안 쓸 수 있어요). 연결이 되면 진행자 폰에 알림이 올 수 있으니, 테스트 중에는 진행자 폰 소리를 꺼 두세요.
- [ ] 카톡으로 어르신께 번호를 보냅니다(평소 자녀가 보내듯이). 메시지에 번호 6자리가 한 줄로 따로 보이게 써요. 예: "엄마, 앱 열고 이 번호 써 줘요" + 다음 줄에 "123 456".
- [ ] 소리: 어르신 폰 벨소리를 일반, 미디어 소리를 중간으로(읽어 주기 소리가 나게). **끝나면 원래대로**.
- [ ] 방해 금지 모드 켜기(다른 알림이 뜨지 않게, 끝나면 끄기).
- [ ] 화면 녹화(선택): 아래 4절 동의를 받은 뒤 폰의 '화면 녹화'를 **소리 없음**으로 시작. 얼굴은 찍지 않아요(카메라·삼각대 쓰지 않음).
- [ ] 타이머(진행자 폰 스톱워치)와 기록지, 펜.
- [ ] 테스트 가족 표시: 끝나고 운영자에게 "테스트 가족"으로 표시해 달라고 요청(dev-server-notes §15, 지표에서 빠지게). 진행자가 직접 할 일은 없어요.

## 2. 시작할 때 말할 문장 (그대로 읽어 주세요)

> "오늘은 어머니(아버지)를 시험하는 게 아니라, **이 앱이 쉬운지 시험하는** 거예요. 막히면 그건 앱을 만든 사람 잘못이에요.
> 제가 옆에서 보기만 하고 도와드리지 않을 거예요. 서운해하지 마세요. 도와드리면 어디가 어려운지 알 수가 없어서 그래요.
> 하시면서 생각나는 걸 소리 내서 말씀해 주시면 정말 도움이 돼요. '이게 뭐지?', '어디 누르지?' 같은 거요.
> 그만하고 싶으시면 언제든 '그만'이라고 하시면 돼요.
> 카톡에 제가 번호를 보내 놨어요. 이 그림(앱 아이콘)을 눌러서 시작해 보세요. 오늘 사진 보기를 끝까지 해 보시면 돼요."

## 3. 진행 규칙

**하면 안 되는 것**
- 화면을 가리키거나, 대신 누르거나, "거기 말고요" 하기.
- "잘하셨어요", "맞아요"처럼 정답을 알려 주는 반응(표정·고개 끄덕임 포함). "네, 계속해 보세요"만 써요.
- 앱 설명을 미리 하기("이건 사진 보는 앱이에요" 등).
- 어르신이 물어보면 바로 답하기 → 대신 **"어떻게 하면 될 것 같으세요?"**라고 되물어요.

**하는 것**
- 단계가 바뀔 때마다 기록지에 시각(분:초)을 적어요.
- 말없이 멈추시면 10초 뒤에 "지금 무슨 생각 하세요?" 한 번만.
- 잘못 누른 곳, 두 번 누른 곳, 화면을 오래 본 곳을 적어요.

**언제 개입하나** — 아래 중 하나면 개입하고, 기록지에 **"개입 #"과 이유**를 적어요.
1. 같은 화면에서 **2분** 넘게 진전이 없을 때(누르기는 하는데 화면이 안 바뀜도 포함).
2. 앱 밖으로 나가서(홈 화면·카톡 등) **1분** 안에 못 돌아오실 때.
3. 어르신이 "모르겠다", "그만할래" 하시거나 지쳐 보일 때.
4. 결제·개인정보·다른 앱 설치처럼 테스트와 상관없는 곳에 들어가셨을 때.

**개입하는 순서**(작게부터, 한 단계씩)
1. 질문만: "이 화면에서 뭘 하면 될 것 같으세요?"
2. 힌트: "화면 아래쪽을 한번 보세요" (어디를 누를지는 말하지 않음)
3. 직접 안내: "이 노란 버튼을 눌러 보세요" (이 단계까지 가면 그 단계는 '도움으로 통과')
4. 진행자가 대신 처리하고 다음 단계로 넘어가기 (그 단계는 '실패')

## 4. 녹화·기록 동의 (시작 전에 읽고 '네'를 받기)

> "더 잘 고치려고 **휴대폰 화면만** 녹화해도 될까요? 얼굴과 목소리는 녹화하지 않아요. 이름이나 전화번호 같은 건 적지 않고, 녹화는 앱 만드는 팀만 보고 다 고친 다음에 지워요. 싫으시면 녹화 없이 종이에만 적을게요."

- '네'라고 하시면 기록지 맨 위 '동의' 칸에 시각만 적어요(서명·이름 받지 않음).
- 녹화 파일에 카톡 대화나 다른 앱 알림이 찍혔다면, 팀에 넘기기 전에 그 부분을 잘라 주세요(어렵다면 녹화를 팀에 넘기지 말고 기록지만).
- 기록지에는 이름·나이(정확한 나이 대신 "70대"만)·전화번호·사는 곳·관계를 쓰지 않아요. 앱 화면의 가족 호칭은 그냥 "호칭"이라고 적어요.

## 5. 끝내는 기준

- **완료**: 도장 화면(P7 "오늘 코스를 마쳤어요"·도장)이 나오면 끝. 그 뒤 알림 물음이 나오면 어르신 선택대로 두고 기록만.
- **중단**: 테스트 시작 후 **40분**이 지나거나, 개입 4단계(대신 처리)가 **3번** 나오거나, 어르신이 그만하고 싶어 하시면 끝.
- 끝나면 질문 3개만(답을 그대로 적기):
  1. "제일 헷갈렸던 데가 어디였어요?"
  2. "내일 혼자 다시 하실 수 있을 것 같으세요?"
  3. "사진 보면서 떠오른 얘기가 있으셨어요?"
- 원래대로 돌리기: 소리·방해 금지·글자 크기. 앱은 지우지 말고 두세요(다음 날 '혼자 다시 하기'를 볼 수 있으면 좋아요).

## 6. 결과로 무엇을 바꾸나 (판정 기준)

테스트가 끝나면 기록지 마지막 표를 채워 팀에 넘겨 주세요. 팀은 아래 기준으로 판정합니다.

| 판정 | 조건 | 다음 할 일 |
|---|---|---|
| **통과** | 도움 0번(개입 1단계 질문은 허용) + 첫 도장까지 완료 + 2분 넘게 막힌 단계 0개 | 빌드 1 관문 G-INT 'V27' 칸 통과로 기록. 관찰 메모의 작은 불편은 다음 빌드 후보로 |
| **조건부 통과** | 첫 도장까지 완료 + 개입 2단계(힌트) 이하만 1~2번 + 같은 지점에서 두 번 막히지 않음 | 힌트가 필요했던 화면을 그 레인에 '중간' 결함으로. 고친 뒤 **같은 분 또는 다른 70대 1명**으로 그 구간만 다시 보기 |
| **실패** | 개입 3단계(직접 안내) 이상이 1번이라도 있음, 또는 개입이 3번 이상, 또는 완료 못 함 | 직접 안내가 필요했던 화면을 '높음' 결함으로, 빌드 1 출시 보류. 고친 뒤 처음부터 다시 1회 |

**막힘 지점을 레인으로 나누는 법**(팀이 함)
- 앱 밖(카톡·홈 화면·아이콘 찾기) → 자녀 안내 문구(라이터)·C3
- 역할 고르기·번호·연결 확인·동의 → 어르신 연결(P0~P2)
- 코스 홈·사진·고르기·자판·도장 → 어르신 코스(P3~P7)
- 소리·읽어 주기 → 오디오
- 미리 정해 둔 질문(퍼널 v2 가설)은 기록지 '가설 확인' 칸으로 따로 답합니다. 예: '지금 할 차례' 행을 누르는가, 동의 화면 ✓를 하나씩 누르는가.

**숫자로 남길 것**: 첫 도장까지 걸린 시간, 단계별 걸린 시간, 개입 횟수와 단계, 막힘(30초 넘게 진전 없음) 횟수, 헛탭(눌렀는데 아무 일 없음) 횟수. 한 분만 본 결과라 **비율로 말하지 않고** "이 분은 여기서 막혔다"로 씁니다.
