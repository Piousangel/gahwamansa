  - 11-24 곱게 차려입기 / 편하게 입기 → A 고름

## 확인 결과

1. **두 칸·순서**: 100%에서 모든 카드가 A 왼쪽·B 오른쪽이다. 노랑은 카드마다 고른 쪽 1개다. 200%에서는 A 위·B 아래로 쌓이고 순서를 지킨다.
2. **14자 보기(100%)**: 안 고른 칸에서 어절 단위로 두 줄이 된다. 옆 팻말은 stretch로 같은 높이까지 늘어난다.
3. **TalkBack(M1)**
   - 팻말을 직접 만져도 초점은 카드 하나에 잡힌다. '다음 항목'도 카드에서 카드로 넘어간다.
   - 접근성 트리(`uiautomator dump --compressed`)에서도 팻말·흐린 칸 노드가 빠진다. 카드 노드만 `11월 23일, 국밥과 칼국수 중, 고른 답 칼국수` 한 이름으로 남는다.
   - 압축하지 않은 덤프에는 숨긴 노드도 보인다. 이 덤프는 중요하지 않은 뷰까지 포함하기 때문이다.
   - 한계: 실제 음성은 녹음하지 못했다. 초점 위치와 접근성 트리로 판단했다.
4. **못 본 것(호스트 과부하로 중단)**
   - 호스트 부하 평균이 35~65까지 올랐다. 그 때문에 에뮬레이터에서 System UI·system process ANR이 계속 났다. 입력이 먹지 않아 다시 부팅했지만 다시 멈췄다.
   - 그래서 아래 세 가지를 찍지 못했다. 다음 순번에서 다시 찍어야 한다.
     - **320×640·200%**
     - **360dp·배율 1.4의 첫 프레임 가로→세로 전환(L-b)**
     - **14자 카드의 200%**
   - L-b는 jest로 고정돼 있다(`childPastSignPair` L3·L5: 폭을 재기 전 가로, 잰 뒤 어절이 넘치면 세로 한 번).
5. 관찰: LogBox에 'Open debugger to view warnings'가 떴다. logcat에는 `ReactNativeJS: Error: undefined`가 찍혔다(11-25 00:22·00:43). 이 화면과 관계가 있는지는 확인하지 못했다. 처음 뜬 때는 지난 날 화면을 열기 전 시작 화면이었다.
