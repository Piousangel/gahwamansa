## 찍은 조건

- **기기**: 에뮬레이터 gahwa_small(emulator-5556, `-read-only`, 창 없음). S25는 건드리지 않았다(모든 adb 명령에 `-s emulator-5556`).
  - 시작 때 화면 설정: 1080×2340, density 440, 글자 1.0, TalkBack 끔(null)
  - 부하: 부팅 직후 27까지 올랐다. 15 아래로 내려간 뒤 찍었다(찍는 동안 3.1~14.7).
- **빌드**: staging debug APK(`assembleStagingDebug`, arm64)에 이 브랜치 JS를 올렸다.
  - APK는 #263 때 빌드한 것을 다시 썼다. 그 뒤 main에 네이티브 변경(package.json·android)이 없다.
  - Metro는 8091에서 띄우고 `adb reverse tcp:8081 tcp:8091`로 이었다. 맥의 8081은 건드리지 않았다.
- **임시 상태** (커밋하지 않았고, 끝난 뒤 모두 되돌렸다)
  - `config.local.ts`: 예시 파일을 복사했다(`API_MODE: 'fake'`).
  - `App.tsx`: 장면 파일로 `createFakeApi(…)`를 골랐다. 장면은 셋이다.
    - FS·P1c: 기본값
    - C1: `{who: 'child'}`
    - C7: `{who: 'child', childFamily, childLinked, consented, parentTitle: '엄마'}`
    - `restore`를 켰다.
  - `useFoldGap`: 접힘 계산 값을 `console.log`로 찍었다(아래 실측).
  - 화면 이동은 uiautomator dump로 글을 찾아 눌렀다. 순서: FS → 부모님 휴대폰이에요 → 숫자 1~6 → P1c, 자녀 홈 → 설정 → C7.
  - 150%의 '전' 두 장(P1c·C1)은 문턱 상수만 잠깐 9로 바꿔 예전 배치로 그려 찍었다. 찍은 뒤 되돌렸다.
- **크기**
  - 320×640 200%: `wm size 880x1760` + `font_scale 2.0`
  - 360×640 100%: `wm size 990x1760` + `font_scale 1.0`
  - 회귀용 320×640 150%: `font_scale 1.5`
- **끝난 뒤 되돌린 것**
  - `wm size reset`, `wm density reset`(440), `font_scale 1.0`, TalkBack null을 확인했다.
  - reverse를 지우고, 에뮬레이터·Metro 8091을 껐다.

## #274 QA-2 M1 반영: 약관 고지는 Dock 안 버튼 바로 위

리드 결정: 버튼을 누르는 것이 곧 동의라서, 약관 고지는 누르는 순간 보여야 한다. 그래서 모든 배율에서 Dock 안 [이 번호로 연결하기] 바로 위에 둔다.

- 조건은 위와 같다(에뮬레이터 5556, 부하 3.7~8.2). 끝난 뒤 size·density·font·TalkBack을 되돌리고, 에뮬레이터·Metro를 껐다.
- 먼저 긴 줄 그대로 Dock에 넣어 봤다(`320-200-qa2-p1c-longline-try.png`).
  - 200%에서 약관 줄이 191dp라, Dock 상한 256dp(40%)를 넘쳤다. 버튼이 Dock 스크롤 뒤로 반쯤 밀리고 '더 있음' 흐림이 생겼다.
  - 그래서 1.6 이상은 **짧은 고지**(처음 「연결하면 약관에 동의해요」, 법률 판정 뒤 「연결하면 약관에 동의하게 돼요」 + '약관' 링크)를 Dock에 두고, 긴 문장은 본문(번호 아래)에 그대로 둔다.
- 짧은 고지만큼 Dock이 커져 본문 창이 280dp로 줄었다. 그러자 두 줄 번호 카드(190)가 다시 걸쳤다.
  - 그래서 1.6 이상에서는 번호를 한 줄로 그린다. 확대 상한 1.2(62dp, 100%의 52보다 크다), 글자 간격 1, 카드 좌우 여백 12다.

### 법률 판정 뒤 확정 문구 (#274 코멘트 7158739909)

- `legal.agree_parent_short`를 「연결하면 약관에 동의하게 돼요」로 확정했다(원안보다 3자 길다).
- 320×640 200%에서 다시 쟀다(`320-200-legal-final-p1c.png`, 부하 8.5).
  - Dock은 672px = 244dp로 상한 256dp 안에 든다. 고지는 그대로 2줄이고, 번호 카드도 통째로 첫 화면에 있다.
- 법률 조건 3개는 jest `p1cLegalShort`가 고정한다.
  - ① '약관' 링크의 읽기 이름이 '이용약관'이고, 누르면 이용약관을 연다.
  - ② 1.6 이상에서 본문 긴 문장의 두 링크가 본문 스크롤 안에 있다.
  - ③ 배율과 상관없이 같은 동의 기록(두 문서 버전)을 남긴다.

## 남은 것

- 첫 화면 빈칸: C7·P1c 200%는 R-15로 민 만큼 첫 화면 아래가 빈다(C7 약 40%). P7 #263 재확인 L2와 같은 종류라, 오너가 빈 화면으로 느끼면 재검토한다.
- P1c·FS는 옛 `ui/Screen`이다. 그래서 '더 있음'이 흐림 28로만 보이고, 빈칸 위에서는 거의 보이지 않는다. v4 띠(MoreBand)로 옮기는 것은 이번 범위 밖이다.
- L1(묶음 이름과 낱개 글이 두 번 잡힘), L3(100% 끝 몇 px 비침), L4(뒤로 링크 모양)는 목록만 남긴다(리드 지시).
- FS 200%에서 스플래시 심볼이 날아와 앉을 자리가 질문·버튼 아래(첫 화면 밖)로 바뀐다. 에뮬레이터는 스플래시를 끝낸 상태로 시작해 보지 못했다 → S25 확인.
