# 200% 캡처가 없던 9화면 실측 (내부 테스트 필수 7번 · A1) · 2026-11-25

내부 테스트 완료 기준(`docs/team/2026-11-25-internal-test-done-criteria.md`) A1 줄에서 '이번에 못 찾은 것'으로 남은 9화면을 찍었다.
화면은 FS·P1·P1c·P9(+P9-2 확인 상자)·C0·C1·C3·C7·C8이다.
**고치지 않았다.** 문제는 아래 '문제 목록'에 적었다. 고칠 레인은 리드가 정한다.

## 찍은 조건

- **기기**: 에뮬레이터 gahwa_small(emulator-5556, `-read-only`, 창 없음). S25는 건드리지 않았다(모든 adb 명령에 `-s emulator-5556`).
  - 시작 때 화면 설정: 1080×2340, density 440, 글자 1.0, TalkBack 끔(`enabled_accessibility_services` = null), `hide_error_dialogs` = null.
- **크기**
  - 320×640dp 200%: `wm size 880x1760` + `font_scale 2.0`
  - 360×640dp 100%: `wm size 990x1760` + `font_scale 1.0`
- **빌드**: main `830b317a`(#263 병합 뒤)에서 `assembleStagingDebug -PreactNativeArchitectures=arm64-v8a`를 새로 빌드해 에뮬레이터에만 설치했다(versionCode 1609).
  - Metro는 8091에서 띄우고 `adb reverse tcp:8081 tcp:8091`로 이었다. 맥의 8081은 건드리지 않았다.
  - 앱의 개발 서버 주소 설정(`debug_http_host`)을 `localhost:8081`로 두었다. 기본값 10.0.2.2:8081은 맥의 다른 Metro로 가서 404가 났다. 그래서 Maestro `clearState` 대신 `stopApp`을 썼다(clearState는 이 설정을 지운다). fake API는 메모리 상태라 앱을 다시 켜면 처음부터다.
- **부하**: 시작 때 1분 평균 4.4였다. APK 빌드 직후 25까지 올라 15 아래로 내려간 뒤 찍었다. 매 장면 전에 15 미만이 될 때까지 기다리게 했다(찍기 시작 때 7.5~14.9).
  - 처음 C3·C7을 찍을 때 16~21이던 회차가 있었는데, 그 캡처는 버리고 15 아래에서 다시 찍었다.
- **임시 상태** (커밋하지 않았고, 끝난 뒤 모두 되돌렸다)
  - `config.local.ts`: 예시 파일을 복사했다(`API_MODE: 'fake'`). 끝난 뒤 지웠다.
  - Maestro 임시 흐름(`app/e2e/audit/_tmp200gap/`): 200%에서는 숫자 키 4~0, P2 '좋아요', 설정 '모두 지우기' 행, 개발자 메뉴 역할 버튼이 첫 화면 밖이다. 그래서 기존 공용 흐름에 스크롤을 더한 사본을 썼다. 끝난 뒤 지웠다.
  - C7·C8만: `selectApi.ts`의 `createFakeApi()`를 `{childFamily: true, childLinked: true, consented: true, parentTitle: '엄마'}`로 잠깐 바꿨다(`audit/c8-delete.yaml` 머리 주석과 같은 방법). 개발자 메뉴로 어르신 연결을 흉내 내는 길(`common/child-linked-home.yaml`)은 200%에서 개발자 메뉴 버튼이 화면 밖이라 쓰지 않았다. 끝난 뒤 되돌렸다(`git status` 깨끗).
- **재는 방법**: 각 화면에 들어간 뒤 `screencap`(1번) → `uiautomator dump` → 본문(`screen-body`)을 왼쪽 9%에서 천천히 밀며 화면이 더 바뀌지 않을 때까지 찍었다(2번부터).
  - 접힘 걸침(R-15)은 dump에서 '본문 창 아래 끝에 붙어 있고 위 끝은 그보다 위인 요소'를 후보로 잡고, 캡처로 눈으로 확인했다.
  - 읽기 순서는 dump 트리 순서다. 누를 수 있는 묶음 안의 글은 뺐다. dump는 화면에 보이는 요소만 주므로 스크롤한 장의 dump를 이어 붙였다. 실제 TalkBack 초점은 실기기로만 확인된다(아래 'S25 확인 목록').
- **끝난 뒤 되돌린 것**
  - `wm size reset`(1080×2340), `wm density reset`(440), `font_scale 1.0`, TalkBack 끔(null), `hide_error_dialogs` 지움(null)을 확인했다.
  - 앱의 `debug_http_host` 설정 파일을 지웠다. reverse를 모두 지웠다. 에뮬레이터와 Metro 8091을 껐다.
