# 5단계 캡처 후속 4건 실측 · 2026-11-25

#254 캡처([2026-11-25-five-steps](../2026-11-25-five-steps/README.md))의 [후속] 문제 1·3·4·5를 고친 뒤 다시 찍었다.
'전' 열은 #254 캡처 파일이고, '후' 열은 이 폴더에 있다.

## 찍은 조건

- **기기**: 에뮬레이터 gahwa_small(emulator-5556, `-read-only`, 창 없음). S25는 연결하지 않았다.
  - 시작 때 화면 설정: 1080×2340, density 440, 글자 1.0, TalkBack 끔(`enabled_accessibility_services` = null)
  - 호스트 부하 1분 평균: 시작 때 4.05였고, 찍는 동안 4.1~13.7이었다(15 넘은 때 없음)
- **빌드**: 설치돼 있던 staging 디버그 APK(`com.bumojasik.app.staging`)에 이 브랜치 JS를 올렸다.
  - Metro는 8091에서 띄우고 `adb reverse tcp:8081 tcp:8091`로 연결했다. 맥의 8081은 건드리지 않았다.
- **임시 상태** (커밋하지 않았고, 끝난 뒤 모두 되돌렸다)
  - `config.local.ts`: 예시 파일을 복사했다(`API_MODE: 'fake'`). 끝난 뒤 지웠다.
  - `App.tsx`: 장면 파일(`scene.tmp.ts`)을 읽어 `createFakeApi({linked, consented, realImage, completedSteps, recallSlot, answeredChoice, passOnKey})`로 앱을 띄웠다. `restore`를 켰다.
    - 5단계 스위치는 #254와 같은 방식으로 켰다. 시작 때 `setFeature('fiveSteps', …)`를 부른다.
  - fake 사진 주소는 `http://localhost:8093/day-01.jpg`(`content/photos`를 맥에서 띄우고 `adb reverse tcp:8093`)로 바꿨다. 앱 폴더에 사진을 복사하지 않았다.
  - ② 높이를 재려고 `RecallStep`에 잠깐 `console.log`를 넣었다. 잰 뒤 지웠다.
- **크기**
  - 360×640dp 100%: `wm size 990x1760`, `font_scale 1.0`
  - 320×640dp 200%: `wm size 880x1760`, `font_scale 2.0`
- **끝난 뒤 되돌린 것**
  - `wm size reset`(1080×2340), `wm density reset`(440), `font_scale 1.0`, TalkBack 끔(null)을 확인했다.
  - reverse를 지웠다. 에뮬레이터·Metro 8091·사진 서버 8093을 껐다.
