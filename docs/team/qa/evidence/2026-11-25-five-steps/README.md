## 보인 문제 (고치지 않고 기록만 — 리드 지시)

1. **지금 행 스크롤 위치** (01, 두 배율 모두)
   - `CourseHome`은 행의 자연 위치(FoldStack 측정값)로 `showRange`를 부른다.
   - 그런데 실제 행은 R-15 접힘 여백만큼 더 아래에 있다. 그래서 스크롤한 뒤에도 지금 행이 '더 있음' 띠 아래로 반쯤 가려진다.
   - 스크롤한 화면 위쪽에는 접힘 여백(빈칸)도 보인다.
   - jest에는 레이아웃이 없어 이 경로를 시험하지 못했다.
2. **200% 선택 카드 글자 꺾임** (04·06, 320×640 200%)
   - `Choice`의 `tagBelow`(`answerBody`의 `flexBasis: '100%'`)가 실기기에서 줄을 바꾸지 못한다. 글 칸이 '골랐어요' 옆에서 줄어들어 낱말이 한 글자씩 꺾인다.
   - ⑤는 「봄, 그게 좋아요」가 세로로 한 글자씩 나온다.
   - 원인 추정: `flexShrink` 1 때문에 wrap 대신 줄어든다.
   - jest 시험은 스타일 값만 봐서 이 문제를 잡지 못했다.
   - **200% 사용성에 직접 영향** — 다음 수정 1순위로 제안한다.
3. **P7 본문이 첫 화면 밖으로 밀림** (08: 360 100%, 07·08: 320 200%)
   - 건넨 날은 본문이 3줄이 된다. 그러면 R-15 접힘 규칙으로 본문 묶음이 통째로 밀려, 첫 화면에 제목만 남는다.
   - 3단계 P7(본문 2줄)도 320 200%에서는 같은지 비교 캡처가 필요하다.
4. ② 100% 첫 화면에 보기 카드가 하나도 없다(03). 시안 README 리스크 3에서 이미 예상한 것이다. 관찰 테스트에서 볼 항목이다.
5. 다 마친 홈의 도장이 제목 오른쪽이 아니라 아래 줄에 있다(02). 제목이 3줄이라 묶음이 wrap된 결과다. 시안 C-나는 제목 옆을 기대했으니 디자인 확인이 필요하다.
