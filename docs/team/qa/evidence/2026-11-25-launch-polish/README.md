# 시작 빌드 다듬기 실측 (PR #249) · 2026-11-25

- **기기**: 에뮬레이터 gahwa_small(emulator-5556, `-read-only`, 창 없음)
  - 시작할 때 화면은 1080×2340, density 440, 글자 1.0, TalkBack 끔이었다.
  - 호스트 부하 1분 평균은 시작 때 4.1이었다. 찍는 동안 다른 작업 때문에 19~39까지 올랐다. 그래서 화면 전환이 느렸고, 캡처는 전환이 끝난 뒤에 찍었다.
- **빌드**: 설치돼 있던 staging 디버그 APK(`com.bumojasik.app.staging`)에 이 브랜치 JS를 올렸다.
  - 브랜치는 `v4/launch-polish`이고, origin/main(#242·#243)을 병합한 뒤(a711db4a)다.
  - Metro는 8091에서 띄우고 `adb reverse tcp:8081 tcp:8091`로 연결했다. 맥의 8081(몽망 expo)은 건드리지 않았다.
- **임시 상태** (커밋하지 않았고 되돌렸다)
  - `selectApi`는 `createFakeApi({day: 1, who: 'parent', linked, consented, realImage, completedSteps})`로 바꿨다. P3·P4는 `[]`, P5는 `['photo']`이다.
  - `App.tsx`의 `restore`를 켰다.
  - 첫 인사를 다시 보이게 하려고 `prefs.firstGreetingSeen`이 늘 false를 돌려주게 했다.
  - fake 사진 주소는 앱 폴더에 복사한 `content/photos/day-01.jpg`(`file://…/files/day-01.jpg`)로 바꿨다. 1일차 '마을 입구 나무'와 같은 사진이다. 끝난 뒤 지웠다.
  - 08번만: P5 머리줄을 잠시 뺐다(비교용).
- **크기**
  - S25급: 1080×2340, density 440 → 393×851dp
  - 320×640dp: `wm size 880x1760`
  - 100%는 `font_scale 1.0`, 200%는 `font_scale 2.0`
- **끝난 뒤 되돌린 것**
  - 화면 설정: `wm size reset`(1080×2340), `wm density reset`(440), `font_scale 1.0`, TalkBack 끔(`enabled_accessibility_services` = null)을 확인했다.
  - 그 밖: reverse를 지웠고, 앱 폴더의 사진 사본을 지웠다. 그다음 에뮬레이터와 Metro 8091을 껐다.

## 확인 결과

1. **P5 머리줄 뒤 선택지 접힘 (QA-1 M1)**
   - 320×640 200%에서는 머리줄이 없을 때(08)도 안내와 선택지가 이미 첫 화면 밖이었다. 머리줄은 그 빈자리를 채울 뿐이다. 그래서 '선택지가 처음 보이는 위치'는 바뀌지 않았다. 한 번 내리면 보인다(06).
   - 걸친 요소는 R-15대로 통째로 밀린다. 잘린 글자는 없다.
2. **P4 질문 1개**: 100%·200% 모두 질문이 하나다. 200%에서도 질문과 [읽어 주세요]가 첫 화면에 든다(04).
3. **P3 인사**: 100%는 카드 둘째 줄에, 200%는 카드 밖 제목에 '하나씩 차례로 해요'가 나온다. 어느 배율에도 남은 수 문구가 없다.

- **P5 문구 겹침**: 머리줄 '요즘 마음 가는 쪽을 골라요'와 바로 아래 안내 '정답은 없어요. 마음 가는 쪽을 눌러 주세요'에 '마음 가는 쪽'이 두 번 나온다. 안내 문구를 다듬을지는 라이터가 판단할 몫이다.
