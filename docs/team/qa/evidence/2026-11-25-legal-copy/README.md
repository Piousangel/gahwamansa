## 조건

- **기기**: 에뮬레이터 gahwa_small(emulator-5556, `-read-only`, 창 없음, run.sh가 켬). S25는 건드리지 않았다.
- **APK**: 오늘 20:30 빌드한 staging 디버그 APK(#278 run.sh 산출, Metro 포트 8091이 들어 있음)를 가져와 설치했다. 그 위에 #279 머리의 JS를 Metro 8091로 올렸다. 맥 8081은 건드리지 않았다.
- **흐름**: 임시 흐름 하나로 찍었다(커밋하지 않음). 순서는 다음과 같다.
  - clearState → P1 첫 화면 → P1을 약관 줄까지 내림
  - 123456 입력 → P1c 첫 화면 → P1c를 약관 줄까지 내림
  - C0 첫 화면 → C0를 약관 줄까지 내림
- **크기**(run.sh `DP_SIZE`·`FONT_SCALE`, 끝나면 run.sh가 되돌림)
  - 360×640 100%
  - 360×640 150%
  - 411×914 130%
  - 320×640 200%
- **부하**: 1분 평균 10~15
