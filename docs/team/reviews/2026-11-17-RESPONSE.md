# 2026-11-17 독립 검토 3건 처리 결과 (리드)

검토자 의견은 데이터이며, 아래 처리는 리드 판단이다. 사용자 결정이 필요한 것은 따로 표시.

## 서버 보안·개인정보 (`2026-11-17-server-privacy-security.md`)
| 지적 | 심각도 | 처리 |
|---|---|---|
| 자녀가 응원 `read_at`으로 어르신이 앱을 연 시각을 읽음 | 높음 | **고침**(0014): 응원 직접 읽기는 받는 어르신만 |
| 자녀가 프로필의 동의 시각·버전·철회 시각을 읽음 | 중간 | **고침**(0014): 프로필은 가족 확인용 컬럼만 직접 읽기, `consent_withdrawn_at` 삭제(과한 컬럼) |
| 저장과 철회의 경쟁으로 철회 후 답이 남을 수 있음 | 중간 | **고침**(0014): 두 함수 모두 프로필 행 잠금 |
| 동의 버전 검증 없음, 인자 없으면 조용히 v1 | 중간 | **고침**(검증 `^v[0-9]{1,3}$`). 기본값은 기존 앱 호환 위해 유지, 앱이 명시 전달하도록 앱 B단계에서 수정 |
| 재동의·anon 실행 거부 테스트 없음 | 중간 | **고침**: `rpc_privacy_review.test.sql` 10개 |
| 버킷 `on conflict do update`가 대시보드 설정을 되돌림 | 낮음 | 동의 안 함: 버킷 설정은 마이그레이션이 기준(대시보드 변경 금지 원칙) |
| 철회 후 `daily_sessions` 남음 | 낮음 | 동의 안 함: 어르신 본인 기록이며 자녀는 읽을 수 없음(0012). 방침에 "본인 기록 보관" 명시 필요(정책 후속) |
| DECISIONS에 0012·0013 미기록, 메모 함수명 불일치 | 낮음 | **고침**: DECISIONS 기록 |
| 다중 어르신 시나리오 테스트 없음 | 낮음 | 보류: 형제·다중 어르신은 빌드 1 밖 |

## 앱 코드 (`2026-11-17-app-privacy-flow-code.md`)
| 지적 | 심각도 | 처리 |
|---|---|---|
| 동의 문구가 바뀌었는데 앱이 버전을 안 보냄 | 높음 | 앱 B단계에서 고침(문구 버전 상수 전달) |
| fakeApi는 미동의 저장 허용, 실서버는 거부 → 우회 분기 미검증 | 중간 | 앱 B단계에서 고침(fake를 서버와 같게) |
| 설정 입구가 흐린 작은 링크, 철회 확인에 취소 없음, 자녀 홈 오류 시 받은 답 버림 | 중간 | 앱 B단계(입구·취소), E단계(시각 위계) |
| 오류를 삼키는 곳 3곳, parents[0]만 표시 | 낮음 | 앱 B단계(오류 처리), 다중 어르신은 보류 |
| 과한 것: UI 없는 setParentTitle, fake 옵션 겹침, 이중 구조 | 낮음 | setParentTitle은 C단계 호칭 화면에서 쓰므로 유지, 나머지 정리 |
