# 시안 v15 독립 검토 (시니어 프로덕트 디자이너 + UX 라이터) · 2026-11-17
대상: `docs/design/v3` 새 시트 12개 + 고친 시트. 근거: DECISIONS 마지막 항목들, copy-v3-confirmed 1~9절, tokens-v3, third-party-login/GUIDELINES, reviews/2026-11-17-design-session-review.
렌더: Playwright(Chromium)로 새 시트 12개 전부 + P4·P5·P8·C4·P2·C2·P14를 1800폭으로 직접 찍어 확인(support.js 없이 렌더, 이미지 일부는 자리표시). 5폭×3배율 측정은 리드 sweep 결과를 따름. 검토만, 시안·코드 수정 없음.
**종합: 조건부 승인.** 아래 높음 4건을 고치면 승인. 리드 sweep의 '실패 0'에도 눈에 보이는 겹침이 1건 있어 자동 측정만으로는 부족함.

## 높음 (출시 전 반드시)
1. **P6_keyboard · 연결 끊김 보드: '오늘은 넘어갈게요' 링크가 '한 글자 이상…' 줄과 겹쳐 글자가 잘림.** 배너 한 줄이 들어오면서 본문 높이가 부족. 끊김 배너가 있는 보드에서도 링크·이유 줄 간격 24 이상을 지키고, sweep 측정에 '요소 겹침(교차 사각형)'을 추가.
2. **P5_question · 저장 실패: 고른 카드('봄') 테두리가 빨강으로 바뀜.** 어르신에게는 '틀린 답'으로 읽힘(P6의 '틀림 표시 0' 원칙과 충돌). 고른 카드는 선택 상태 그대로 두고, 빨강은 아래 오류 상자에만.
3. **C7_settings_v2 · 로그아웃 확인 '다시 로그인하면 지금 가족과 그대로 이어져요'는 사실과 다를 수 있음.** 계정 자동 합치기 금지(DECISIONS)라 카카오로 들어온 사람이 구글로 다시 로그인하면 다른 계정. → '같은 방법(카카오)으로 다시 로그인하면 …'(확정문 10절).
4. **어르신 상단 바 모양 불일치.** P4·P5·PX_read_aloud는 '← 오늘 코스'(긴 화살표, 제목이 같은 줄), P6_keyboard·copy 8절은 '‹ 오늘 코스'. 인벤토리는 고쳤다고 적었으나 렌더는 ←. 공용 상단 바 하나(‹, 64, 제목 아랫줄)로 맞추기.

## 중간
- **해님 규칙 위반(DECISIONS Gemini 권고: 말은 첫 만남·완료·오류만, 하트 금지):** P3 말풍선 '둘 남았어요'(평소 화면에서 말함), P7 완료 해님 옆 하트, P8 응원 해님이 하트를 듦. → P3는 말풍선 없이 단계 행 위 글자 한 줄, P7·P8 하트 제거(빌드 1 범위 '볼터치 제거만'과 묶어 에셋 교체).
- **C3_wait 만료 보드:** 위험색(빨강) 상자는 사용자 잘못처럼 보임 → 안내색(noticeSoft)+시계 아이콘. 제목 '부모님 폰에서 번호를 쓰면 연결돼요'가 만료 상태에도 그대로라 모순 → 만료 시 제목 숨김. 제목 문구도 3절 확정('{호칭} 폰에서 … 이어져요')과 다르고, 샘플이 '{호칭}' 대신 '부모님' 고정.
- **C3 '새 번호 받기' ↔ C2·C4·P14 '번호 만들기'.** 자녀는 번호를 '만드는' 사람. '새 번호 만들기'로 통일.
- **C5_history 동의 거부 아이콘이 눈(eye).** '지켜본다'로 읽혀 감시 느낌 완화 원칙과 반대. C4의 같은 상태는 심볼 → C5도 심볼(빈 상태도 C4와 같은 심볼로, 지금은 점선 폴라로이드라 두 탭이 다름).
- **C0_login 상태 누락:** 인증번호 시간 지남·요청이 많음·새 인증번호 보냄(토스트) 보드가 없음(7절 확정 문구는 있음). 150%에서 '…바로 확인해요 · 10분 동안…'의 '·'가 줄 첫머리로 떨어짐 → 두 줄로 나눔.
- **C7_v2 '새 폰 연결 번호 / 부모님이 폰을 바꿨을 때 써요':** 호칭 변수면 '엄마이'가 됨 → '{호칭} 폰을 바꿨을 때 써요'. 알림 행 '연결되면 알려 드려요'는 연결 뒤에는 의미 없음 → 연결 뒤 자녀 알림이 무엇인지 PM 정의 필요(없으면 연결 후 행 숨김).
- **P6 자판 열림 100%에서도 제목·단계 숨김.** 리드 결정은 '150% 이상'만. 100%는 제목 한 줄 유지하거나 결정을 '자판 열림 전부'로 고쳐 기록.
- **P6 '잘 쓰셨어요'**: 칭찬형(copy 원칙 '아이 대하는 말 줄임', DECISIONS '칭찬 금지')과 어긋남 → '낱말을 다 쓰셨어요'(10절).
- **N1_push·C3·C5 상단에 '‹ 이전' 없음.** 탭 루트(C4·C5)와 단계형 안내(N1)는 예외가 맞지만 DECISIONS '첫 화면 제외 모든 화면' 규칙에 예외 목록을 적어야 개발이 헷갈리지 않음(C3은 C2로 돌아갈 길 필요 여부 결정).
- **PX_music 200%:** 날짜 왼쪽, '음악 켜기·설정'은 오른쪽 정렬로 떨어져 시선이 지그재그 → 왼쪽 정렬로 날짜 아래 줄.

## 낮음

- C5 오류 상태만 왼쪽 정렬(빈·거부는 가운데) → 같은 정렬로.
