## 중간
3. **추천 낱말이 조사를 붙이면 칸은 전부 체크인데 시트가 뜸.** "나무가"는 `filledCount`=2(칸 모두 확인 표시)이지만 `isMatch` false → "다 썼어요" 누르면 "한 번 더 볼까요?" 시트(`keyboardMatch.ts:14-27`, `KeyboardStep.tsx:81,100-109`). 화면이 "다 맞음"과 "다시 볼까요"를 동시에 말함(리뷰 B 판정 규칙 빈칸 지적과 같음). → 둘 중 하나로 결정: (a) 앞부분이 낱말 전체와 같으면 일치로 인정, (b) 입력이 더 길면 마지막 칸 체크를 보류. 단위 테스트 추가.
4. **조합 중 칸 체크가 잠깐 사라짐.** "나무"를 두벌식으로 치면 "나"(칸1 체크)→"남"(체크 사라짐)→"나무". 어르신에게 "틀렸다"는 신호로 읽힐 수 있음(`keyboardMatch.ts:18`). → 마지막 입력 음절에 한해 NFD 자모로 목표 음절이 접두면 칸 유지(`'남'.normalize('NFD').startsWith('나'.normalize('NFD'))`). 거꾸로 자동 완료는 전체 문자열이 같을 때만이라 오판 위험은 없음.
5. **일치 뒤 접근성 포커스 이동 없음.** 명세 P6: "자판 닫힘 → 알림 1회 → 포커스 '마치기'". 지금은 포커스된 입력칸이 `display:none`(`KeyboardStep.tsx:180`)이 되어 TalkBack 포커스가 사라짐. → 알림 뒤 마치기 버튼에 `sendAccessibilityEvent(ref,'focus')`(비활성이어도 포커스는 가능, 1.5초 뒤 활성).
