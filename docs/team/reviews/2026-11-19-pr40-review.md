# PR #40 디자인 리뷰 (응원 시트 V14 손잡이 삭제) — 2026-11-19
검토자: 디자인 리뷰어, high. 기준: RULES-V4, tokens-v4.json, UX 깊이 회의 SUMMARY (d) 응원 시트 행. Chrome headless로 3보드(360×640 100%, 320×640 200%, 360×800) 직접 렌더.

## 판정: 승인 (H·M 없음, L 1)

## 확인
- 회의 (d)표 '끌리지 않는 손잡이 막대 → 삭제(V14)' 반영: 세 보드 모두 막대 없음, 닫기 X(48×48 알약) 유지, 끌어서 닫기 없음. '왜' 표의 나머지 행(hint '하나를 누르면 바로 보내요' 유지, 문장 4개 유지, 닫기 X 유지)도 시안과 일치.
- 320·200%: 시트 안 스크롤 + 아래 화살표 띠(R-19), 첫 선택지가 첫 화면에 보이고 둘째는 일부만 보임. 선택지 글자는 bodyLg 상한 2.0이 의도라는 주석은 tokens와 일치(R-11). 시트 제목 heading도 2.0.
- 색: inkTitle·inkBody·inkSub·action·line, card 면만 사용 → allowed 안. placeholder·장식 색 없음. 700 역할은 시트 제목 1개.
- 시트 막대 삭제 후 머리 영역 간격 어색함 없음(100%).

## L
1. 200%에서 시트 머리(제목 두 줄 + 보조 두 줄)가 시트 높이의 약 절반을 쓰고 선택지는 첫 항목이 한 줄 3행으로 커서 한 번에 한 항목만 보인다. 제품 영향은 크지 않으나, 보조 문장을 스크롤 영역 안으로 넣으면 선택지가 한 칸 더 보인다(선택 사항, 이 PR 범위 밖).

오너 피드백: 시트에서 가짜 신호(끌리지 않는 막대)가 없어져 '잘림·헛동작' 문제는 개선. 단조로움·뒤로 링크와는 무관한 변경.
