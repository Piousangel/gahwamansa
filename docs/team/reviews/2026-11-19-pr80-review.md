# PR #80 디자인 리뷰 (P7 완료 앨범 물건) — 2026-11-19
검토자: 디자인 리뷰어, high. 기준: docs/design/IDENTITY-REVIEW.md 방법 1, RULES-V4, tokens-v4, ease-and-joy C절(칭찬·연속 보상 금지), frontend-design 점검표. P7_album_ds4를 Chrome headless로 직접 렌더(4보드). 도장 연출 타이밍은 정적 시안이라 직접 확인하지 못했다(PR 주장만).

## 판정: 조건부 승인 (H 없음, M 2, L 3)

## M
1. **사진에 'AI가 만든 그림' 표기가 없다.** P4(#81)는 표기를 사진 안 칩으로 유지하는데 P7 사진 마운트에는 어떤 표기도 없다. 같은 앱의 같은 종류 이미지라 AI 표기가 일관되지 않으면 표시 의무·신뢰(P4에서 지킨 규칙)와 충돌한다. 칩을 마운트 아래 여백 또는 사진 안 모서리에 두고 R-18(어르신 글자 20 이상)을 지킬 것. 칩이 도장·테이프와 겹치지 않게 위치를 정해야 한다.
2. **도장 연출 순서를 정적 시안으로 보증할 수 없다.** 본문은 '사진·테이프가 먼저, 도장이 마지막'(기존 300ms 이상 페이드, 동작 줄이기 즉시)이라 했지만 보드는 최종 상태 한 장뿐이다. 구현이 쓸 타이밍 표(사진 t=0, 테이프 t=?, 도장 t=?; 동작 줄이기에서는 모두 즉시)를 시안 주석에 숫자로 적고 기존 P7_motion 값과 동일함을 명시할 것(motion.elderForbidden에 어긋나는 새 모션이 없는지 확인).

## L
1. 칭찬·보상 읽힘: 큰 도장·마운트·테이프는 사실(오늘 찍힘)을 장식한 것이고 문구는 '오늘 코스를 마쳤어요'·'오늘 첫 도장을 찍었어요'·'도장을 찍었어요. 내일 또 만나요' 그대로라 칭찬어('잘했어요'·'대단해요')·점수·연속일이 없다. 다만 이번 주 도장 줄(7칸 중 오늘까지 채움)은 개수가 늘어나는 표현이라 연속 보상으로 읽힐 수 있다(기존 요소·변경 없음). 큰 도장 주변 번짐 원(연한 테라코타)이 '축하 효과'처럼 보이지 않게 투명도를 낮추는 것을 권한다.
2. 200%: 사진·큰 도장·제목이 첫 화면에, 도장 줄·보조 문장은 줄 경계 아래로 밀리고 더 있음 띠가 영역 밖(R-15·R-19 충족, 잘림·겹침 없음). 주 버튼 '알겠어요'는 Dock에 온전히 보임.
3. 색·R-01~R-20: 글자는 inkTitle·inkBody만, 도장 #C44F2E·#EE6640은 장식(글자 위에 안 놓임), 갈색은 주 버튼에만, 700 역할 2개 이하. frontend-design 점검(대담함 한 곳, 카드 반복 없음)은 타당: 이 보드에서 장식이 P7 한 곳에 몰려 위계가 분명하다. 새 문구 없음.

## 오너 피드백 개선 여부
- 단조로움: 개선(사진 + 도장 한 장이 주인공, 위계 분명). 잘림: 100%·200% 모두 잘림·겹침 없음. 작은 뒤로 링크: P7은 BackLink가 없는 종료 화면이라 해당 없음.

## 재확인 (08db7e1)
- 직접 재렌더(4보드). M1 해소: 마운트 아래 캡션 'AI가 만든 그림'이 있고 글자 크기 20 이상(주석 'sub 20/30 이상', 렌더 100%에서도 읽힘), 도장·테이프와 겹치지 않는다. 캡션은 살짝 기울어져 있으나 가독성에 지장 없음.
- M2 해소: 시안 주석에 ms 타이밍 표가 들어갔다(0ms 열림, 300ms 사진·테이프 페이드 300ms, 300ms 도장 시작 180ms 곡선, 번짐 원 520ms, 700ms 본문 둘째 줄 300ms 페이드, 동작 줄이기 즉시). 기존 '300ms 이상 페이드' 규정과 일치.
- L1 해소: 번짐 원 투명도 .10.
- 신규 L: 200%에서 캡션이 두 줄이 되어 마운트가 커지고 제목 '오늘 코스를 마쳤어요'가 첫 화면 밖으로 밀렸다(스크롤로 닿음·잘림 없음이라 허용). 완료 문구가 첫 화면에 보이면 더 좋으므로 200%에서 캡션을 사진 안 모서리 칩으로 옮기거나 마운트를 줄이는 것을 선택 사항으로 권고.
- 재확인 판정: **승인**(H·M 없음).
