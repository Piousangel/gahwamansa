# PR #92 디자인 리뷰 (응원 시트 아이콘 4종 + C4 이야기 꺼내기 예시 모양) — 2026-11-19
검토자: 디자인 리뷰어, medium. 기준: design-system/assets/icons README 문법(24 viewBox·선 2.5·round·currentColor·안전영역 2), RULES-V4(R-01~R-20), tokens-v4. 4개 SVG와 기존 아이콘(bell·photo·cheer·family·chat·home)을 96·40·24px로 나란히 렌더해 비교했고, C3_C4_P8_ds4의 C4 확정 보드를 직접 렌더했다. 크리에이티브 디렉션 6안은 아직 오너 선택 전이라 이 결과는 현재 정체성 기준이며, 방향이 바뀌면 아이콘 스타일(획 두께·둥근 정도)도 바뀔 수 있다.

## 판정: 승인 (H 없음, M 0, L 4)

## 아이콘
- **획·격자**: 4종 모두 viewBox 24, stroke-width 2.5, round cap/join, fill none, currentColor, role=img + title/aria-label로 기존 아이콘 문법과 같다. 안전영역 2 안(해 광선 y 3~21, 찻잔 김 y 3, 쪽지 x 6~18)이다. 속성 grep으로 기존 bell·photo·home과 같은 stroke-width 2.5 확인.
- **시각 무게(렌더 비교)**: 해·찻잔·쪽지는 기존 bell·photo·home과 같은 굵기로 읽힌다. 새싹은 차지하는 면적이 작아(x 6~18, y 6~20) 24px에서 다른 아이콘보다 가볍다. 해도 광선이 짧아 가볍다.
- **비텍스트 대비 3:1**: 선색이 currentColor이므로 action(#744821)이면 card 7.80·paper 7.05로 3:1 충족(contrast-v4 nonText allowed의 action on paper·card). 옅은 면(paperSoft·noticeSoft) 위에서도 action 3:1 이상. 선택 상태 actionSoft 위에서도 6.03.
- **200%**: 벡터라 확대해도 선명하고 선이 아이콘 크기에 비례해 굵어진다(96px 렌더에서 선·끝이 깨지지 않음). Choice 200%에서는 아이콘 크기를 함께 키울지 고정할지 시안에 한 줄 필요(글자만 커지면 상대적으로 작아 보임).
- **의미 읽힘**: 해(사랑해요, 오늘도 좋은 하루)·찻잔(덕분에 하루가 따뜻해요)·쪽지(오늘도 편안한 하루 보내세요)는 문장과 연결이 쉽다. 새싹(늘 고마워요)은 '자란다/성장'이라 연결이 약하다. 아이콘 옆에 글자가 항상 있어 오독 위험은 낮다.

## 예시 모양(C4 이야기 꺼내기)
- 예시 카드는 점선 테두리 + 연한 면 + '예시' 칩으로 실제 답 카드(실선·흰 카드)와 구분된다. 100% 렌더에서 구분이 보인다. 읽기 이름도 '예시, 이야기 꺼내기, …'로 시작해 스크린리더 혼동을 막는다.

## L
1. 'a 아이콘만' 분류가 틀렸다. README 표와 SVG 주석이 'a 아이콘만(곁에 글자가 있음)'이라고 적지만 곁에 글자가 있으면 정의상 'b 아이콘+글자'이다(새싹·쪽지는 단독으로 의미가 안 읽힘). 'b'로 고치고 어르신 화면 단독 사용 금지를 비고에 적을 것.
2. 예시 칩 글자가 100%에서 작게 보인다(약 13~14). 자녀 화면 하한 16(R-18) 미달 소지. 칩은 16 이상으로.
3. 예시 카드 제목이 실제 카드와 같은 '부모님의 최근 답'이다. 점선·칩으로 구분되나, 같은 제목은 '이미 왔다'로 읽힐 수 있어 제목도 '답이 오면 이렇게 보여요'처럼 다르게 하거나 칩을 제목 줄에 두는 것을 권한다(문구라 라이터 확인). 날짜는 PR #89에서 정리 예정이라고 했으므로 그쪽에서 확인.
4. 라이선스·출처: 4종 SVG는 도형(circle·path)을 직접 그린 것으로 보이고 외부 자산을 가져온 흔적(외부 속성·메타·고유 path 해시)이 없다. 다만 README에 '자체 제작, 외부 아이콘 세트 미사용' 한 줄이 없다. 한 줄 추가를 권한다(출처 표기 요구 없음).

## 확인 완료
- 하트·이모지 금지(Q5): 사물 4종만, 하트 없음. 색은 currentColor라 갈색 = 누르는 것(Choice 행) 규칙과 합치(R-06).
- 아이콘은 장식이 아니라 Choice 행의 보조라 role=img + 이름이 있고 행의 읽기 이름은 문장이다.
- 일반 틀: 크리에이티브 디렉션 6안 중 어느 방향이 되면 획 두께·모서리 반경이 바뀔 수 있으므로 이 4종은 현 정체성(선 2.5·round) 기준의 임시 자산이다. 방향이 정해지면 한 번에 재생성할 수 있게 '선 두께·반경만 바꾸면 되는 구조'(path에 하드코딩 없음)인지 같이 점검할 것.
