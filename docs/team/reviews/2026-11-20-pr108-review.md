## 확인한 것(요청 항목별)

- **타이밍(시안 12줄과 대조): 같다.** `P7_T = {mountFade 300, stampAt 300, land 180, squash 70, inkAt 520, ink 420, textAt 700, text 300}`.

  | 시각 | 시안 | 구현 |
  |---|---|---|
  | 0~300ms | 사진 마운트·테이프 페이드 | 같음 |
  | 300ms | 도장 scale 1.3→1, 180ms, 곡선 `.3,0,.8,.15` | 같음. 도장 opacity도 같은 180ms로 0→1(그 전에 1.3배로 보이지 않게). 시안에 없는 값이지만 타당하다 |
  | 480ms | 닿음 + 눌림 scaleY .94 70ms 뒤 복원, 곡선 `.2,.8,.2,1` | 같음. 촉각·소리 1회는 애니메이션 콜백이 아니라 타이머라 프레임이 밀려도 닿는 때와 맞다 |
  | 520ms | 번짐 원 opacity .10→0, scale .9→1.15, 420ms | 같음 |
  | 700ms | 둘째 줄 300ms 페이드 | 같음 |

  모두 opacity·scale만 쓰고 네이티브 드라이버로 돌린다. 점멸·흔들기는 없다.
- **동작 줄이기: 모두 즉시다.**
  - `mode === 'reduce'`(동작 줄이기 또는 화면 읽기 켜짐, `useMotionMode`)이면 마운트·도장·둘째 줄을 끝 값으로 놓는다. 번짐 원은 그리지 않는다(`ink` 없음).
  - 소리·촉각은 유지한다(시안 "도장·번짐·페이드 없음"과 맞음).
  - 판정 전(`mode === null`) 첫 프레임에는 아무 연출도 시작하지 않는다. jest `p7Motion`이 확인한다.
- **도중에 뒤로 가거나 화면을 벗어날 때: 정리된다.**
  - 언마운트하면 `alive=false`, 타이머 전부 `clearTimeout`, 애니메이션 전부 `stop()`을 한다.
  - `start` 콜백은 `alive`일 때만 상태를 바꾼다. 뒤로가기(`useBackAction` → `popTo('CourseHome')`)와 '알겠어요'는 같은 경로다.
  - 테스트 "연출 중 떠나도 촉각·소리가 뒤늦게 울리지 않는다"가 있다.
  - 끝(또는 중간에 멈춤)이면 모든 값을 끝 상태로 맞춰, 둘째 줄이 투명으로 남지 않는다.
- **화면 읽기 순서와 연출 중 포커스**
  - 사진·테이프·도장·번짐은 숨긴다. 읽히는 순서는 캡션('AI가 만든 그림 / 실제 장소가 아니에요') → 제목(heading) → 도장 줄(찍은 요일만 한 번) → 둘째 줄(live region)이다.
  - 화면 읽기가 켜지면 reduce라 연출이 없고, 둘째 줄은 이번 주 도장을 받아 생길 때 한 번 읽힌다. 연출 중에 포커스를 옮기지 않는다.
  - 다만 첫 포커스가 제목이 아니라 캡션이 된다(L1).
- **새 토큰: 대비 표와 생성기를 통과한다.**
  - `node scripts/gen-tokens-v4.js --check`: "같음"이다. `tokensV4.test`(생성물 일치·허용 짝 대비)도 통과한다.
  - `contrast-v4.py`를 사본에서 다시 돌렸더니 원본 JSON과 차이가 0이었다(표 갱신 누락 없음).
  - `brandSeal`(#EE6A44)·`brandSealGlyph`(#FFFAF3)는 "장식 전용, 글자 바탕 금지"로 역할을 적었고, 글자 역할 허용 짝에는 들어가지 않는다.
  - 참고: 획과 면의 대비는 약 3.0:1이다. 장식이라 기준 밖이지만, 나중에 글자 바탕으로 쓰지 않게 역할 문구를 유지해야 한다.
- **`SHOW_WEEK_STRIP` 끄기: 깔끔하게 빠진다.**
  - `false`면 `strip`이 null이라 본문 묶음이 3개(마운트·제목·둘째 줄)가 된다. `useFoldGap(items.length, …, from 1)`이 개수를 따라간다.
  - 둘째 줄 문구(첫 도장 판정)는 이번 주 도장 데이터에서 계산하므로 줄을 빼도 그대로다. 다른 곳에서 이 줄을 참조하지 않는다.
  - 상수라서 꺼진 상태는 테스트로 고정돼 있지 않다(L3).
- **200%**: 마운트 272, 사진 96, 도장은 캡션 위(top -2)로 #95와 같다. 접힘에 걸치면 도장 줄을 통째로 미는 테스트가 있다.
- **#85 L1**: 개발자 메뉴를 닫을 때 `who`를 비운다. 한 줄이고 문제없다.
