## 중간

### M1. 미연결 어르신은 여전히 '뒤로 두 번'에 기기 도장이 지워진다(`ConnectScreen.tsx:68`, `AppRoot.tsx:133-138`)
- 이번 수정은 **연결된** 어르신만 고친다(번호 확인 뒤 `[Consent]`로 reset).
- 미연결 흐름은 다음과 같다:
  1. 역할 선택 → 시작 `Connect`(뿌리)
  2. '코스 보기'로 `navigate('CourseHome')` → 스택 `[Connect, CourseHome]`
  3. 미리보기 코스를 하면 도장이 기기(`localStamps`)에 찍힌다
  4. 코스 홈에서 뒤로 → `Connect`
  5. 한 번 더 뒤로 → `resetRole()` → `localStamps().clear()`
- 확인 없이 미연결 도장이 사라진다. 이번 버그와 같은 종류다. 미연결 도장은 그 사람의 유일한 기록이다.
- 고칠 방향(둘 중 하나):
  - 뒤로가기의 `resetRole`은 역할만 되돌리고 도장은 지우지 않게 한다. 지우기는 '모두 지우기'(`clear`)에만 둔다.
  - 또는 미연결 기기도 코스 홈을 뿌리로 둔다(번호 화면은 띠에서 push).
- jest에 "미연결: 코스 홈 → 뒤로 → 뒤로 뒤에도 기기 도장 유지"를 추가한다.

## 의도한 변경 확인(H1과 별개로 코드는 타당)

- **번호 확인 뒤 reset의 진입 경로별 확인**

  | 경로 | 결과 |
  |---|---|
  | 첫 연결·재연결(새 폰) | `ConnectScreen` 번호 확인 → `reset([Consent])` → 동의·거절 모두 `replace('CourseHome')`. 코스 홈이 뿌리라 뒤로 = 앱 나감 |
  | 동의 거절 | 같은 `replace('CourseHome')` |
  | 이미 동의한 상태 | `Consent`가 확인 뒤 바로 `replace` |
  | 앱 재시작 | `whoAmI === 'parent'`면 시작 `CourseHome`(뿌리) |
  | 딥링크 /c | 시작 화면 미리 채움만(`prefill`) 한다. 코스 홈에서 띠로 열면 `push('Connect', {from:'course'})`, 뒤로 = `goBack` |
  | 알림으로 열기 | `PushHost`가 `navRef.reset([CourseHome])` |

- **`resetRole` 호출처(grep)**:
  - `ChildLogin`(뒤로·바), `ConnectScreen`(뿌리일 때 뒤로, 역할 불일치 오류 L265), `ChildSettings`(로그아웃), `RelationScreen`·`ChildGate`(뒤로·막힘 버튼).
  - 어르신에게 해당하는 곳은 `ConnectScreen` 두 곳뿐이다. 연결된 어르신은 이제 `Connect`가 뿌리로 남지 않는다. 남는 문제는 M1(미연결)이다.
- **기기 데이터를 지우는 경로 전체**
  - `localStamps().clear()`: `resetRole`·`clear`(모두 지우기)·개발자 메뉴.
  - `clearAccountKeys`: 계정 삭제·자녀 로그아웃.
  - `clearDevSessions`: 개발 빌드만.
  - 이 밖에 prefs 첫 인사, 푸시 토큰, 자녀 약관 대기가 있다.
  - 사용자가 모르게 데이터가 지워지는 경로는 M1뿐이다.
- **ListRow 읽기와 누름 영역**
  - `onPress`가 있으면 행 전체가 버튼(role button)이다. 읽기 라벨은 호출부가 보이는 글과 같게 준다('사진 보기, 지금 할 차례' / '…, 했어요' + 힌트 '다시 보기'). 누르지 않는 행은 `accessible` View 하나로 읽힌다.
  - 최소 높이는 어르신 64(`minTouch`)이고 높이는 `minHeight`만 쓴다.
  - 누름 상태는 면 색만 바꾸고 테두리 두께는 그대로라, 눌러도 배치가 움직이지 않는다.
- **'다시 보기'(완료 전에도 누를 수 있음)와 측정 이벤트: 남지 않는다.**
  - `review: true`로 열리면 `useStepStarted(…, review)`가 보내지 않고, 크게 보기도 보기 전용이면 계측하지 않는다.
  - 완료 전 다시 보기도 같다. "보기 전용은 계측 0"(리드 결정, P4 M2)과 같다.
  - 다시 보기 횟수를 보고 싶으면 별도 이름이 필요하다(지금은 없음, 결정 사항).
- **200% 행 단위 접힘**: 단계 행 3개, 띠, 인사, 도장 줄, 기록 링크가 `FoldBody`(`useFoldGap`)의 각각 한 요소다. 걸치는 행만 통째로 민다.
- **날짜와 설정 고정**
  - 날짜 줄(heading)과 '설정'은 `DsScreen` 위 영역(`header`)이라 본문 스크롤에 따라가지 않는다.
  - 날짜는 렌더마다 `kstDateLine()`으로 다시 계산한다. 자정을 넘겨 화면이 그대로면 다음 렌더 전까지 어제 날짜가 남는다(기존 동작과 같음).
- **#108 L1~L3**: 반영됐다.
  - L1: 제목으로 `focusLater`.
  - L2: 마운트·도장은 `mode`만 정해지면 시작하고, 둘째 줄만 응답과 700ms 중 늦은 때 페이드한다.
  - L3: `showWeekStrip()`을 테스트할 수 있다.
- **Dock 주 슬롯 secondary·buttonRef**: '다 마친 뒤 다시 보기'를 보조 모양으로 둔다(시안 ds4b 3/3). 돌아오면 그 버튼으로 포커스가 돌아온다(D-10). 다른 Dock 사용처는 선택 props라 영향이 없다.
