## 계약
- **Dismiss**(`ui/ds/dismiss.ts`): `'close'|'later'|{decline}`, 닫기 '닫기'·다음에 '다음에' 고정, 거절은 `안 ○○요` 형식(개발 빌드 경고). `DISMISS_TEXT` 와 문구 파일 `dismiss` 가 같은지는 `backDestination.test` 가 지킴(ui 는 copy 를 모르는 구조 유지).
- **Sheet X '닫기' 고정**: `closeLabel` prop 제거, 라벨은 `dismissLabel('close')`. 호출부 3곳이 넘기던 값(`child.cheer.close`·`title_sheet.close`·`family.stop_sheet.close`)이 모두 '닫기'라 읽기 변화 없음.
- **BackLink `to` 필수**: 타입으로 강제 + 개발 빌드에서 '이전·뒤로'·'…로' 아닌 값 경고. 호출부 7곳(코스 단계 3·자녀 로그인 3·호칭·게이트) 모두 `to` 로 교체됨.
- **copyBan 버튼 키 규칙**: close/later/cancel/거절 키와 값이 어긋나면 실패, '닫기'는 close·cancel·keep 키에만, '다음에'는 later 키에만 — 현재 문구 파일 전체가 통과. 예외 `consent.decline` 은 법률 확인 뒤 바꾼다고 명시.

## 목적지 문구가 실제 이동 대상과 맞는지
- **자동 목적지**(`<BackBar />`, onBack 없음)는 `backDestination(navigation.getState())` 로 스택 바로 아래 화면 이름을 쓰므로 `goBack` 이 가는 곳과 구조적으로 일치(Oss·Web·HistoryDay·ParentFamily·Consent·ParentSettings·DeleteAccount·ChildAppInfo·FamilyPreview·ChildCode·ChildSettings). 탭 위 화면은 보던 탭 이름, 아래 화면이 없거나 표에 없으면 null → 바가 숨음(이전으로 돌아가지 않음).
- **onBack 이 스택 밖으로 가는 곳**은 모두 목적지를 직접 줌: 코스 단계·기록은 `course`/`to=오늘 코스로`(toCourseHome 일치), Connect 는 `fromCourse ? 오늘 코스로 : 처음으로(resetRole)`, 실패 화면 redeem 단계 `other`·확인 화면 `onOther` 는 '번호 쓰기로'(같은 Connect), 자녀 로그인은 처음으로(resetRole)·`로그인으로`(goBack)·`이메일 주소로`(goBack)가 `nav.to` 값과 같음. 라벨 표(BACK_TO)는 `RouteName` 이 두 스택의 route 키 전체를 요구해 빠뜨리면 타입 오류.
- `copyNames` 테스트가 `nav.to.CourseHome = 오늘 코스로 = course.title` 및 '처음으로'는 첫 화면 이동 키에만(`nav.to.Gate`·`DeleteDone` 허용 목록)을 확인, `nav.to` 27개는 전부 '…로'이고 '이전'·'뒤로' 없음(copyBan).
- **L1** `Wait: '기다리는 화면으로'`·`Code: '번호로'` 는 다른 항목보다 목적지 이름이 어색하고 `copyNames` 가 화면 제목과 대조하지 않는 키라 NAMES.md(docs/design/NAMES.md)와 한 번 맞춰 볼 것.
- **L2** 아래 화면이 표에 없거나 스택이 한 장이면 `canGoBack()` 이 참이어도 뒤로 바가 숨음. 지금은 모든 route 가 표에 있어 영향 없으나 새 화면을 더할 때 `RouteName` 타입이 막아 주는지 의존.
