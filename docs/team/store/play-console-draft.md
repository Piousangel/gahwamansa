## 8. 앱 액세스(심사용) [팀 결정: A안 채택 — DECISIONS "정책 문서 v2 관련 리드 결정", 서버 0027 예정]
기준(policy.md 7.4에서 확인): https://support.google.com/googleplay/android-developer/answer/15748846 — 재사용 가능한 자격 증명, 2단계·일회용 코드 피하기, 영어.

**채택 A: 심사 전용 가족 + 만료 없는 재사용 번호.** 부모님 경로는 원래 1회용·7일 만료 번호라 심사자가 들어갈 수 없어서. (기각: B 설명만=거절 위험, C 심사자가 번호 직접 발급=한 기기 한 역할 규칙·재설치로 따라 하기 어려움)

0027 보안 요구(서버 담당에게 전달):
- 번호는 **기본 꺼짐**, 운영자가 심사 제출 때만 켜고 심사 끝나면 끔
- **연결 수 상한**(제안: 심사 가족에 붙는 부모님 프로필 최대 5개, 넘으면 거절) — 번호가 새도 피해 범위 제한
- 심사 종료 뒤 심사 가족에 붙은 부모님 프로필·답 정리(운영자 실행)
- 일반 6자리 번호와 겹치지 않는 값, 시도 제한은 일반 번호와 같게
- 심사 가족에 자녀 2명(심사용 구글 계정 + 운영자 계정)을 두어 심사자가 계정을 지워도 가족 전체가 지워지지 않게
- 실제 번호·계정 값은 비밀: 콘솔 입력칸에만, 저장소·문서에 쓰지 않음

자녀 경로: **구글 심사용 계정**(2단계 인증 끔, [사용자] U-5) 제공. 카카오 테스트 계정은 카카오 개발자 팀원 등록 필요 가능성(**불확실**)이라 구글로 안내. 이메일 인증번호는 일회용 코드라 심사 경로로 쓰지 않음.

콘솔 입력 문구(영어, A안 기준):
```
This app has two roles: Parent and Child (adult child of the parent).

Child (Google sign-in):
1. Open the app and tap "자녀 휴대폰이에요" (This is the child's phone).
2. Tap the Google sign-in button and use: [USER: review Google account] / [USER: password]. 2-step verification is off.
3. A review family is already set up, so you will see the album home.

Parent (no sign-up, uses a 6-digit code):
1. On a different device (or after clearing app data), open the app and tap "부모님 휴대폰이에요" (This is the parent's phone).
2. Enter the code [USER: fixed review code]. It does not expire during review.
3. On the consent screen tap "좋아요" (Agree), then start today's course: photo -> choose one -> type a word.

Account deletion: Parent: 설정 (Settings) > 모두 지우기. Child: 설정 > 내 계정 지우기. Web: [USER: delete URL].
All features are free. No payment is required.
```
- "A review family is already set up": 심사용 구글 계정을 심사 가족의 자녀로 미리 연결해 둬야 함(사용자가 prod에서 1회, 0027 반영 뒤)
- "type a word"는 P6 자판으로 쓰기 구현 전이면 지움(§3 대조 표와 같이)
