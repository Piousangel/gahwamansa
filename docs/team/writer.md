# UX 라이팅·콘텐츠 가이드 (writer)

작성일 2026-11-16 · 대상: 어르신 앱 문구, 자녀 앱 문구, 30일 콘텐츠, 스토어 문구

## 0. 가정 (질문 없이 정한 것)
- 어르신 호칭은 기본 "어르신", 자녀 화면의 부모 호칭은 앱 변수 `{호칭}`(엄마, 아빠 등)으로 둔다. 아래 자녀 문구는 "엄마"로 예시.
- 동의 범위는 "고른 답"(밸런스 선택)만 공개로 가정한다. 글씨 쓴 기록·접속 여부 공개 여부는 확정이 아니다(사용자 결정 1).
- 해님은 인사·칭찬·안내에만 말한다. 사진 설명과 질문은 해님 말풍선 안에서 읽는다.
- 모든 어르신 문구는 TTS(음성 읽어주기)로 읽히므로 한자어·영어·기호를 피한다.

## 1. 말투 가이드

### 1-1. 해님의 말투 원칙
1. 해요체로 말한다. "~해요", "~해 볼까요?". 반말 금지, "~하십시오" 같은 딱딱한 말도 금지.
2. 한 문장에 한 가지만 말한다. 한 화면에 해님 문장은 3개 이하.
3. 시키지 않고 권한다. "누르세요" 대신 "눌러 볼까요?"
4. 칭찬은 결과가 아닌 한 일에 한다. "맞혔어요"보다 "오늘도 오셨네요".
5. 정답이 없다고 먼저 알린다. 밸런스 질문은 "정답은 없어요".
6. 해님은 자기를 "저"라고 부르고, 어르신을 "어르신"이라 부른다. 이름·나이를 묻지 않는다.
7. 놀라게 하거나 재촉하는 말 금지. "빨리", "벌써", "아직", 느낌표 연속 금지.
8. 사용자를 탓하지 않는다. 오류는 "앱이 못 알아봤어요"처럼 앱이 주어가 된다.

### 1-2. 어르신 화면 문구 규칙
| 항목 | 규칙 |
|---|---|
| 글자 크기 | 본문 20sp 이상(SPEC 7-6). 문구는 이보다 크게 써도 줄이 넘치지 않는 길이로 쓴다 |
| 문장 길이 | 한 문장 20자 안팎, 최대 30자. 질문은 최대 35자(2줄) |
| 한 화면 문장 | 안내 3문장 이하, 버튼 3개 이하 |
| 버튼 | 2~6자. 동사로 끝낸다. "다음", "시작하기", "다시 해 볼게요" |
| 존댓말 | 해요체. "~시겠어요?"는 쓰되 "~하시기 바랍니다"는 금지 |
| 낱말 | 쉬운 우리말. "인증번호"→"번호", "로그인"→"들어가기", "알림"→"소식", "네트워크"→"인터넷" |
| 숫자 | 6자리 번호는 3자리씩 띄워 보여 준다(예: 482 915). 큰 숫자 칸 6개 |
| 틀려도 괜찮다는 표현 | 글자 따라 쓰기·번호 입력 모두 "틀려도 괜찮아요"를 1회 이상 안내. 틀림·실패 단어 사용 금지 |
| 선택지 | 정답 느낌 표시 금지(체크·불꽃 효과는 선택했다는 표시로만). "정답", "오답" 단어 금지 |

### 1-3. 자녀 화면 문구 규칙
- 해요체 + 짧은 설명. 어르신 화면보다 정보를 더 써도 되지만 한 문장 40자 이내.
- 부모를 평가하는 말 금지. "참여율 낮음", "미완료" 대신 "오늘은 쉬셨어요".
- 리포트는 사실 + 대화 제안 순서. "엄마는 오늘 가을을 골랐어요. 가을 이야기를 해 볼까요?"
- 부모에게 부담을 주는 독촉 문구 금지("왜 안 하세요?"). 응원은 고정 문구 중 선택만 가능.
- "곧 유료" 표시는 작은 배지로만 쓰고 협박·압박 문구 금지. 무료 기간에는 "지금은 무료로 볼 수 있어요".
- 의료 효능 단정 금지. "두뇌 활동", "기억 떠올리기"만.

## 2. 30일 콘텐츠 표

- 사진은 AI 생성 예정이므로 장면은 풍경·사물 중심, 인물은 작게·뒷모습·멀리 두는 것을 전제로 한다.
- 단어는 사진 속 사물. 괄호는 받침 난이도(쉬움·보통·어려움)와 받침 글자.
- 밸런스 선택지는 "A 선택지 / B 선택지 — 보조 문구" 형식. 보조 문구는 질문에 이어 해님이 읽는다.
- 자녀 소재는 `{호칭}` 자리에 엄마·아빠가 들어간다.
- 구체적 연도, 물가, 제품은 쓰지 않았다. 장면 사실 확인은 AI 사진 큐레이터 단계에서 검수.
- 회상 질문 칸은 콘텐츠 시드(`supabase/seed_content_14d.sql`·`seed_content_30d.sql`)와 같다(2026-11-25 동기, 시드가 정본). 일차는 원본 번호라 시드 day_index와 다르니 사진 제목으로 맞춘다. 나머지 칸은 옛 초안이 남아 있다.

## 6. 검수 메모
- 표현 점검: 의료 효능을 단정하는 단어를 문서 전체와 스토어 문구에 쓰지 않았다. "두뇌 활동", "기억 떠올리기"만 사용.
- 장면 점검: 실존 인물·브랜드·정치·종교·질병·죽음·전쟁·가난 강조 소재 없음. 30번만 먼 인물이 있고 나머지는 사물·풍경 중심.
- 중복 점검: 밸런스 30개가 모두 다르고, 음식·계절·노래·나들이·하루 습관·여행으로 분포.
- 중립 점검(2026-11-17 개인화 회의): 질문·선택지·회상 질문·첫마디 문장에 ① 성별에 따른 역할("어머니는 부엌" 류) ② 종교·제사 의례(명절은 음식·모임·놀이로) ③ 직업·학력·빈부를 전제한 표현("농사지을 때", "공장 다닐 때") ④ 특정 지역·사투리 흉내 ⑤ 건강·시력·기억력을 묻거나 평가하는 말이 없을 것. 콘텐츠는 성별·나이·고향 같은 개인 속성으로 나누지 않으므로 한 문장이 모든 분께 맞아야 한다.
- 계절 점검: 새 칸을 만들 때 글에 계절을 박을지(`season_cue=text`) 먼저 정한다. 상시 풀은 계절 무관 문장을 기본으로 하고, 계절 문장은 빌드 2 시즌 풀용으로 따로 모은다(docs/team/photo-curator.md 9절).

## 7. 사용자 결정이 필요한 것
1. 동의 공개 범위: 고른 답만인지, 글씨 쓴 기록·접속 여부까지인지.
2. 동의 거부 시 앱 동작: 보기만 되고 답은 저장 안 함 / 시작 불가 중 선택.
3. 어르신 호칭: 항상 "어르신"인지, 자녀가 호칭을 정해 줄지.
4. 사진 설명에 "AI가 만든 그림" 표기를 앱 안에도 넣을지(스토어에는 넣었음).
