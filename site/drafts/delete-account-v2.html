가화만사성 계정·데이터 지우기

앱: 가화만사성 · 개발자: [운영자 입력 필요: Play 스토어에 보이는 개발자 이름과 똑같이] · 시행일 [운영자 입력 필요]

앱을 열 수 있으면 앱에서 지우는 게 가장 빠릅니다. 누르는 순간 바로 지워집니다.
앱을 열 수 없으면 아래 2번처럼 메일로 요청하세요. 앱을 설치하지 않아도 됩니다.

1. 앱에서 지우기

부모님

  1. 코스 홈 위쪽의 설정을 누릅니다.
  2. 모두 지우기를 누릅니다.
  3. "모두 지울까요?"가 나오면 모두 지우기를 한 번 더 누릅니다.

고른 답과 도장이 모두 지워지고, 가족과 연결도 끊깁니다. 자녀 화면에서도 부모님의 답이 사라집니다.

답만 지우고 앱은 계속 쓰고 싶으시면: 설정 → 그만 보여 주기. 지금까지 저장된 답이 지워지고, 앞으로 고른 답은 저장되지 않습니다. 앱은 그대로 쓰실 수 있습니다.

불확실: 메뉴 이름은 확정 문구(copy-v3-confirmed P13·P9) 기준. 출시 빌드 화면과 대조 필요. 확인 단계 수(1번 vs 2번)는 DECISIONS "2단계 확인 유지"와 문구 문서 "확인 한 번" 권장이 엇갈림

자녀

  1. 아래 탭의 설정을 누릅니다. 불확실: 탭 이름(C7)
  2. 계정 지우기를 누릅니다.
  3. 안내를 읽고 계정 지우기를 누릅니다. 가족의 마지막 자녀라면 확인 글자 "지우기"를 써야 합니다.
  • 다른 자녀가 아직 가족에 있으면: 내 계정만 지워집니다. 부모님의 고른 답과 기록은 남아 다른 자녀가 계속 볼 수 있습니다.
  • 내가 마지막 자녀라면: 내 계정과 함께 부모님의 고른 답과 기록이 모두 지워집니다. 부모님 앱은 연결이 풀린 상태가 됩니다.

확실: 서버 delete_my_account가 마지막 자녀면 가족 전체, 아니면 본인만 지움(0017)

2. 앱을 열 수 없을 때: 메일로 요청하기

받는 곳: [운영자 입력 필요: 문의 메일]
제목: [가화만사성] 지우기 요청

메일에 적어 주세요.

  • 요청하시는 분: 부모님 / 자녀
  • 자녀: 로그인 방법(카카오 / 구글 / 이메일 인증번호). 구글·이메일 인증번호는 그 메일 주소에서 보내 주세요. 카카오는 카카오톡 닉네임과 가입한 날짜쯤을 적어 주세요(카카오 이메일은 받지 않아서 메일로는 찾을 수 없습니다).
  • 부모님: 연결된 자녀가 대신 요청해 주시는 게 가장 확실합니다. 자녀가 지우면 됩니다(위 1번). 자녀가 없으시면 휴대폰 기종과 연결했던 대략의 날짜를 적어 주세요. 불확실: 이름·전화번호 없이 쓰는 부모님을 확인할 방법이 아직 없음. 앱 설정에 "확인 번호" 표시 등 방법 결정 필요
  • 지울 범위: 계정 전체 / 고른 답만

본인인지 확인하려고 몇 가지 여쭐 수 있습니다. 주민등록번호, 비밀번호, 인증번호는 보내지 마세요.

받은 뒤 [운영자 입력 필요: 처리 기한, 제안 10일] 안에 지우고, 끝나면 메일로 알려 드립니다.

3. 지워지는 것과 남는 것

정보지우면
로그인 정보(카카오 회원번호·닉네임, 구글 이메일·이름, 인증번호 메일 주소, 부모님 익명 로그인 번호)바로 지움. 같은 카카오·구글 계정으로 다시 들어오면 새 사람으로 처음부터 시작합니다 확실: 0017이 로그인 계정까지 삭제
부모님이 고른 답, 코스 기록(도장)바로 지움(부모님이 지울 때, 또는 마지막 자녀가 지울 때)
응원, 가족 연결 번호, 부르는 말(호칭)바로 지움(가족 전체가 지워질 때). 다른 자녀가 남아 있으면 가족 정보는 남습니다
푸시 알림 토큰바로 지움 확실
이용 기록(글자·답이 없는 기록)그 가족의 기록을 지움 불확실: 구현 전(U14). 제안대로 만들지 결정 필요
오류 기록(Crashlytics, 도입 시)운영자가 따로 지우지 않으며 Google이 90일 뒤 지우기 시작합니다. 사람을 알아볼 정보는 담지 않습니다 불확실: 도입 확정 전
서버 백업하루 한 번 백업을 7일 보관하므로, 최대 7일 뒤 백업에서도 사라집니다
서버 접속 기록(IP 등)Supabase가 정한 기간 뒤 자동 삭제 불확실: 요금제별 기간 확인 필요

법 때문에 따로 남겨 두는 정보는 없습니다. 결제를 받지 않는 무료 앱이기 때문입니다. 불확실: 통신비밀보호법 접속 기록 보관 의무 해당 여부 법률 확인 필요. 해당하면 "접속 기록 3개월" 행을 추가

지운 뒤에는 되살릴 수 없습니다.

불확실(이 줄은 게시 전 결정): 마지막 자녀가 지우면 부모님 휴대폰의 익명 로그인 번호는 서버에 남습니다(부모님 기기의 것이라 자녀가 지울 수 없음). 이 번호에는 이름·답이 붙어 있지 않습니다. 정리 방법을 정해 여기에 적어야 함

4. 카카오·구글과의 연결 끊기

앱에서 계정을 지우면 가화만사성 쪽 로그인 정보는 지워집니다. 하지만 카카오·구글 계정 자체는 지워지지 않고, 각 회사의 "연결된 서비스" 목록에 가화만사성이 남아 있을 수 있습니다.

  • 카카오: 계정을 지울 때 앱이 카카오 연결 끊기도 함께 시도합니다. 그래도 남아 있으면 카카오톡 → 설정 → 카카오계정 → 연결된 서비스 관리 → 가화만사성 → 연결 끊기. 불확실: 카카오톡 메뉴 경로는 버전마다 다름, 게시 전 실제 앱으로 확인. 앱이 카카오 로그인 상태가 아니면 연결 끊기가 실패함 — 서버에서 끊는 기능은 설계만 됨(dev-app-notes TODO)
  • 구글: Google 계정 관리(myaccount.google.com) → 보안 → 타사 앱 및 서비스와의 연결 → 가화만사성 → 연결 삭제. 불확실: 메뉴 이름 게시 전 확인
  • 이메일 인증번호로 가입하셨다면 따로 끊을 것이 없습니다.

검토 요청 사항 (독립 검토자에게)

  1. Play 요건 3가지(앱 밖 요청 가능, 앱·개발자명, 지우는/남는 데이터와 기간)를 이 페이지가 모두 채우는지.
  2. 부모님(익명) 본인 확인 방법 공백 — "자녀가 대신 지우기"를 1순위로 안내한 것이 정책상 괜찮은지(어르신 본인 요청이 우선이라는 v1 문장을 뺐음).
  3. 카카오 이메일 미수집 때문에 메일 요청 시 카카오 가입자를 찾을 수단이 닉네임뿐 — 확인 방법이 충분한지(앱 안 지우기 우선 유도로 충분한지).
  4. "법 때문에 남기는 정보 없음" 단정 표현의 법률 확인.
  5. P9 확인 단계 수 문구가 출시 빌드와 맞는지, 메뉴 이름 대조(라이터·QA).
  6. 마지막 자녀 삭제 뒤 남는 부모님 익명 계정의 처리·고지 방법(서버 담당).
  7. 카카오 서버 연결 끊기(Admin 키 Edge Function) 미구현 상태에서 "앱이 함께 시도" 문장이 과장이 아닌지.
