앱: 가화만사성 · 개발자(상호): [운영자 입력 필요: 행복가게 — 사업자등록증 표기와 똑같이, Play 개발자 이름과도 같게] · 시행일 [운영자 입력 필요]

앱을 열 수 있으면 앱에서 지우는 게 가장 빠르고 확실합니다. 누르는 순간 서버에서 바로 지워집니다.
앱을 열 수 없으면 아래 2번처럼 메일로 요청하세요. 앱을 설치하지 않아도 됩니다.

1. 앱에서 지우기

부모님

  1. 코스 홈 위쪽의 설정을 누릅니다.
  2. 모두 지우기를 누릅니다.
  3. "모두 지울까요?"가 나오면 모두 지우기를 한 번 더 누릅니다.

고른 답과 도장이 모두 지워지고, 가족과 연결도 끊깁니다. 자녀 화면에서도 부모님의 답이 사라집니다. 확실: 앱 문구·DeleteAccountScreen 대조(검토 B)

답만 지우고 앱은 계속 쓰고 싶으시면: 설정 → 그만 보여 주기. 지금까지 저장된 답이 지워지고, 앞으로 고른 답은 저장되지 않습니다. 앱은 그대로 쓰실 수 있습니다.

자녀

  1. 설정을 누릅니다.
  2. 내 계정 지우기를 누릅니다.
  3. 안내를 읽고 계정 지우기를 누릅니다. 가족의 마지막 자녀라면 확인 글자 "지우기"를 써야 합니다.
  • 다른 자녀가 아직 가족에 있으면: 내 계정만 지워집니다. 부모님의 고른 답과 기록은 남아 다른 자녀가 계속 볼 수 있습니다.
  • 내가 마지막 자녀라면: 내 계정과 함께 부모님의 고른 답과 기록, 부모님 휴대폰의 로그인 번호까지 모두 지워집니다. 부모님 앱은 연결이 풀린 상태가 됩니다. 게시 조건 G3

불확실: 3단계 버튼 이름("계정 지우기")은 출시 빌드 화면과 대조

2. 앱을 열 수 없을 때: 메일로 요청하기

받는 곳: [운영자 입력 필요: 문의 메일]
제목: [가화만사성] 지우기 요청

부모님

부모님의 기록은 부모님 본인이 지우시는 것이 원칙입니다.

  1. 가장 좋은 방법: 부모님 휴대폰에서 앱을 열고 설정 → 모두 지우기(위 1번).
  2. 앱을 열 수 없으면: 메일에 휴대폰 기종과 가족과 연결한 대략의 날짜를 적어 보내 주세요. [운영자 입력 필요: 운영자가 정한 본인 확인 방법] 게시 조건 G7
  3. 자녀가 대신 요청하실 때는 부모님이 지우기를 원하신다는 것을 확인할 수 있어야 합니다(예: 부모님과 함께 보낸 메일, 통화 확인). 자녀가 자기 계정을 지워도 다른 자녀가 남아 있으면 부모님 기록은 지워지지 않습니다.

자녀

  • 로그인 방법(카카오 / 구글 / 이메일 인증번호)을 적어 주세요.
  • 구글·이메일 인증번호로 가입하셨다면 그 메일 주소에서 보내 주세요.
  • 카카오로 가입하셨다면, 운영자는 카카오 이메일을 받지 않아 메일만으로는 계정을 찾기 어렵습니다. 되도록 앱에서 직접 지워 주세요. 앱을 열 수 없으면 카카오 닉네임(동의하신 경우)과 가입한 대략의 날짜를 적어 주세요.

지울 범위도 적어 주세요: 계정 전체 / 고른 답만.

본인인지 확인하려고 몇 가지 여쭐 수 있습니다. 주민등록번호, 비밀번호, 인증번호는 보내지 마세요.

메일을 받은 날부터 10일 안에(보통 7일) 지우고, 끝나면 메일로 알려 드립니다.

3. 지워지는 것과 남는 것

4. 카카오·구글과의 연결 끊기

앱에서 계정을 지우면 가화만사성 쪽 로그인 정보는 지워집니다. 하지만 카카오·구글 계정 자체는 지워지지 않고, 각 회사의 "연결된 서비스" 목록에 가화만사성이 남아 있을 수 있습니다.

  • 카카오: 계정을 지울 때 앱이 카카오 연결 끊기도 함께 시도합니다. 확실: realApi.deleteMyAccount가 카카오 연결 끊기 호출(검토 B) 그래도 남아 있으면 카카오톡 → 설정 → 카카오계정 → 연결된 서비스 관리 → 가화만사성 → 연결 끊기. 불확실: 카카오톡 메뉴 경로 게시 전 실제 앱으로 확인
  • 구글: Google 계정 관리(myaccount.google.com) → 보안 → 타사 앱 및 서비스와의 연결 → 가화만사성 → 연결 삭제. 불확실: 메뉴 이름 게시 전 확인
  • 이메일 인증번호로 가입하셨다면 따로 끊을 것이 없습니다.
