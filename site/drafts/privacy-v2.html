가화만사성 개인정보처리방침

시행일: [운영자 입력 필요: 시행일] · 버전 2

[운영자 입력 필요: 사업자 상호](이하 "운영자")는 "가화만사성" 앱(이하 "앱")을 만들고 운영합니다. 앱에서 부모님은 매일 옛날 사진을 보고, 둘 중 하나를 고르는 질문에 답하고, 휴대폰 자판으로 낱말을 써 봅니다. 자녀는 부모님이 허락하시면 부모님이 고른 답과 날짜를 봅니다.

이 방침은 앱이 어떤 정보를 왜 모으고, 언제 지우는지 알려 드립니다.

1. 한눈에 보기

  • 부모님은 이름·전화번호 없이 씁니다. 앱이 만든 무작위 번호로만 구분합니다.
  • 부모님이 고른 답은 부모님이 "좋아요"를 누르셨을 때만 저장되고, 연결된 가족에게만 보입니다.
  • 가족에게는 최근 30일 동안 고른 답만 보입니다. 31일이 지난 답은 지웁니다. 불확실: 자동 지우기 기능은 출시 전 구현 예정(마이그레이션 0023)
  • 위치, 연락처, 사진첩, 카메라, 마이크, 전화번호는 쓰지 않습니다. 광고를 넣지 않습니다.
  • 계정을 지우면 바로 지워집니다. 법 때문에 따로 보관하는 정보는 없습니다. 불확실: 법률 확인 필요(5절)

3. 가족에게 보이는 것과 동의

  • 부모님이 번호로 연결하면 "고른 답을 가족과 나눠요" 화면이 나옵니다. "좋아요"를 누르시면 고른 답과 날짜가 연결된 가족(자녀)에게 보입니다. 코스를 안 한 날, 걸린 시간, 끝낸 단계는 가족에게 보이지 않습니다. 확실: 서버 child_summary가 답·날짜만 돌려줌(0012)
  • 가족에게는 최근 30일 동안 고른 답만 보입니다.
  • "싫어요"를 누르셔도 앱은 그대로 쓰실 수 있습니다. 이때 고른 답은 저장하지 않습니다. 가족에게는 답도, 코스를 했는지도 보이지 않습니다.
  • 설정의 "그만 보여 주기"를 누르시면 지금까지 저장된 답이 바로 지워집니다. 다시 보여 주시면 그날부터 고른 답만 저장됩니다. 확실: withdraw_consent가 답을 지움(0012)
  • 이 앱의 동의 문구는 2026-11 버전 2입니다. 버전 1보다 가족에게 보이는 범위가 좁아져서 이미 동의하신 분께 다시 묻지 않고 이 방침으로 알립니다. 불확실: "범위를 좁히는 변경은 재동의 없이 고지로 충분"은 팀 판단(설계 리뷰). 법률 확인 필요

6. 만 14세 미만

자녀 계정은 만 14세 이상만 만들 수 있습니다. 운영자는 만 14세 미만의 정보를 일부러 모으지 않으며, 알게 되면 바로 지웁니다. 이 앱은 어린이를 위한 앱이 아닙니다. 불확실: 가입 화면에 연령 안내만 둘지, 확인 단계를 둘지 미결정. Play 대상 연령은 만 18세 이상으로 제안(docs/team/store/play-console-draft.md)

7. AI로 만든 그림과 음악

  • 앱의 오늘의 사진은 생성형 AI(Google Gemini)로 만든 그림입니다. 실제 장소나 실제 사람을 찍은 사진이 아닙니다. 앱 안의 사진 화면과 설정에서도 "AI가 만든 그림"이라고 알려 드립니다. 그림에는 이용자의 정보가 쓰이지 않습니다. 확실: DECISIONS 11-17 Gemini API 채택·AI 표기
